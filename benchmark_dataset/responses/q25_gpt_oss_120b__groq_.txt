┌───────────────────────────────────────┐  
│ **Introduction**                      │  
│                                       │  
│ Astronauts appear to float when they are   │  
│ orbiting Earth or traveling through space. │  
│ This phenomenon is commonly called “weightlessness” │  
│ or “micro‑gravity”.                     │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Definition**                         │  
│                                       │  
│ *Weightlessness* is the state in which an │  
│ object experiences no net contact force │  
│ (no normal force) acting on it. In orbit, │  
│ the spacecraft and everything inside it │  
│ are in continuous free‑fall toward Earth, │  
│ so the occupants feel weightless.       │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Key Concepts**                       │  
│                                       │  
│ • **Free‑fall:** All objects accelerate │  
│   toward the Earth at the same rate.   │  
│ • **Orbit:** A continuous free‑fall path │  
│   that matches the curvature of Earth. │  
│ • **Micro‑gravity:** The residual │  
│   accelerations (≈10⁻⁶ g) that remain due │  
│   to tidal forces, atmospheric drag, etc.│  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Characteristics**                    │  
│                                       │  
│ • Apparent weight = 0 N (no normal force).│  
│ • Objects drift, float, and can be moved│  
│   with very little effort.               │  
│ • Fluids form spherical blobs; flames │  
│   become spherical.                     │  
│ • Human body experiences muscle atrophy │  
│   and bone density loss over long stays.│  
└───────────────────────────────────────┘

┌───────────────────────────────────────┐  
│ **Applications**                       │  
│                                       │  
│ • Spacewalks (EVA) and satellite repair.│  
│ • Micro‑gravity experiments in materials │  
│   science, fluid dynamics, biology.   │  
│ • Testing equipment for long‑duration │  
│   missions (e.g., life‑support systems).│  
│ • Training astronauts on Earth using │  
│   parabolic flights or drop towers.   │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Advantages**                         │  
│                                       │  
│ • Enables research impossible on Earth │  
│   (e.g., crystal growth, protein folding).│  
│ • Allows precise satellite positioning │  
│   (no atmospheric drag).               │  
│ • Provides a realistic environment for │  
│   testing spacecraft hardware.        │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Disadvantages**                      │  
│                                       │  
│ • Prolonged weightlessness leads to   │  
│   muscle atrophy, bone loss, and fluid │  
│   redistribution in the human body.   │  
│ • Engineering challenges: equipment │  
│   must be secured to prevent drift.   │  
│ • Psychological effects (e.g., dis-  │  
│   orientation, isolation).            │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Important Notes**                    │  
│                                       │  
│ • “Zero‑gravity” is a misnomer – gravity │  
│   still exists; it’s just being continuously │  
│   counteracted by orbital free‑fall.   │  
│ • The term **micro‑gravity** (≈10⁻⁶ g)   │  
│   more accurately describes the tiny │  
│   residual accelerations on the ISS.   │  
│ • Weightlessness is not the same as │  
│   being far from Earth; even at 400 km │  
│   altitude, g ≈ 0.9 g.                  │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Summary**                            │  
│                                       │  
│ Astronauts feel weightless because both │  
│ they and their spacecraft are in continuous │  
│ free‑fall, moving along an orbital path that │  
│ matches Earth’s curvature. The governing │  
│ physics is Newton’s law of gravitation │  
│ ( F = GMm/r² ) and the resulting centripetal │  
│ acceleration ( a = v²/r ). This environment │  
│ enables unique scientific experiments │  
│ but also poses health challenges for │  
│ humans.                               │  
└───────────────────────────────────────┘
