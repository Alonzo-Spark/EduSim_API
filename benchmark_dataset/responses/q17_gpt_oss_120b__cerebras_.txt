┌───────────────────────────────────────────────┐
│ Introduction                                    │
│                                               │
│ The work‑energy theorem is a fundamental bridge │
│ between dynamics (forces) and kinematics (     │
│ motion). It tells us that the net work done on │
│ a particle equals the change in its kinetic    │
│ energy. This relation is widely used in physics│
│ and engineering to analyse systems where       │
│ forces and motion interact.                     │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│ Definition                                      │
│                                               │
│ **Work‑Energy Theorem**: The total (net) work  │
│ \(W_{\text{net}}\) performed by all forces on   │
│ a particle during a displacement equals the     │
│ change in its kinetic energy \(\Delta K\):      │
│                                               │
│ \[
│   W_{\text{net}} = \Delta K
│ \]                                             │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│ Derivation                                      │
│                                               │
│ 1. **Start with the definition of work** for a │
│    variable force \(\mathbf{F}\) acting along   │
│    an infinitesimal displacement \(d\mathbf{s}\):│
│                                               │
│    \[
│      dW = \mathbf{F}\!\cdot d\mathbf{s}
│    \]                                            │
│                                               │
│ 2. **Apply Newton’s second law** \(\mathbf{F}=m\mathbf{a}\)│
│    and write the acceleration as the derivative │
│    of velocity: \(\mathbf{a}=d\mathbf{v}/dt\).   │
│                                               │
│    \[
│      dW = m\frac{d\mathbf{v}}{dt}\!\cdot\mathbf{v}\,dt
│          = m\,\mathbf{v}\!\cdot d\mathbf{v}
│    \]                                            │
│                                               │
│ 3. **Recognise the differential of speed squared**:│
│                                               │
│    \[
│      \mathbf{v}\!\cdot d\mathbf{v}
│        = \tfrac{1}{2}\,d(\mathbf{v}\!\cdot\mathbf{v})
│        = \tfrac{1}{2}\,d(v^{2})
│    \]                                            │
│                                               │
│ 4. **Substitute back** into the work element:   │
│                                               │
│    \[
│      dW = \tfrac{1}{2}m\,d(v^{2})
│    \]                                            │
│                                               │
│ 5. **Integrate** from the initial state \((v_i)\)│
│    to the final state \((v_f)\):                │
│                                               │
│    \[
│      \int_{i}^{f} dW = \tfrac{1}{2}m\!\int_{v_i}^{v_f} d(v^{2})
│    \]                                            │
│                                               │
│    \[
│      W_{\text{net}} = \tfrac{1}{2}m v_f^{2}
│                      - \tfrac{1}{2}m v_i^{2}
│      = \Delta K
│    \]                                            │
│                                               │
│ Hence the net work equals the change in kinetic│
│ energy.                                         │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Applications                                    │
│                                               │
│ • **Mechanical engineering** – sizing motors│
│   and brakes by equating work to kinetic energy│
│ • **Projectile motion** – predicting range   │
│   from initial kinetic energy                │
│ • **Roller‑coaster design** – ensuring safety│
│   by checking that the track can absorb the   │
│   kinetic energy of the train                │
│ • **Energy audits** – converting work done by│
│   pumps or compressors into kinetic‑energy   │
│   terms for efficiency analysis               │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│ Summary                                         │
│                                               │
│ The work‑energy theorem states that the net   │
│ work performed on a particle equals the change│
│ in its kinetic energy. Starting from the       │
│ definition of work and Newton’s second law,   │
│ the theorem emerges by integrating the work    │
│ element \(dW = m\mathbf{v}\cdot d\mathbf{v}\)  │
│ and recognising the differential of \(v^{2}\).│
│ It provides a powerful shortcut: instead of   │
│ solving the full equations of motion, one can │
│ directly relate forces (through work) to the  │
│ resulting speed change.                       │
└───────────────────────────────────────────────┘
