┌─────────────────────────────────────┐
│ Introduction                        │
│                                     │
│ A train is traveling at a constant   │
│ speed of **20 m/s**. When the driver │
│ applies the brakes, the train comes │
│ to a complete stop after **10 s**. │
│ We need to determine the **retard‑ │
│ ation (deceleration)** that the train│
│ experiences during this interval.   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Definition                          │
│                                     │
│ **Retardation** (or deceleration)   │
│ is the magnitude of the negative     │
│ acceleration that reduces an object's│
│ speed. It is expressed in metres per │
│ second‑squared ( m s⁻² ).              │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Key Concepts                        │
│                                     │
│ • **Initial velocity (u)** – speed   │
│   before braking (20 m/s).           │
│ • **Final velocity (v)** – speed after│
│   stopping (0 m/s).                  │
│ • **Time (t)** – interval of braking │
│   (10 s).                            │
│ • **Retardation (a)** – the quantity │
│   we seek.                           │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Given Data (Table)                  │
│                                     │
│ ┌─────────────┬───────┐              │
│ │ Quantity    │ Value │              │
│ ├─────────────┼───────┤              │
│ │ Initial speed (u) │ 20 m/s │        │
│ │ Final speed (v)   │ 0 m/s  │        │
│ │ Time (t)          │ 10 s   │        │
│ └─────────────┴───────┘              │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Main Formula                        │
│                                     │
│          a = Δv / t                │
│          a = (v – u) / t           │
│                                     │
│ [ Explain Formula ]                 │
│ [ Open Formula Lab ]                │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Calculation                         │
│                                     │
│ 1. Identify Δv (change in velocity):│
│    Δv = v – u = 0 m/s – 20 m/s = –20 m/s │
│                                     │
│ 2. Apply the formula:               │
│    a = Δv / t = (–20 m/s) / 10 s = –2 m/s² │
│                                     │
│ 3. Interpretation:                  │
│    The negative sign indicates the  │
│    acceleration is opposite to the │
│    direction of motion – i.e., a    │
│    **retardation of 2 m/s²**.       │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Summary                             │
│                                     │
│ • Initial speed: 20 m/s             │
│ • Final speed: 0 m/s                │
│ • Time to stop: 10 s                │
│ • Retardation: **2 m/s²** (opposite │
│   to motion)                        │
│                                     │
│ The train decelerates uniformly at │
│ 2 m/s² until it stops.               │
└─────────────────────────────────────┘
