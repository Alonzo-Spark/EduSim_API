┌─────────────────────────────────────┐
│ Problem Statement                    │
│                                     │
│ A current of 2 A flows through a      │
│ resistor of 10 Ω. Calculate the      │
│ voltage across the resistor.         │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Formula Card – Ohm's Law              │
│                                     │
│               V = I R                │
│                                     │
│ [ Explain Formula ]                  │
│ [ Open Formula Lab ]                  │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Solution Steps                       │
│                                     │
│ 1. Identify the known quantities:   │
│    • Current (I) = 2 A               │
│    • Resistance (R) = 10 Ω           │
│                                     │
│ 2. Use Ohm's Law (V = I R) to find   │
│    the voltage.                     │
│                                     │
│ 3. Substitute the values:            │
│    V = (2 A) × (10 Ω)                │
│    V = 20 V                         │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Answer                               │
│                                     │
│ The voltage across the 10 Ω resistor│
│ is **20 volts**.                     │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Summary                              │
│                                     │
│ • Ohm's Law relates voltage, current│
│   and resistance: V = I R.           │
│ • Plugging I = 2 A and R = 10 Ω gives │
│   V = 20 V.                          │
│ • This is a direct application of   │
│   the linear relationship in basic   │
│   circuits.                         │
└─────────────────────────────────────┘
