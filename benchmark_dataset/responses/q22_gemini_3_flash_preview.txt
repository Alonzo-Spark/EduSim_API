### 📘 INTERACTIVE LESSON: ACCELERATION DUE TO GRAVITY ($g$)

┌──────────────────────────────────────────────────────────────────┐
│ **Introduction**                                                 │
│                                                                  │
│ Gravity is the universal force of attraction between masses.     │
│ When an object falls freely towards Earth, it experiences a      │
│ constant acceleration caused by Earth's gravitational pull. This │
│ value is denoted by the symbol $g$.                              │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Definition**                                                   │
│                                                                  │
│ **Acceleration due to gravity** is the acceleration gained by an │
│ object due to the gravitational force exerted by a massive body  │
│ (like Earth) in the absence of air resistance.                   │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Key Concepts**                                                 │
│                                                                  │
│ To derive the expression, we synthesize two fundamental laws:     │
│ 1. **Newton’s Second Law of Motion**: $F = ma$                   │
│ 2. **Newton’s Universal Law of Gravitation**: $F = \frac{GmM}{r^2}$│
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Main Formula: The Gravitational Force**                        │
│                                                                  │
│ $$F = G \frac{M \cdot m}{R^2}$$                                  │
│                                                                  │
│ **[ Explain Formula ]**                                          │
│ This represents the force ($F$) between the Earth (mass $M$) and │
│ an object (mass $m$) at a distance $R$ from the center.          │
│ **[ Open Formula Lab ]**                                         │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **The Derivation Steps**                                         │
│                                                                  │
│ 1. **Force on the object**: According to Newton's Second Law,    │
│    the force acting on a falling body is:                        │
│    $$F = m \cdot g$$                                             │
│                                                                  │
│ 2. **Gravitational pull**: According to the Law of Gravitation,  │
│    the force is also:                                            │
│    $$F = \frac{G \cdot M \cdot m}{R^2}$$                         │
│                                                                  │
│ 3. **Equating the two**: Since both represent the same force:    │
│    $$m \cdot g = \frac{G \cdot M \cdot m}{R^2}$$                 │
│                                                                  │
│ 4. **Simplify**: Cancel the mass of the object ($m$) from both   │
│    sides.                                                        │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Final Expression**                                             │
│                                                                  │
│ $$g = \frac{G \cdot M}{R^2}$$                                    │
│                                                                  │
│ **[ Explain Formula ]**                                          │
│ This shows that $g$ depends only on the mass of the planet ($M$) │
│ and the radius ($R$), not the mass of the falling object ($m$).  │
│ **[ Open Formula Lab ]**                                         │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Variable Reference**                                           │
│                                                                  │
│ | Symbol | Meaning | Standard Value (Earth) |                     │
│ | :--- | :--- | :--- |                                           │
│ | $g$ | Acceleration due to gravity | $\approx 9.8 \, m/s^2$ |     │
│ | $G$ | Universal Gravitational Constant | $6.67 \times 10^{-11} \, Nm^2/kg^2$ | │
│ | $M$ | Mass of the Earth | $5.97 \times 10^{24} \, kg$ |         │
│ | $R$ | Radius of the Earth | $6.37 \times 10^6 \, m$ |           │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Important Notes**                                              │
│                                                                  │
│ • **Mass Independence**: A feather and a hammer fall at the same │
│   rate in a vacuum because $g$ is independent of the object's $m$.│
│ • **Inverse Square Law**: If the distance from the center ($R$)  │
│   doubles, the gravity ($g$) becomes one-fourth.                 │
│ • **Shape of Earth**: Earth is an oblate spheroid. $g$ is        │
│   slightly higher at the poles (smaller $R$) than at the equator.│
└──────────────────────────────────────────────────────────────────┘
