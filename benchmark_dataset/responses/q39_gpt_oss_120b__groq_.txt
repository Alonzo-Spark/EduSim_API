┌───────────────────────────────────────┐
│ Quick Definition                       │
│                                       │
│ A **wave** is a disturbance that        │
│ transfers energy through a medium (or   │
│ vacuum) without transporting matter.   │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Wavelength (λ)                         │
│                                       │
│ • Definition: The distance between two │
│   consecutive points that are in      │
│   **identical phase** of the wave (e.g., │
│   crest‑to‑crest or trough‑to‑trough).│
│ • Symbol: λ                           │
│ • Units: meters (m)                    │
│ • Visual cue: One full “hill” of the   │
│   sinusoidal shape.                    │
│                                       │
│ **Key Point:** Larger λ → longer wave   │
│ cycles; smaller λ → more tightly packed│
│ cycles.                                │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Frequency (f)                          │
│                                       │
│ • Definition: The number of complete    │
│   wave cycles that pass a fixed point   │
│   per unit time.                         │
│ • Symbol: f                            │
│ • Units: hertz (Hz) = cycles/second    │
│ • Relationship to period (T):           │
│   f = 1/T                               │
│                                       │
│ **Key Point:** Higher f → more cycles   │
│ per second → higher‑pitch sound or     │
│ higher‑energy electromagnetic wave.    │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Amplitude (A)                          │
│                                       │
│ • Definition: The maximum displacement │
│   of a point on the wave from its       │
│   equilibrium (rest) position.         │
│ • Symbol: A                            │
│ • Units: Same as the quantity being     │
│   displaced (e.g., meters for a       │
│   water wave, volts for an electric   │
│   field).                              │
│ • Visual cue: Height of the “hill” or  │
│   depth of the “valley” in the wave.   │
│                                       │
│ **Key Point:** Larger A → more energy   │
│ carried by the wave (energy ∝ A²).       │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Summary                                 │
│                                       │
│ • **Wavelength (λ):** distance between │
│   identical points of a wave.          │
│ • **Frequency (f):** cycles per second,│
│   f = 1/T.                              │
│ • **Amplitude (A):** maximum displacement│
│   from equilibrium; determines wave    │
│   energy.                               │
│ • The three are interrelated:           │
│   - For a given wave speed (v),          │
│     v = f · λ.                           │
│   - Changing one (e.g., λ) while keeping │
│     v constant changes the others.      │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐

└───────────────────────────────────────┘
