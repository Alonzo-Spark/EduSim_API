│ Introduction                           │
│                                       │
│ This overlay is triggered whenever the   │
│ friction coefficient of a braking track │
│ platform changes (e.g., due to rain,  │
│ oil spill, or wear). It provides real‑ │
│ time data, impact analysis, and actionable │
│ recommendations for operators and   │
│ automated control systems.           │

┌───────────────────────────────────────┐
│ Main Formula                           │
│                                       │
│   d = \frac{v^{2}}{2 μ g}               │
│                                       │
│   • d  – braking distance (m)          │
│   • v  – train speed (m·s⁻¹)            │
│   • μ  – friction coefficient          │
│   • g  – gravitational acceleration (9.81 │
│          m·s⁻²)                        │
