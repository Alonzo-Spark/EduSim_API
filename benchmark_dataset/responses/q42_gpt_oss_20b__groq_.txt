┌───────────────────────────────────────────────────────────────────────┐
│ Definition: Electric Field                                                │
│                                                                             │
│ The electric field at a point is the force per unit positive test charge │
│ experienced by a small test charge placed at that point. It is a vector   │
│ field denoted by **E**.                                                    │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Definition: Electric Potential                                            │
│                                                                             │
│ Electric potential is the potential energy per unit charge at a point in │
│ an electric field. It is a scalar quantity denoted by **V**.              │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Main Formula                                                               │
│                                                                             │
│     $$ \mathbf{E} = \frac{\mathbf{F}}{q} $$                                │
│                                                                             │
│ [ Explain Formula ] [ Open Formula Lab ]                                   │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Main Formula                                                               │
│                                                                             │
│     $$ V = \frac{U}{q} $$                                                  │
│                                                                             │
│ [ Explain Formula ] [ Open Formula Lab ]                                   │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Key Concepts                                                              │
│                                                                             │
│ • **E** is a vector; **V** is a scalar.                                    │
│ • The electric field is the negative gradient of the potential:            │
│   $$ \mathbf{E} = -\nabla V $$                                            │
│ • Potential difference equals work done per unit charge.                   │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Summary                                                                    │
│                                                                             │
│ The electric field describes the force exerted on a unit charge in a      │
│ region, while the electric potential describes the energy per unit charge │
│ at that point. They are intrinsically linked through the relationship     │
│ **E = -∇V**.                                                               │
└───────────────────────────────────────────────────────────────────────┘
