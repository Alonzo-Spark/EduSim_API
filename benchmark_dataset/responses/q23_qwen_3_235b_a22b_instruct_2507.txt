┌───────────────────────────┐  
│ **Quick Definition**      │  
│                           │  
│ **Mass** is the amount of matter in an object.  
│ **Weight** is the force of gravity acting on that mass.  
│                           │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Key Concepts**          │  
│                           │  
│ • Mass is intrinsic — it doesn't change with location.  
│ • Weight depends on gravity — it changes on the Moon, Mars, etc.  
│ • Mass is measured in kilograms (kg).  
│ • Weight is measured in newtons (N).  
│                           │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Main Formula**          │  
│                           │  
│ $$  
W = mg  
$$                          │  
│                           │  
│ [ Explain Formula ]       │  
│ [ Open Formula Lab ]      │  
└───────────────────────────┘  

> **Where:**  
> - $ W $ = weight (in newtons, N)  
> - $ m $ = mass (in kilograms, kg)  
> - $ g $ = acceleration due to gravity (~9.8 m/s² on Earth)  

---

┌───────────────────────────┐  
│ **Characteristics**       │  
│                           │  
│ **Mass**                  │  
│ ✔ Scalar quantity          │  
│ ✔ Constant everywhere      │  
│ ✔ Measured with balance    │  
│                           │  
│ **Weight**                │  
│ ✔ Vector quantity (has direction — toward center of gravity)  
│ ✔ Varies with location     │  
│ ✔ Measured with spring scale  
│                           │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Example Comparison**    │  
│                           │  
│ Suppose you have a 10 kg object:  
│  
│ - **On Earth:**  
│   $ W = 10~\text{kg} \times 9.8~\text{m/s}^2 = 98~\text{N} $  
│  
│ - **On the Moon** (g ≈ 1.6 m/s²):  
│   $ W = 10~\text{kg} \times 1.6~\text{m/s}^2 = 16~\text{N} $  
│  
│ → Mass remains **10 kg**, but weight drops from 98 N to 16 N.  
│                           │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Common Misconceptions** │  
│                           │  
│ ❌ "I weigh 60 kg"         │  
│ → Technically, that’s your *mass*. Your *weight* is about 588 N.  
│  
│ ❌ "Mass and weight are the same."  
│ → They’re related, but fundamentally different.  
│  
│ ✅ Use "mass" when talking about matter.  
│ ✅ Use "weight" when talking about gravitational force.  
│                           │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Applications**          │  
│                           │  
│ • Engineering: Calculating loads on structures (uses weight).  
│ • Space travel: Fuel calculations depend on mass (unchanging).  
│ • Medicine: Dosages based on *mass*, not weight.  
│ • Physics: Inertia depends on mass; gravitational force on weight.  
│                           │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Summary**               │  
│                           │  
│ • **Mass** = how much stuff. **Weight** = how hard gravity pulls.  
│ • Mass is constant. Weight changes with gravity.  
│ • Use $ W = mg $ to convert between them.  
│ • Always distinguish units: kg (mass) vs. N (weight).  
│                           │  
└───────────────────────────┘
