Here's the breakdown of how we'll present the derivation, designed to look like an interactive textbook section:

**Introduction**

┌───────────────────────────┐
│ Introduction to Electric Force │
│                           │
│ Electric force is the     │
│ fundamental interaction   │
│ between charged objects.  │
│ It's responsible for      │
│ phenomena like static     │
│ cling and the behavior    │
│ of circuits.              │
└───────────────────────────┘

**Definition**

┌───────────────────────────┐
│ Definition: Electric Force  │
│                           │
│ Electric force is a       │
│ non-contact force that    │
│ arises between any two    │
│ charged objects.          │
│ Like charges repel and    │
│ unlike charges attract.   │
└───────────────────────────┘

**Key Concepts**

┌───────────────────────────┐
│ Key Concepts: Coulomb's Law│
│                           │
│ The electric force is      │
│ quantified by Coulomb's   │
│ Law.  This law states that│
│ the magnitude of the      │
│ electric force between    │
│ two point charges is      │
│ directly proportional to  │
│ the product of the        │
│ magnitudes of the charges │
│ and inversely             │
│ proportional to the       │
│ square of the distance    │
│ between their centers.    │
└───────────────────────────┘

**Formula**

┌───────────────────────────┐
│ Main Formula: Coulomb's Law │
│                           │
│ $$F = k_e \frac{|q_1 q_2|}{r^2}$$ │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

**Formula Explanation**

┌───────────────────────────┐
│ Explain Formula: Coulomb's Law │
│                           │
│ *   **F**: Electric force    │
│     (measured in Newtons, N)│
│ *   **k_e**: Coulomb's       │
│     constant (≈ 8.9875 ×    │
│     10^9 N⋅m²/C²)         │
│ *   **q_1** and **q_2**:    │
│     Magnitudes of the       │
│     charges (measured in    │
│     Coulombs, C)          │
│ *   **r**: Distance         │
│     between the centers of  │
│     the charges (measured   │
│     in meters, m)         │
│                           │
│ The absolute value ensures  │
│ the force magnitude is     │
│ positive. The direction of  │
│ the force depends on the    │
│ signs of the charges.      │
└───────────────────────────┘

**Derivation**

┌───────────────────────────┐
│ Derivation: Electric Force │
│                           │
│ The derivation of Coulomb's│
│ Law involves the          │
│ following steps:          │
│                           │
│ 1.  **Experimental      │
│     Observation:** Early   │
│     experiments showed    │
│     that the force       │
│     between charged       │
│     objects depended on   │
│     the magnitude of the  │
│     charges and the       │
│     distance between      │
│     them.                 │
│                           │
│ 2.  **Proportionality:**  │
│     Through careful       │
│     measurements, it was  │
│     found that the force  │
│     is:                   │
│     *   Directly          │
│         proportional to   │
│         the product of    │
│         the charges:     │
│         `F ∝ q₁ * q₂`       │
│     *   Inversely         │
│         proportional to   │
│         the square of the │
│         distance:       │
│         `F ∝ 1/r²`         │
│                           │
│ 3.  **Combining           │
│     Proportionalities:**  │
│     Combining these       │
│     observations:         │
│                           │
│     `F ∝  q₁ * q₂ / r²`     │
│                           │
│ 4.  **Introducing the     │
│     Constant:** To turn   │
│     the proportionality   │
│     into an equation, a   │
│     constant of          │
│     proportionality      │
│     (k_e, Coulomb's      │
│     constant) is          │
│     introduced:          │
│                           │
│     $$F = k_e \frac{|q_1 q_2|}{r^2}$$ │
│                           │
│ 5.  **Coulomb's Constant:** │
│     The value of k_e is   │
│     determined           │
│     experimentally.       │
│                           │
└───────────────────────────┘

**Applications**

┌───────────────────────────┐
│ Applications: Electric Force│
│                           │
│ Electric force is         │
│ fundamental to many       │
│ applications:             │
│                           │
│ *   **Electrostatic       │
│     phenomena:**          │
│     Explains static cling,│
│     lightning, and the    │
│     operation of          │
│     capacitors.           │
│ *   **Atomic Structure:** │
│     Holds atoms together,│
│     determining the       │
│     interactions between  │
│     protons and electrons.│
│ *   **Circuit Design:**   │
│     Underlies the         │
│     behavior of current   │
│     and voltage in        │
│     electrical circuits.  │
└───────────────────────────┘

**Advantages**

┌───────────────────────────┐
│ Advantages: Electric Force  │
│                           │
│ *   **Predictive Power:**  │
│     Coulomb's Law         │
│     accurately predicts    │
│     the force between      │
│     charged objects.      │
│ *   **Foundation for      │
│     Electromagnetism:**   │
│     Forms the basis for    │
│     understanding more    │
│     complex              │
│     electromagnetic       │
│     phenomena.            │
└───────────────────────────┘

**Disadvantages**

┌───────────────────────────┐
│ Disadvantages: Electric Force│
│                           │
│ *   **Point Charges:**    │
│     Coulomb's Law is most │
│     accurate for point    │
│     charges.              │
│ *   **Relativistic        │
│     Effects:** At very    │
│     high speeds or        │
│     strong fields,        │
│     relativistic effects  │
│     (not covered by       │
│     Coulomb's Law) become│
│     significant.          │
└───────────────────────────┘

**Important Notes**

┌───────────────────────────┐
│ Important Notes: Electric Force │
│                           │
│ *   **Vector Quantity:**   │
│     Electric force is a   │
│     vector quantity,      │
│     meaning it has both   │
│     magnitude and         │
│     direction.            │
│ *   **Superposition       │
│     Principle:** The      │
│     net force on a charge │
│     due to multiple       │
│     charges is the vector │
│     sum of the forces     │
│     from each individual  │
│     charge.              │
└───────────────────────────┘
