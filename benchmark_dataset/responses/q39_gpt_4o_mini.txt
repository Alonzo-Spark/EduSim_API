┌───────────────────────────┐  
│ Quick Definition          │  
│                           │  
│ The wavelength, frequency, │  
│ and amplitude are key     │  
│ characteristics of waves. │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Wavelength                │  
│                           │  
│ Wavelength is the distance│  
│ between successive peaks   │  
│ (or troughs) of a wave.   │  
│ It is typically denoted by │  
│ the Greek letter lambda (λ).│  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Frequency                 │  
│                           │  
│ Frequency is the number of │  
│ cycles (or waves) that pass│  
│ a point in a unit of time.│  
│ It is measured in Hertz (Hz).│  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Amplitude                 │  
│                           │  
│ Amplitude refers to the    │  
│ maximum displacement of a  │  
│ point on the wave from its │  
│ rest position. It is a measure│  
│ of the wave's energy.      │  
└───────────────────────────┘
