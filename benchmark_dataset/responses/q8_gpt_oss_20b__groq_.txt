┌───────────────────────────┐
│ Problem                    │
│                            │
│ A ball is projected at an  │
│ angle of 45° with velocity │
│ 20 m/s. Find its range.    │
└───────────────────────────┘

┌───────────────────────────┐
│ Introduction               │
│                            │
│ Projectile motion describes│
│ the trajectory of an       │
│ object launched into the   │
│ air under the influence of│
│ gravity. The range is the  │
│ horizontal distance        │
│ traveled.                  │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts               │
│                            │
│ - Projectile motion        │
│ - Range                     │
│ - Launch angle              │
│ - Initial speed             │
│ - Gravity                   │
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula               │
│                            │
│  R = v^2 sin(2θ) / g       │
│                            │
│ [ Explain Formula ]        │
│ [ Open Formula Lab ]       │
└───────────────────────────┘

┌───────────────────────────┐
│ Application                │
│                            │
│ Using the formula with     │
│ v=20 m/s, θ=45°,           │
│ g=9.8 m/s², we get R =     │
│ (20² sin 90°) / 9.8 = 400   │
│ / 9.8 ≈ 40.8 m.            │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                    │
│                            │
│ The range of the ball is   │
│ approximately 40.8 meters. │
└───────────────────────────┘
