│                      Introduction                                  │
│                                                                             │
│ Astronauts feel “weightless” when they are in space because they are      │
│ in a continuous state of free‑fall around the Earth.  The sensation is     │
│ not due to the absence of gravity, but rather to the fact that both the   │
│ spacecraft and the astronauts inside it are falling at the same rate.     │
│ When every part of the system experiences the same gravitational pull,   │
│ there is no normal force pushing back on the astronauts, so they feel    │
│ weightless.                                                                 │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                          Definition                                 │
│                                                                             │
│ **Weightlessness** (also called *microgravity*) is the apparent lack of    │
│ weight experienced by objects in free‑fall, where the only force acting   │
│ on them is gravity.  It is distinct from true zero‑gravity, which does     │
│ not exist in the real universe.                                            │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Key Concepts                                 │
│                                                                             │
│ • **Free‑fall** – An object moving solely under the influence of gravity   │
│   without any other forces acting on it.                                    │
│ • **Orbit** – A trajectory in free‑fall that keeps an object from hitting   │
│   the surface of a planet due to its tangential velocity.                  │
│ • **Normal force** – The reaction force that gives the sensation of weight; │
│   it is absent when all parts of a system are accelerating together.      │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Formula                                      │
│                                                                             │
│     W = m · g                                                              │
│                                                                             │
│ **Explanation**:  Weight (W) is the force of gravity on a mass (m).  In a  │
│ free‑falling spacecraft, the normal force that would normally balance this │
│ weight is absent, so the astronauts feel no weight.                        │

┌───────────────────────────────────────────────────────────────────────┐
│                        Important Notes                                 │
│                                                                             │
│ • The term “microgravity” refers to the small residual accelerations that │
│   exist in orbit, caused by atmospheric drag, solar radiation pressure,   │
│   and the non‑spherical shape of Earth.                                    │
│ • Astronauts are not actually “weightless” in the sense of zero gravity;   │
│   they are simply experiencing the same gravitational pull on all parts   │
│   of the spacecraft, so the usual sensation of weight disappears.         │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Summary                                      │
│                                                                             │
│ Weightlessness occurs because astronauts and their spacecraft are in a     │
│ continuous free‑fall around Earth.  The gravitational pull on every part    │
│ of the system is the same, eliminating the normal force that normally      │
│ provides the sensation of weight.  This is why astronauts feel weightless  │
│ while orbiting.                                                             │
