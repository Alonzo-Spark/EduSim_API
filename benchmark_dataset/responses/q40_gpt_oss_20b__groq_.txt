┌───────────────────────────┐  
│ Introduction               │  
│                           │  
│ Transverse and longitudinal│  
│ waves are the two basic    │  
│ types of mechanical waves. │  
│ They differ in how the      │  
│ particles of the medium    │  
│ move relative to the       │  
│ direction of wave          │  
│ propagation.               │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Definition                 │  
│                           │  
│ • Transverse wave: The     │  
│   displacement of the      │  
│   medium is perpendicular  │  
│   to the direction of      │  
│   wave travel.             │  
│ • Longitudinal wave: The   │  
│   displacement is parallel │  
│   to the direction of      │  
│   wave travel.             │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Key Concepts               │  
│                           │  
│ • Both are mechanical      │  
│   waves that require a     │  
│   medium (solid, liquid,   │  
│   gas).                    │  
│ • Transverse waves can     │  
│   travel in solids;        │  
│   longitudinal waves can   │  
│   travel in all media.     │  
│ • Speed depends on         │  
│   medium properties.       │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Characteristics            │  
│                           │  
│ Transverse:                │  
│ - Particle motion is       │  
│   perpendicular to wave   │  
│   propagation.             │  
│ - Common in light, sound   │  
│   waves in strings, and    │  
│   electromagnetic waves.  │  
│ Longitudinal:              │  
│ - Particle motion is       │  
│   parallel to wave         │  
│   propagation.             │  
│ - Sound waves in air, water│  
│   and solids.              │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Applications               │  
│                           │  
│ • Transverse:              │  
│   • Light and radio waves │  
│   • Seismic surface waves │  
│ • Longitudinal:            │  
│   • Sound transmission    │  
│   • Ultrasound imaging    │  
│   • Seismic body waves    │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Summary                    │  
│                           │  
│ Transverse waves move the  │  
│ particles perpendicular to │  
│ the direction of travel,   │  
│ while longitudinal waves   │  
│ move particles parallel to │  
│ the direction of travel.   │  
│ Both require a medium and  │  
│ have distinct applications │  
│ in physics and engineering.│  
└───────────────────────────┘
