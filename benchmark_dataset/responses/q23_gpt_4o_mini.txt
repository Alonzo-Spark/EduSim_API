┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Mass is the measure of    │
│ the amount of matter in   │
│ an object, while weight   │
│ is the force exerted on   │
│ that object due to gravity.│
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ - **Mass**: Measured in   │
│   kilograms (kg) or grams │
│   (g). It is a scalar     │
│   quantity and does not   │
│   change regardless of    │
│   location.               │
│                           │
│ - **Weight**: Measured in │
│   newtons (N) or pounds   │
│   (lb). It is a vector    │
│   quantity that depends on │
│   the local gravitational  │
│   field strength.         │
└───────────────────────────┘

┌───────────────────────────┐
│ Characteristics           │
│                           │
│ - Mass is constant,       │
│   whereas weight varies    │
│   with gravity.           │
│ - Mass is a measure of    │
│   inertia, while weight is │
│   a measure of force.     │
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula              │
│                           │
│     $$W = mg$$           │
│                           │
│ Where:                   │
│ - \(W\) = weight (N)     │
│ - \(m\) = mass (kg)      │
│ - \(g\) = acceleration due│
│   to gravity (9.81 m/s²) │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

┌───────────────────────────┐
│ Applications              │
│                           │
│ - Understanding the       │
│   difference is crucial in │
│   physics, engineering,    │
│   and various scientific   │
│   applications, such as    │
│   calculating forces and   │
│   designing structures.    │
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes           │
│                           │
│ - On Earth, weight is     │
│   directly proportional to │
│   mass. However, on other  │
│   planets, the weight of   │
│   an object will differ    │
│   due to varying gravitational│
│   forces.                 │
└───────────────────────────┘
