┌───────────────────────────────────────┐
│ Definition                              │
│                                        │
│ **Pressure** is the normal force       │
│ exerted uniformly over a surface.      │
│ It quantifies how much force is applied │
│ per unit area of the contacting surface.│
│                                        │
│ Mathematically, it describes the       │
│ intensity of the force distribution.   │
└───────────────────────────────────────┘


┌───────────────────────────────────────┐
│ Main Formula                            │
│                                        │
│          P = \frac{F}{A}               │
│                                        │
│ [ Explain Formula ]                     │
│ [ Open Formula Lab ]                    │
└───────────────────────────────────────┘


┌───────────────────────────────────────┐
│ SI Unit                                 │
│                                        │
│ The SI unit of pressure is the **pascal**│
│ (symbol: **Pa**). One pascal equals one │
│ newton per square metre (1 Pa = 1 N·m⁻²).│
│                                        │
│ Common multiples:                      │
│ • kilopascal (kPa) = 10³ Pa            │
│ • megapascal (MPa) = 10⁶ Pa            │
│ • bar = 10⁵ Pa (often used in           │
│   engineering)                         │
└───────────────────────────────────────┘
