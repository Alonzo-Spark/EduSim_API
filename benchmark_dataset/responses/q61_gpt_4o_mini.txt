┌───────────────────────────┐  
│ Introduction              │  
│                           │  
│ When a mass is attached to a spring, it exhibits harmonic motion. This system can be analyzed using Hooke's Law, which describes the behavior of springs.   │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Quick Definition          │  
│                           │  
│ A spring-mass system consists of a mass attached to a spring that can oscillate back and forth when displaced from its equilibrium position.   │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Key Concepts              │  
│                           │  
│ - **Mass (m)**: The object attached to the spring.  
│ - **Spring Constant (k)**: A measure of the spring's stiffness.  
│ - **Displacement (x)**: The distance from the equilibrium position.  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Main Formula              │  
│                           │  
│     Rendered Formula      │  
│                           │  
│ $$ F = -kx $$            │  
│                           │  
│ [ Explain Formula ]       │  
│ [ Open Formula Lab ]      │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Characteristics           │  
│                           │  
│ - The force exerted by the spring is proportional to the displacement.  
│ - The direction of the force is always opposite to the displacement.  
│ - The system can oscillate indefinitely if not dampened.  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Applications              │  
│                           │  
│ - Used in mechanical clocks.  
│ - Found in suspension systems in vehicles.  
│ - Used in various engineering applications such as measuring devices.  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Advantages                │  
│                           │  
│ - Simple to model mathematically.  
│ - Demonstrates fundamental principles of mechanics.  
│ - Widely applicable in real-world scenarios.  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Disadvantages             │  
│                           │  
│ - Assumes ideal conditions (no friction, perfect elasticity).  
│ - Real springs may not behave linearly at large displacements.  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Important Notes           │  
│                           │  
│ - The spring constant (k) varies with the material and geometry of the spring.  
│ - Damping forces (like friction) can affect the oscillation amplitude over time.  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Summary                  │  
│                           │
