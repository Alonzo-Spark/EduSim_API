┌───────────────────────────┐  
│ Quick Definition          │  
│                           │  
│ Projectile motion is the │  
│ motion of an object that  │  
│ is thrown into the air and│  
│ is subject to the force of│  
│ gravity.                 │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Key Characteristics       │  
│                           │  
│ 1. **Trajectory**: The path│  
│    followed by the object  │  
│    is a curved shape,     │  
│    typically a parabola.  │  
│                           │  
│ 2. **Initial Velocity**:  │  
│    The motion begins with  │  
│    an initial velocity at   │  
│    a certain angle to the  │  
│    horizontal.            │  
│                           │  
│ 3. **Acceleration**:      │  
│    The only force acting on │  
│    the object is gravity,  │  
│    causing a constant      │  
│    downward acceleration.  │  
│                           │  
│ 4. **Independence of Motion**:│  
│    The horizontal and      │  
│    vertical components of   │  
│    motion are independent. │  
│                           │  
│ 5. **Maximum Height**:     │  
│    There is a point in the │  
│    trajectory where the    │  
│    object reaches its      │  
│    highest point.         │  
│                           │  
│ 6. **Range**: The total    │  
│    horizontal distance      │  
│    traveled by the object   │  
│    when it returns to the   │  
│    same vertical level.    │  
└───────────────────────────┘
