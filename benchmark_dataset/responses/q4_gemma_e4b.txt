**4. Formula Extraction Details (Python Example):**

```python
import re

def extract_formulas(markdown_text):
    """Extracts LaTeX formulas from markdown text."""
    formula_data = []
    latex_pattern = r"$$([^$]+)$$"
    matches = re.findall(latex_pattern, markdown_text)

    for match in matches:
        formula_data.append({
            "formula": match,
            "title": "Main Formula",  # Default title
            "surroundingContext": "", # To be filled in later
            "variables": []
        })

    return formula_data
```
