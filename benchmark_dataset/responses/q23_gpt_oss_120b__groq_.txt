┌───────────────────────────────────────┐
│               Introduction              │
│                                           │
│ Mass and weight are fundamental concepts │
│ in physics and everyday life, but they │
│ are often confused. This section gives   │
│ a clear, side‑by‑side explanation of      │
│ what each term means and how they differ. │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│                Definition                │
│                                           │
│ • **Mass** – a measure of the amount of   │
│   matter contained in an object. It is a  │
│   scalar quantity, the same everywhere,   │
│   and does not change with location.      │
│                                           │
│ • **Weight** – the force exerted on that   │
│   mass by gravity. It depends on both the │
│   object's mass and the local gravitational│
│   field. Weight can vary from place to     │
│   place.                                   │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│               Key Concepts               │
│                                           │
│ - **Inertia** – Mass quantifies an object │
│  ’s resistance to changes in its motion.  │
│ - **Force** – Weight is a force; it has   │
│   both magnitude and direction (toward    │
│   the centre of the gravitating body).    │
│ - **Units** – Mass: kilograms (kg);       │
│   Weight: newtons (N) or pounds (lb).     │
│ - **Location Dependence** – Mass is       │
│   constant; weight changes with           │
│   gravitational acceleration (g).         │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│               Applications               │
│                                           │
│ • **Engineering** – Designing structures │
│   requires knowing the weight (force)    │
│   that components must support.           │
│ • **Spaceflight** – Astronauts experience │
│   micro‑gravity, so their mass stays the   │
│   same while weight drops to near zero.   │
│ • **Everyday Life** – Scales measure mass │
│   (via calibrated weight), but we often   │
│   talk about “how heavy” (weight).        │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│            Important Notes               │
│                                           │
│ 1. **Mass never changes** unless matter   │
│    is added or removed.                   │
│ 2. **Weight = mass × local g**. On Earth, │
│    g ≈ 9.81 m/s², so a 10 kg mass weighs   │
│    ≈ 98 N.                                 │
│ 3. On the Moon (g ≈ 1.62 m/s²), the same   │
│    10 kg mass weighs only ≈ 16 N.         │
│ 4. In scientific contexts, “weight” often│
│    refers to **force**, not mass.         │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│                 Summary                  │
│                                           │
│ • Mass is an intrinsic property of matter │
│   measured in kilograms.                  │
│ • Weight is the gravitational force on that│
│   mass, measured in newtons, and varies   │
│   with the local gravitational field.      │
│ • The relationship is given by W = m g.    │
│ • Remember: mass = “how much stuff”;      │
│   weight = “how heavy it feels”.           │
└───────────────────────────────────────┘
