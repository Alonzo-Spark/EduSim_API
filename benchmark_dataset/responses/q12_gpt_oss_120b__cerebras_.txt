┌─────────────────────────────────────┐
│ 📖 Introduction                      │
│                                     │
│ Inertia is a fundamental concept in │
│ physics that describes an object's   │
│ resistance to any change in its      │
│ state of motion. Whether an object   │
│ is at rest or moving uniformly, its │
│ inertia determines how much force is│
│ must be applied to alter that state.│
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ 📚 Quick Definition                  │
│                                     │
│ **Inertia** – the tendency of a body│
│ to maintain its current state of    │
│ motion (either rest or uniform      │
│ straight‑line motion) unless acted  │
│ upon by an external net force.      │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ 🧭 Types of Inertia                  │
│                                     │
│ 1️⃣ **Linear (Translational) Inertia**│
│    – Resistance to changes in       │
│      linear velocity. Directly       │
│      proportional to the object's   │
│      mass (m).                       │
│                                     │
│ 2️⃣ **Rotational (Angular) Inertia** │
│    – Resistance to changes in       │
│      angular velocity. Quantified   │
│      by the *moment of inertia* (I).│
│      Depends on how mass is         │
│      distributed relative to the    │
│      axis of rotation.              │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ 📐 Main Formula                      │
│                                     │
│        I = Σ mᵢ rᵢ²                │
│                                     │
│ *Explain Formula*                   │
│ The moment of inertia (I) sums the  │
│ products of each mass element (mᵢ) │
│ and the square of its distance (rᵢ) │
│ from the rotation axis. It captures │
│ how mass distribution affects        │
│ rotational resistance.               │

┌─────────────────────────────────────┐
│ 📌 Important Notes                    │
│                                     │
│ • Inertia is *not* a force; it is a │
│   property of matter.                │
│ • Linear inertia is quantified by    │
│   mass (kg).                         │
│ • Rotational inertia depends on both │
│   mass and its geometry.             │
│ • The SI unit of moment of inertia   │
│   is kilogram·meter² (kg·m²).        │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ 📝 Summary                           │
│                                     │
│ • Inertia = resistance to change in│
│   motion.                            │
│ • Two primary types: linear (mass)  │
│   and rotational (moment of inertia).│
│ • Moment of inertia = Σ m r²,        │
│   crucial for analyzing rotating    │
│   systems.                           │
└─────────────────────────────────────┘
