┌───────────────────────────────────────────────┐  
│ Introduction                                    │  
│                                                   │  
│ Mechanical energy is the sum of an object’s      │  
│ kinetic energy (energy of motion) and            │  
│ gravitational potential energy (energy due to    │  
│ position). When only conservative forces act,   │  
│ the total mechanical energy remains constant      │  
│ throughout the motion. This principle lets us     │  
│ predict speeds and heights without solving        │  
│ detailed force equations.                        │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Definition                                      │  
│                                                   │  
│ **Conservation of Mechanical Energy**: In a       │  
│ closed system where non‑conservative forces (like │  
│ friction or air resistance) are negligible, the   │  
│ total mechanical energy \(E_{\text{mech}}\)       │  
│ stays the same:                                   │  
│                                                   │  
│ \[E_{\text{mech}} = K + U = \text{constant}\]     │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Key Concepts                                    │  
│                                                   │  
│ • **Kinetic Energy (K)** – \(\displaystyle K = \frac{1}{2}mv^{2}\) │  
│ • **Potential Energy (U)** – For gravity,          │  
│   \(\displaystyle U = mgh\) (height \(h\) above a   │  
│   reference level)                                 │  
│ • **Conservative Force** – A force whose work      │  
│   depends only on initial and final positions.     │  
│ • **Non‑conservative Forces** – Forces like        │  
│   friction that dissipate mechanical energy as heat.│  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Main Formula                                     │  
│                                                   │  
│ \[K_i + U_i = K_f + U_f\]                         │  
│                                                   │  
│ [ Explain Formula ]   [ Open Formula Lab ]        │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Example – Falling Ball                           │  
│                                                   │  
│ A ball of mass \(m = 0.5\ \text{kg}\) is dropped   │  
│ from a height \(h_i = 5\ \text{m}\).               │  
│                                                   │  
│ **Step 1 – Initial Energies**                     │  
│ • \(K_i = 0\) (ball starts from rest)             │  
│ • \(U_i = mgh_i = 0.5 \times 9.8 \times 5 = 24.5\ \text{J}\) │  
│                                                   │  
│ **Step 2 – Just Before Impact** (height \(h_f = 0\))│  
│ • \(U_f = 0\)                                      │  
│ • Conservation ⇒ \(K_f = K_i + U_i = 24.5\ \text{J}\) │  
│ • Solve for speed:                                 │  
│   \(\displaystyle K_f = \frac{1}{2}mv_f^{2}\) ⇒   │  
│   \(v_f = \sqrt{\frac{2K_f}{m}} = \sqrt{\frac{2\cdot24.5}{0.5}} \approx 9.9\ \text{m/s}\) │  
│                                                   │  
│ The ball’s mechanical energy stayed at 24.5 J,    │  
│ merely converting from potential to kinetic.     │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Energy Comparison Table                         │  
│                                                   │  
│ ┌─────────────┬───────────────┬───────────────┐ │  
│ │ Position    │ Kinetic (J)   │ Potential (J) │ │  
│ ├─────────────┼───────────────┼───────────────┤ │  
│ │ Top (5 m)   │ 0.0           │ 24.5          │ │  
│ │ Bottom (0 m)│ 24.5          │ 0.0           │ │  
│ └─────────────┴───────────────┴───────────────┘ │  
│                                                   │  
│ Total mechanical energy = 24.5 J in both rows.   │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Important Notes                                 │  
│                                                   │  
│ • The principle holds **only** when friction‑   │  
│   like forces are negligible.                     │  
│ • Choose a consistent reference level for       │  
│   potential energy; the absolute value is       │  
│   irrelevant – only differences matter.          │  
│ • For systems with springs, add elastic          │  
│   potential \(U = \tfrac{1}{2}kx^{2}\).           │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Summary                                         │  
│                                                   │  
│ • Mechanical energy = kinetic + potential.      │  
│ • In the absence of non‑conservative forces,    │  
│   this total remains constant.                   │  
│ • The conservation law lets us relate speeds    │  
│   and heights without detailed force analysis.   │  
│ • Real‑world applications: roller coasters,     │  
│   pendulums, satellite orbits, etc.              │  
└───────────────────────────────────────────────┘
