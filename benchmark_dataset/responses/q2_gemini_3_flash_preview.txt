### 📘 Lesson: Uniform Acceleration
**Topic:** Kinematics (Equations of Motion)

---

┌──────────────────────────────────────────────────────────┐
│ **Introduction**                                         │
│                                                          │
│ When an object changes its velocity at a constant rate,  │
│ it undergoes **Uniform Acceleration**. To solve for      │
│ final velocity, we look at the relationship between      │
│ initial speed, rate of change, and time elapsed.         │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│ **Main Formula: First Equation of Motion**               │
│                                                          │
│                 $$v = u + at$$                           │
│                                                          │
│ 💡 **Variable Breakdown:**                                │
│ • $v$: Final Velocity ($m/s$)                            │
│ • $u$: Initial Velocity ($m/s$)                          │
│ • $a$: Acceleration ($m/s^2$)                            │
│ • $t$: Time interval ($s$)                               │
│                                                          │
│ [ 🧪 Open Formula Lab ]                                  │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│ **Step-by-Step Calculation**                             │
│                                                          │
│ **1. Identify Given Values:**                            │
│ • Initial Velocity ($u$) = $0\,m/s$ (starts from rest)   │
│ • Acceleration ($a$) = $2\,m/s^2$                        │
│ • Time ($t$) = $10\,s$                                   │
│                                                          │
│ **2. Substitute into Formula:**                          │
│ $$v = 0 + (2 \times 10)$$                                │
│                                                          │
│ **3. Final Result:**                                     │
│ $$v = 20\,m/s$$                                          │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│ **Key Characteristics**                                  │
│                                                          │
│ • **Linear Growth:** The velocity increases by the same  │
│   amount ($2\,m/s$) every single second.                 │
│ • **Direction:** Since acceleration is positive, the car │
│   is speeding up in the direction of motion.             │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│ **Data Summary Table**                                   │
│                                                          │
│ | Parameter          | Symbol | Value    | Unit    |     │
│ |--------------------|--------|----------|---------|     │
│ | Initial Velocity   | $u$    | 0        | $m/s$   |     │
│ | Acceleration       | $a$    | 2        | $m/s^2$ |     │
│ | Time               | $t$    | 10       | $s$     |     │
│ | **Final Velocity** | $v$    | **20**   | $m/s$   |     │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│ **Suggested Questions**                                  │
│                                                          │
│ 1. How far did the car travel during these 10 seconds?   │
│ 2. If the car then brakes at $4\,m/s^2$, how long will   │
│    it take to stop?                                      │
└──────────────────────────────────────────────────────────┘
