┌───────────────────────────┐  
│ Quick Definition          │  
│                           │  
│ Pressure is defined as   │  
│ the force exerted per     │  
│ unit area on a surface.   │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ SI Unit                  │  
│                           │  
│ The SI unit of pressure   │  
│ is the Pascal (Pa), which  │  
│ is equivalent to one      │  
│ Newton per square meter   │  
│ (N/m²).                   │  
└───────────────────────────┘
