To derive the expression for the maximum height of a projectile, we will analyze the motion of the projectile under the influence of gravity. Here's a structured breakdown of the derivation:

┌───────────────────────────┐
│ Introduction              │
│                           │
│ When a projectile is launched, it follows a curved path due to the influence of gravity. The maximum height is reached when the vertical component of its velocity becomes zero. This section outlines how to derive the expression for the maximum height.  │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ - Initial velocity (\(v_0\))  │
│ - Angle of projection (\(\theta\)) │
│ - Acceleration due to gravity (\(g\)) │
│ - Maximum height (\(H\)) │
└───────────────────────────┘

┌───────────────────────────┐
│ Derivation Steps          │
│                           │
│ 1. **Resolve the initial velocity**:    │
│    The initial velocity can be resolved into horizontal and vertical components.  │
│    \[
│    v_{0y} = v_0 \sin(\theta) 
│    \]                          │
│    \[
│    v_{0x} = v_0 \cos(\theta) 
│    \]                          │
│                           │
│ 2. **Equation of motion**:   │
│    The maximum height is reached when the vertical component of velocity becomes zero. Using the equation of motion:  │
│    \[
│    v_{y}^2 = v_{0y}^2 - 2gH 
│    \]                          │
│    At maximum height, \(v_y = 0\), so:  │
│    \[
│    0 = (v_0 \sin(\theta))^2 - 2gH 
│    \]                          │
│                           │
│ 3. **Solve for H**:          │
│    Rearranging gives us:  │
│    \[
│    H = \frac{(v_0 \sin(\theta))^2}{2g} 
│    \]                          │
└───────────────────────────┘
