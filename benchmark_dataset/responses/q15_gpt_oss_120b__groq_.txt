┌─────────────────────────────┐
│          Introduction         │
│                               │
│ When a gun is fired, the      │
│ expanding gases push the      │
│ bullet forward. By Newton’s   │
│ third law, the gun experiences│
│ an equal‑and‑opposite reaction│
│ force, causing it to move     │
│ backward – this is the recoil.│
└─────────────────────────────┘

┌─────────────────────────────┐
│            Definition         │
│                               │
│ **Recoil** – the backward     │
│ motion of a firearm when      │
│ it discharges a projectile.  │
│ It is the result of the       │
│ action‑reaction pair described │
│ by Newton’s third law.        │
└─────────────────────────────┘

┌─────────────────────────────┐
│          Key Concepts         │
│                               │
│ • Action–reaction forces      │
│ • Conservation of momentum    │
│ • Mass‑velocity relationship   │
│ • Impulse transferred to gun  │
│ • Effects of barrel length    │
└─────────────────────────────┘

│        Important Notes        │
│                               │
│ • The recoil force equals the │
│   bullet’s momentum change   │
│   divided by the time of      │
│   acceleration.               │
│ • Heavier guns recoil less for│
│   the same bullet mass.        │
│ • Suppressors reduce muzzle   │
│   blast but not the recoil.   │
└─────────────────────────────┘

┌─────────────────────────────┐
│            Summary            │
│                               │
│ The gun’s recoil is a direct  │
│ manifestation of Newton’s     │
│ third law: the forward push on │
│ the bullet generates an equal │
│ backward push on the gun.     │
│ Momentum conservation links   │
│ bullet and gun velocities via │
│  m_b v_b = m_g v_g. This       │
│ relationship guides firearm   │
│ design and shooter technique. │
