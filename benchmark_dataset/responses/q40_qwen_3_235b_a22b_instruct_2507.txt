┌───────────────────────────┐  
│ **Quick Definition**      │  
│                           │  
│ **Transverse waves**:     │  
│ Particles of the medium   │  
│ vibrate perpendicular to  │  
│ the direction of wave     │  
│ propagation.              │  
│                           │  
│ **Longitudinal waves**:   │  
│ Particles vibrate parallel│  
│ (along) the direction of  │  
│ wave propagation.         │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Key Characteristics**   │  
│                           │  
│ **Transverse Waves**:     │  
│ - Crests and troughs      │  
│ - Can travel through      │  
│   solids and on surfaces  │  
│   of liquids              │  
│ - Examples: light, ripples│  
│   on water, guitar strings│  
│                           │  
│ **Longitudinal Waves**:   │  
│ - Compressions and        │  
│   rarefactions            │  
│ - Can travel through      │  
│   solids, liquids, and    │  
│   gases                   │  
│ - Examples: sound waves,  │  
│   seismic P-waves          │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Visual Representation** │  
│                           │  
│ **Transverse Wave**:       │  
│     ʌ                     │  
│     |  crest               │  
│ <--→→→→→→→→→→→→→→→→→→→→→→→→ │  
│     |  trough              │  
│     ∨                     │

│   C  R  C  R  C  R         │

│   →→→→→→→→→→→→→→→→→→→       │  
│   Compression (C)         │  
│   Rarefaction (R)         │  
│   Direction of wave &     │  
│   particle motion →       │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Wave Motion Comparison**│  
│                           │
│ | Property               | Transverse        | Longitudinal         |  
│ |------------------------|-------------------|-----------------------|  
│ | **Direction of**       | Perpendicular     | Parallel              |  
│ | **vibration**          | to wave direction | to wave direction     |  
│ | **Wave features**      | Crests, troughs   | Compressions,         |  
│ |                        |                   | rarefactions          |  
│ | **Medium required?**   | Solid or surface  | Solid, liquid, gas    |  
│ | **Polarization**       | Possible          | Not possible          |  
│ | **Example**            | Light (EM wave)   | Sound in air          |  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Important Notes**       │  
│                           │  
│ ✅ **Transverse waves**    │  
│ - Electromagnetic waves   │  
│   (like light) are        │  
│   transverse and do **not**│  
│   require a medium.        │  
│                           │  
│ ❌ **Longitudinal waves**  │  
│ - Cannot be polarized      │  
│   because vibrations are  │  
│   along the direction of  │  
│   propagation.            │  
│                           │  
│ 🌍 **In earthquakes**:    │  
│ - P-waves = Longitudinal  │  
│ - S-waves = Transverse    │  
└───────────────────────────┘  

---

┌───────────────────────────┐  
│ **Summary**               │  
│                           │  
│ **Transverse waves** move │  
│ side-to-side relative to  │  
│ their direction of travel,│  
│ forming peaks and valleys.│  
│                           │  
│ **Longitudinal waves**    │  
│ push and pull in the same │  
│ direction they travel,    │  
│ creating dense and sparse │  
│ regions.                  │  
│                           │  
│ The key difference is the │  
│ **direction of particle  │  
│ oscillation** relative to │  
│ wave motion.              │  
└───────────────────────────┘
