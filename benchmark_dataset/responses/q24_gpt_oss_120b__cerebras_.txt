┌───────────────────────────────────────┐  
│ **Introduction**                       │  
│                                       │  
│ Determine the gravitational force that │  
│ acts between two identical masses of   │  
│ 5 kg each when they are 2 m apart.      │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Formula**                             │  
│                                         │  
│      **Newton’s Law of Gravitation**    │  
│                                         │  
│   $$\displaystyle F = G\frac{m_1 m_2}{r^{2}}$$   │  
│                                         │  
│   [ Explain Formula ]   [ Open Formula Lab ] │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Input Parameters**                    │  
│───────────────────────────────────────│  
│ **Symbol** │ **Value**                  │  
│------------│---------------------------│  
│ $m_1$      │ 5 kg                      │  
│ $m_2$      │ 5 kg                      │  
│ $r$        │ 2 m                       │  
│ $G$        │ $6.674\times10^{-11}\,$N·m²·kg⁻² │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Calculation**                         │  
│                                         │  
│ 1️⃣ Insert the numbers into the formula:│  
│ $$F = 6.674\times10^{-11}\frac{(5)(5)}{(2)^{2}}$$ │  
│                                         │  
│ 2️⃣ Compute the numerator:               │  
│ $(5)(5)=25$                              │  
│                                         │  
│ 3️⃣ Compute the denominator:             │  
│ $(2)^{2}=4$                              │  
│                                         │  
│ 4️⃣ Combine: $$F = 6.674\times10^{-11}\frac{25}{4}$$ │  
│                                         │  
│ 5️⃣ Simplify: $$\frac{25}{4}=6.25$$      │  
│                                         │  
│ 6️⃣ Final multiplication: $$F = 6.674\times10^{-11}\times6.25$$ │  
│                                         │  
│ 7️⃣ Result: $$F \approx 4.17\times10^{-10}\ \text{N}$$ │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Result**                              │  
│                                         │  
│ The gravitational attraction between   │  
│ the two 5 kg masses separated by 2 m is │  
│ **≈ 4.2 × 10⁻¹⁰ N** (to two‑significant‑figures). │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│ **Summary**                             │  
│                                         │  
│ • Newton’s law relates mass, distance, │  
│   and the universal constant $G$.       │  
│ • Even modest masses generate extremely │  
│   tiny forces when the separation is not │  
│   astronomically small.                 │  
│ • The computed force is on the order of │  
│   $10^{-10}$ N, essentially negligible │  
│   for everyday mechanical interactions.│  
└───────────────────────────────────────┘
