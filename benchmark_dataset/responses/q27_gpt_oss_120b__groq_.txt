│ **Definition**                                 │  
│                                               │  
│ *Pascal’s law* (also called the *law of pressure*) │  
│ states that **any change in pressure applied   │  
│ to an incompressible, confined fluid is transmitted │  
│ undiminished in all directions throughout the fluid**. │  
│                                               │  
│ In other words, a pressure increase at any point │  
│ in a closed fluid produces an equal pressure     │  
│ increase everywhere else in the fluid.          │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Main Formula**                               │  
│                                               │  
│          **\( P = \dfrac{F}{A} \)**           │  
│                                               │  
│ *Explain Formula* – Pressure (**\(P\)**) is the │  
│ force (**\(F\)**) applied per unit area (**\(A\)**). │  
│ Because the fluid transmits pressure uniformly, │  
│ the same **\(P\)** is felt at every point in the │  
│ container.                                    │  
│                                               │  
│ *Open Formula Lab* – Experiment with different │  
│ forces and areas to see how the pressure changes│  
│ and how the law holds in hydraulic systems.   │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Applications**                               │  
│                                               │  
│ 1. **Hydraulic Presses** – Small force applied │  
│    on a small piston creates a large force on │  
│    a larger piston, enabling metal shaping,   │  
│    car lifts, etc.                            │  
│                                               │  
│ 2. **Braking Systems** – Hydraulic brakes   │  
│    in cars and bicycles use fluid to transmit │  
│    pedal force equally to all brake pads.    │  
│                                               │  
│ 3. **Aircraft Flight Controls** – Push‑rods   │  
│    and hydraulic actuators move flaps and    │  
│    elevators with minimal pilot effort.      │  
│                                               │  
│ 4. **Dentistry & Medicine** – Dental drills, │  
│    blood pressure cuffs, and IV infusion     │  
│    pumps rely on pressure transmission.      │  
│                                               │  
│ 5. **Water Supply & Irrigation** – Water │  
│    distribution networks use the principle to │  
│    maintain uniform pressure across long pipes.│  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Summary**                                    │  
│                                               │  
│ • Pascal’s law: pressure change in a confined │  
│   incompressible fluid is transmitted equally │  
│   in all directions.                          │  
│ • Core formula: \( P = \frac{F}{A} \).          │  
│ • Enables devices that multiply force, such as│  
│   hydraulic presses, brakes, aircraft controls│  
│   and many everyday fluid‑power systems.      │  
└───────────────────────────────────────────────┘
