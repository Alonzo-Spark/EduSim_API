┌───────────────────────────────────────────────┐
│ Introduction                                   │
│                                               │
│ Latent heat is a fundamental concept in      │
│ thermodynamics that describes the amount of    │
│ energy required for a substance to change its │
│ phase without a change in temperature.        │
│ Understanding latent heat helps explain       │
│ processes such as melting, boiling, and       │
│ sublimation—key phenomena in physics,         │
│ chemistry, and engineering.                   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Definition                                     │
│                                               │
│ **Latent heat** is the heat energy absorbed   │
│ or released by a material during a change of   │
│ state (phase transition) at constant           │
│ temperature and pressure.                     │
│ It is “latent” because the energy does not      │
│ appear as a temperature change; instead, it   │
│ is used to break or form intermolecular bonds. │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Key Concepts                                   │
│                                               │
│ • **Latent heat of fusion** – energy needed to │
│   melt a solid into a liquid (e.g., ice →      │
│   water).                                      │
│ • **Latent heat of vaporisation** – energy     │
│   required to turn a liquid into a gas (e.g., │
│   water → steam).                              │
│ • **Latent heat of sublimation** – energy      │
│   for a solid → gas transition (e.g., dry ice │
│   → CO₂ gas).                                   │
│ • The amount of heat absorbed or released is   │
│   proportional to the mass undergoing the      │
│   phase change.                                │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Change of State                                 │
│                                               │
│ During a phase change, the temperature of the │
│ substance remains constant while the supplied │
│ heat is used to overcome molecular forces:     │
│                                               │
│ 1. **Solid → Liquid (melting)** – heat breaks   │
│    the rigid lattice, allowing molecules to     │
│    move more freely.                           │
│ 2. **Liquid → Gas (boiling/evaporation)** –    │
│    heat separates molecules completely,        │
│    creating vapor.                             │
│ 3. **Solid → Gas (sublimation)** – direct      │
│    transition without passing through the       │
│    liquid phase.                               │
│                                               │
│ In each case, the energy supplied (or released)│
│ is the latent heat.                             │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Main Formula                                    │
│                                               │
│          Q = m L                               │
│                                               │
│ [ Explain Formula ]                            │
│ [ Open Formula Lab ]                           │
└───────────────────────────────────────────────┘

*Explanation of variables*  
- **Q** : Heat energy transferred (Joules)  
- **m** : Mass of the substance undergoing the phase change (kg)  
- **L** : Specific latent heat (J kg⁻¹) – differs for fusion, vaporisation, etc.

┌───────────────────────────────────────────────┐
│ Applications                                   │
│                                               │
│ • **Weather & climate** – formation of clouds  │
│   (latent heat of vaporisation) and ice       │
│   melting.                                     │
│ • **Refrigeration & air‑conditioning** – uses │
│   evaporative cooling (latent heat of          │
│   vaporisation).                               │
│ • **Industrial processes** – steel melting,   │
│   glass production, and drying of materials. │
│ • **Energy storage** – phase‑change materials │
│   (PCM) that store/release heat during phase    │
│   transitions.                                 │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Important Notes                                 │
│                                               │
│ • The temperature stays constant **only**      │
│   during the phase change; before and after    │
│   it, temperature can change.                 │
│ • Latent heat values are material‑specific and │
│   must be looked up in tables.                │
│ • Heat transfer can be **endothermic** (absor │
│   ber) or **exothermic** (release).            │
│ • In real‑world systems, heat losses and       │
│   non‑ideal conditions can alter the simple    │
│   Q = m L relationship.                       │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Summary                                        │
│                                               │
│ Latent heat quantifies the energy required for │
│ a substance to change its phase while          │
│ maintaining constant temperature. The         │
│ governing equation Q = m L links the heat      │
│ transferred to the mass and the specific       │
│ latent heat of the material. This concept      │
│ underpins many natural and engineered processes│
│ ranging from weather phenomena to cooling      │
│ technologies.                                  │
└───────────────────────────────────────────────┘
