┌───────────────────────────┐
│ Problem Statement         │
│                           │
│ A train moving at 20 m/s  │
│ applies brakes and stops  │
│ after 10 seconds.         │
│ Calculate retardation.    │
└───────────────────────────┘

┌───────────────────────────┐
│ Given Data                │
│                           │
• Initial Velocity (u)      │
  = 20 m/s                  │
                           │
• Final Velocity (v)        │
  = 0 m/s                   │
  (Since the train stops)   │
                           │
• Time (t)                 │
  = 10 s                    │
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula              │
│                           │
│   $$a = \frac{v - u}{t}$$ │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

┌───────────────────────────┐
│ Calculation               │
│                           │
│ Substitute the known      │
│ values into the formula:  │
│                           │
│ $$a = \frac{0 - 20}{10}$$ │
│                           │
│ $$a = \frac{-20}{10}$$    │
│                           │
│ $$a = -2 \, \text{m/s}^2$$│
└───────────────────────────┘

┌───────────────────────────┐
│ Result                    │
│                           │
│ The acceleration is       │
│ -2 m/s².                  │
│                           │
│ Since the acceleration is │
│ opposite to the direction │
│ of motion, it is called   │
│ retardation.              │
│                           │
│ **Retardation = 2 m/s²**  │
└───────────────────────────┘
