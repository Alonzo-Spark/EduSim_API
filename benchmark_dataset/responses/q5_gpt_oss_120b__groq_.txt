┌───────────────────────────────┐  
│ Introduction                     │  
│                                   │  
│ A train is travelling at a constant  │  
│ speed of **20 m s⁻¹**. The driver     │  
│ applies the brakes and brings the   │  
│ train to a complete stop in **10 s**. │  
│ We need to determine the constant   │  
│ **retardation** (negative acceleration) │  
│ that produces this motion.          │  
└───────────────────────────────┘  

┌───────────────────────────────┐  
│ Given Data                       │  
│                                   │  
│ • Initial speed,  u = 20 m s⁻¹     │  
│ • Final speed,    v = 0 m s⁻¹      │  
│ • Time,           t = 10 s        │  
└───────────────────────────────┘  

┌───────────────────────────────┐  
│ Main Formula                     │  
│                                   │  
│          a = \frac{v - u}{t}      │  
│                                   │  
│ [ Explain Formula ]               │  
│ [ Open Formula Lab ]               │  
└───────────────────────────────┘  

┌───────────────────────────────┐  
│ Calculation Steps                │  
│                                   │  
│ 1️⃣ Insert the known values:      │  
│    a = (0 m s⁻¹ − 20 m s⁻¹) / 10 s   │  
│                                   │  
│ 2️⃣ Perform the subtraction:      │  
│    a = (‑20 m s⁻¹) / 10 s          │  
│                                   │  
│ 3️⃣ Divide:                        │  
│    a = ‑2 m s⁻²                  │  
│                                   │  
│ The negative sign indicates that │  
│ the acceleration is opposite to   │  
│ the direction of motion – i.e., a  │  
│ **retardation**.                  │  
└───────────────────────────────┘  

┌───────────────────────────────┐  
│ Answer                           │  
│                                   │  
│ The train’s retardation is **‑2 m s⁻²**. │  
│ (Magnitude = 2 m s⁻², direction opposite to motion) │  
└───────────────────────────────┘  

┌───────────────────────────────┐  
│ Summary                          │  
│                                   │  
│ • Use the linear motion equation   │  
│   \(a = (v-u)/t\) when initial and │  
│   final speeds and time are known. │  
│ • Plugging the train’s data gives │  
│   a = ‑2 m s⁻², meaning the train   │  
│   decelerates at 2 m s⁻².          │  
└───────────────────────────────┘
