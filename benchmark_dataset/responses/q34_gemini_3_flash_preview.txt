### 📘 TOPIC: THERMAL EXPANSION IN SOLIDS

┌──────────────────────────────────────────────────────────────────────────┐
│ **Introduction**                                                         │
│                                                                          │
│ Thermal expansion is the tendency of matter to change its shape, area,    │
│ and volume in response to a change in temperature. In a metal rod, this  │
│ manifest primarily as an increase in length.                             │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Kinetic Mechanism (The "Why")**                                        │
│                                                                          │
│ 1. **Atomic Vibration:** Atoms in a metal rod are held by spring-like     │
│    interatomic forces.                                                   │
│ 2. **Energy Gain:** As heat is applied, atoms gain kinetic energy and    │
│    vibrate with greater amplitude.                                       │
│ 3. **Asymmetric Potential:** Because the potential energy well is        │
│    asymmetrical, atoms push further apart than they pull together,       │
│    increasing the average distance between them.                         │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Main Formula: Linear Expansion**                                       │
│                                                                          │
│ $$\Delta L = \alpha L_0 \Delta T$$                                       │
│                                                                          │
│ **Variable Key:**                                                        │
│ • $\Delta L$: Change in length (Expansion)                               │
│ • $L_0$: Original length of the rod                                      │
│ • $\alpha$: Coefficient of linear expansion (Material specific)          │
│ • $\Delta T$: Change in temperature                                      │
│                                                                          │

└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Characteristics of Expansion**                                         │
│                                                                          │
│ | Property | Description |                                               │
│ | :--- | :--- |                                                          │
│ | **Material Dependence** | Different metals (e.g., Copper vs Steel)      │
│ | | expand at different rates for the same heat. |                       │
│ | **Reversibility** | Expansion is typically reversible; the rod |        │
│ | | contracts to its original size upon cooling. |                       │
│ | **Directionality** | In a thin rod, expansion is most noticeable |     │
│ | | along the longitudinal axis. |                                       │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Applications & Engineering**                                           │
│                                                                          │
│ • **Railway Tracks:** Small gaps are left between rails to allow for     │
│   expansion during summer, preventing buckling.                          │
│ • **Bimetallic Strips:** Two different metals bonded together bend when  │
│   heated, used as switches in thermostats.                               │
│ • **Riveting:** Hot rivets are inserted into holes; they contract as     │
│   they cool, pulling the metal plates tightly together.                  │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Important Notes**                                                      │
│                                                                          │
│ ⚠️ **Internal Stress:** If a metal rod is heated but its ends are fixed  │
│ (preventing expansion), it will develop immense internal thermal stress  │
│ which can lead to structural failure.                                    │
└──────────────────────────────────────────────────────────────────────────┘
