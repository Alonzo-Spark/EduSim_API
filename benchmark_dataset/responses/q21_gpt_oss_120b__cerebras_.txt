┌───────────────────────────────────────────────────────────────┐
│ Introduction                                                    │
│                                                                   │
│ Gravitation is a fundamental interaction that causes any two   │
│ masses to attract each other. It governs the motion of planets,│
│ moons, satellites, and everyday objects on Earth.               │
└───────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ Main Formula                                                    │
│                                                                   │
│                 $$F = G \frac{m_1 m_2}{r^2}$$                    │
│                                                                   │
│ [ Explain Formula ]    [ Open Formula Lab ]                     │
└───────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ Explanation of Variables                                         │
│                                                                   │
│ • **F** – Gravitational force between the two masses (Newtons)  │
│ • **G** – Universal gravitational constant ≈ 6.674×10⁻¹¹ N·m²/kg²│
│ • **m₁**, **m₂** – Masses of the interacting objects (kilograms) │
│ • **r** – Distance between the centers of the two masses (meters)│
│                                                                   │
│ The force grows with larger masses and diminishes with the      │
│ square of the separation distance.                               │
└───────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ Applications                                                    │
│                                                                   │
│ • Predicting planetary orbits (Kepler’s laws)                    │
│ • Calculating satellite trajectories and launch windows          │
│ • Determining tidal forces on Earth and other celestial bodies   │
│ • Estimating the weight of objects on different planets          │
└───────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ Summary                                                          │
│                                                                   │
│ Newton’s law of gravitation quantifies the attractive force      │
│ between any two masses as a product of their masses divided by   │
│ the square of the distance between them, scaled by the constant  │
│ **G**. It is essential for understanding orbital mechanics,      │
│ astrophysics, and everyday phenomena like falling objects.       │
└───────────────────────────────────────────────────────────────────┘
