┌─────────────────────────────┐
│ Introduction                │
│                             │
│ Bernoulli’s theorem is a    │
│ fundamental principle in     │
│ fluid dynamics that describes │
│ the behavior of fluid flow.  │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Quick Definition            │
│                             │
│ Bernoulli's theorem states   │
│ that an increase in the     │
│ speed of a fluid occurs at  │
│ the expense of its pressure  │
│ or potential energy.         │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Key Concepts                │
│                             │
│ 1. **Fluid Dynamics**: The   │
│    study of fluids (liquids  │
│    and gases) in motion.     │
│ 2. **Conservation of Energy**:│
│    Energy in a fluid system   │
│    is conserved.              │
│ 3. **Pressure Variation**:    │
│    Pressure decreases when    │
│    the fluid velocity increases. │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Main Formula                │
│                             │
│     Rendered Formula        │
│                             │
│ $$ P + \frac{1}{2} \rho v^2 + \rho gh = \text{constant} $$ │
│                             │
│ [ Explain Formula ]         │
│ [ Open Formula Lab ]        │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Applications                │
│                             │
│ 1. **Aviation**: Explains how│
│    airplane wings generate   │
│    lift.                     │
│ 2. **Hydraulics**: Used in  │
│    designing pipes and pumps.│
│ 3. **Venturi Effect**: Applied│
│    in carburetors and atomizers.│
└─────────────────────────────┘

┌─────────────────────────────┐
│ Advantages                  │
│                             │
│ - Helps in predicting fluid  │
│   behavior in various systems.│
│ - Essential for engineering  │
│   applications in aerodynamics  │
│   and hydraulics.           │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Disadvantages               │
│                             │
│ - Assumes incompressible and │
│   non-viscous fluids, which  │
│   may not be realistic in all │
│   scenarios.                │
│ - Does not account for       │
│   turbulence in fluid flow.  │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Important Notes             │
│                             │
│ - Bernoulli's theorem is    │
│   derived from the principle │
│   of conservation of energy. │
│ - It is applicable in steady,│
│   incompressible, and non-viscous│
│   flow conditions.          │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Summary                     │
│                             │
│ Bernoulli’s theorem is a    │
│ crucial concept in fluid     │
│ dynamics, explaining how      │
│ fluid speed and pressure are  │
│ related. Its applications span │
│ various fields, from aviation  │
│ to hydraulics, although it has │
│ limitations in real-world     │
│ scenarios.                   │
└─────────────────────────────┘
