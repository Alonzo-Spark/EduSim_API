┌───────────────────────────┐  
│ Introduction               │  
│                           │  
│ A force of 50 N acts on a │  
│ body of mass 10 kg. Find  │  
│ the acceleration.         │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Definition                 │  
│                           │  
│ • **Force (F)** – a push   │  
│   or pull measured in new │  
│   tons (N).                 │  
│ • **Mass (m)** – amount of │  
│   matter, measured in kg.  │  
│ • **Acceleration (a)** –  │  
│   rate of change of speed, │  
│   measured in m·s⁻².        │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Key Concepts               │  
│                           │  
│ Newton’s Second Law states │  
│ that the net force on an    │  
│ object equals its mass times│  
│ the acceleration it acquires│  
│ ( F = m a ).                │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Main Formula               │  
│                           │  
│   F = m a                 │  
│                           │  
│ [ Explain Formula ]       │  
│ [ Open Formula Lab ]      │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Calculation                │  
│                           │  
│ Given: F = 50 N, m = 10 kg │  
│ → a = F / m = 50 N / 10 kg │  
│ = 5 m·s⁻²                 │  
│                           │  
│ The body accelerates at   │  
│ **5 m·s⁻²**.               │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Important Notes            │  
│                           │  
│ • Ensure units are consistent│  
│   (N, kg, m·s⁻²).          │  
│ • 1 N = 1 kg·m·s⁻².         │  
│ • Acceleration is a vector│  
│   (direction matters).    │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Summary                    │  
│                           │  
│ Using Newton’s second law,│  
│ the acceleration is found│  
│ by dividing the applied    │  
│ force by the mass: a = F/m │  
│ → a = 5 m·s⁻² for this case.│  
└───────────────────────────┘
