┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Retardation (or deceleration) is the negative acceleration of an object, meaning it's slowing down. │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ *   **Initial Velocity (u):** The velocity at the start of the braking.
│ *   **Final Velocity (v):** The velocity at the end of the braking (when the train stops).
│ *   **Time (t):** The duration over which the braking occurs.
│ *   **Acceleration (a):** The rate of change of velocity.  Retardation is a specific case of acceleration.
│                           │
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula              │
│                           │
│     $$v = u + at$$       │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

┌───────────────────────────┐
│ Formula Explanation       │
│                           │
│ This formula relates the final velocity (v), initial velocity (u), acceleration (a), and time (t).  It's derived from the definition of acceleration.  We can rearrange it to solve for acceleration.
│                           │
└───────────────────────────┘

┌───────────────────────────┐
│ Problem Data            │
│                           │
│ *   Initial Velocity (u) = 20 m/s
│ *   Final Velocity (v) = 0 m/s (since the train stops)
│ *   Time (t) = 10 s
│                           │
└───────────────────────────┘

┌───────────────────────────┐
│ Calculation               │
│                           │
│ 1.  **Rearrange the formula:**  To find acceleration (a), we rearrange the formula:
│     $$a = \frac{v - u}{t}$$
│
│ 2.  **Substitute the values:**
│     $$a = \frac{0 \text{ m/s} - 20 \text{ m/s}}{10 \text{ s}}$$
│
│ 3.  **Calculate:**
│     $$a = -2 \text{ m/s}^2$$
│                           │
└───────────────────────────┘

┌───────────────────────────┐
│ Answer                    │
│                           │
│ The retardation (deceleration) of the train is 2 m/s². The negative sign indicates that the acceleration is in the opposite direction to the initial motion, meaning the train is slowing down.
│                           │
└───────────────────────────┘
