┌───────────────────────────┐
│ Introduction              │
│                           │
│ Archimedes’ principle states that any object fully or         │
│ partially submerged in a fluid experiences an upward         │
│ buoyant force equal to the weight of the fluid displaced     │
│ by the object. This principle helps explain why objects      │
│ float or sink in liquids.                                   │
└───────────────────────────┘

┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ The buoyant force on an   │
│ object is equal to the    │
│ weight of the fluid it    │
│ displaces.                │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ - Buoyant Force: The      │
│   upward force acting on   │
│   an object submerged in   │
│   a fluid.                │
│ - Displacement: The volume │
│   of fluid that is moved   │
│   out of the way by the    │
│   submerged object.        │
└───────────────────────────┘

┌───────────────────────────┐
│ Example                   │
│                           │
│ Consider a wooden block   │
│ with a volume of 0.5 m³   │
│ submerged in water. The    │
│ weight of the water       │
│ displaced by the block    │
│ can be calculated using    │
│ the formula:              │
│                           │
│ Volume of water displaced  │
│ = Volume of block = 0.5 m³ │
│                           │
│ Weight of water displaced  │
│ = Volume × Density         │
│ = 0.5 m³ × 1000 kg/m³     │
│ = 500 kg                  │
│                           │
│ Thus, the buoyant force    │
│ acting on the block is    │
│ equal to the weight of     │
│ the displaced water,       │
│ which is 500 kg.          │
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula              │
│                           │
│     Rendered Formula      │
│                           │
│ $$ F_b = \rho \cdot g \cdot V $$ │
│                           │
│ Where:                   │
│ - \( F_b \) is the buoyant force  │
│ - \( \rho \) is the density of the fluid │
│ - \( g \) is the acceleration due to gravity │
│ - \( V \) is the volume of fluid displaced │
│                           │

┌───────────────────────────┐
│ Applications              │
│                           │
│ Archimedes’ principle is   │
│ used in various fields     │
│ including:                │
│ - Shipbuilding: To ensure  │
│   vessels are buoyant.     │
│ - Hydrometry: To measure   │
│   fluid densities.         │
│ - Design of submarines:    │
│   To manage buoyancy and    │
│   stability.               │
└───────────────────────────┘

┌───────────────────────────┐
│ Advantages                │
│                           │
│ - Helps in understanding    │
│   fluid mechanics.         │
│ - Provides a basis for      │
│   designing floating        │
│   structures.              │
└───────────────────────────┘

┌───────────────────────────┐
│ Disadvantages             │
│                           │
│ - Only applies to fluids    │
│   at rest.                 │
│ - Not applicable for       │
│   non-homogeneous fluids.  │
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes           │
│                           │
│ - The principle holds true  │
│   regardless of the shape   │
│   or density of the object. │
│ - Temperature and pressure   │
│   can affect fluid density.  │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                   │
│                           │
│ Archimedes’ principle     │
│ explains the behavior of   │
│ objects in fluids,         │
│ emphasizing the balance    │
│ between gravitational and   │
│ buoyant forces. It has     │
│ wide-ranging applications   │
│ in science and engineering. │
└───────────────────────────┘
