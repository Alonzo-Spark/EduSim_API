│ Quick Definition          │
│                           │
│ Work is done when a force │
│ causes displacement of an│
│ object.                   │
└───────────────────────────┘

---

┌───────────────────────────┐
│ Main Formula              │
│                           │
│  $$W = F \cdot d \cdot cos(\theta)$$ │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

---

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ *   **Force (F):** The    │
│     push or pull acting   │
│     on the object.        │
│ *   **Displacement (d):** │
│     The distance the      │
│     object moves in the   │
│     direction of the      │
│     force.                │
│ *   **Angle (θ):** The    │
│     angle between the     │
│     force vector and the  │
│     displacement vector.  │
│                           │
└───────────────────────────┘

---

│                           │
