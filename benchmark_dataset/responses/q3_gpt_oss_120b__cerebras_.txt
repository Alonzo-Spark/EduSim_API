┌───────────────────────────────────────────────┐
│ Introduction                                    │
│                                               │
│ Understanding motion is fundamental in      │
│ physics and everyday life. Two terms that    │
│ often cause confusion are **distance** and   │
│ **displacement**. Though they sound similar, │
│ they describe very different concepts.       │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Definition                                      │
│                                               │
│ **Distance** – the total length of the path   │
│ travelled by an object, regardless of direction.│
│ It is a *scalar* quantity (only magnitude).   │
│                                               │
│ **Displacement** – the straight‑line distance │
│ from the starting point to the ending point, │
│ together with the direction of that line.     │
│ It is a *vector* quantity (magnitude + direction).│
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Key Concepts                                    │
│                                               │
│ • **Scalar vs. Vector**                        │
│   - Scalars have only magnitude (e.g., distance).│
│   - Vectors have magnitude and direction (e.g., displacement).│
│                                               │
│ • **Path Dependence**                           │
│   - Distance depends on the actual route taken.│
│   - Displacement depends only on the initial   │
│     and final positions.                       │
│                                               │
│ • **Units**                                     │
│   - Both are measured in meters (m) in SI, but│
│     displacement may be expressed with a       │
│     directional qualifier (e.g., 5 m north).   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Examples                                        │
│                                               │
│ 1️⃣ **Straight‑Line Motion**                    │
│    - A car travels 100 m east along a straight   │
│      road.                                      │
│    - Distance = 100 m (the road length).       │
│    - Displacement = 100 m east (straight line).│
│                                               │
│ 2️⃣ **Triangular Path**                         │
│    - A person walks 30 m north, then 40 m east.│
│    - Distance = 30 m + 40 m = 70 m (total path).│
│    - Displacement = √(30² + 40²) = 50 m northeast│
│      (the straight line from start to finish). │
│                                               │
│ 3️⃣ **Round‑Trip**                              │
│    - A runner jogs 200 m around a 50‑m circular│
│      track, returning to the start point.      │
│    - Distance = 200 m (total ground covered). │
│    - Displacement = 0 m (no change in position).│
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Comparison Table                                 │
│                                               │
│ ┌─────────────────────┬─────────────────────┐ │
│ │ Property            │ Distance            │ │
│ ├─────────────────────┼─────────────────────┤ │
│ │ Type                │ Scalar              │ │
│ │ Depends on          │ Entire path travelled│ │
│ │ Direction needed?  │ No                  │ │
│ │ Example (above)    │ 70 m (30 m N + 40 m E)│ │
│ └─────────────────────┴─────────────────────┘ │
│ ┌─────────────────────┬─────────────────────┐ │
│ │ Property            │ Displacement        │ │
│ ├─────────────────────┼─────────────────────┤ │
│ │ Type                │ Vector              │ │
│ │ Depends on          │ Start & end points │ │
│ │ Direction needed?  │ Yes                 │ │
│ │ Example (above)    │ 50 m northeast      │ │
│ └─────────────────────┴─────────────────────┘ │
│                                               │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Summary                                         │
│                                               │
│ • **Distance** = total ground covered, a scalar│
│   that ignores direction.                     │
│ • **Displacement** = straight‑line change in   │
│   position, a vector that includes direction.│
│ • The two quantities are equal only when the  │
│   motion is along a straight line without any  │
│   turns.                                       │
│                                               │
│ Remember: *“How far did you go?”* → distance. │
│ *“Where are you now relative to where you started?”* │
│ → displacement.                               │
└───────────────────────────────────────────────┘
