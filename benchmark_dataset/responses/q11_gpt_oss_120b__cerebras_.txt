┌───────────────────────────────────────────────┐
│               Introduction                      │
│                                                   │
│ Sir Isaac Newton (1643‑1727) formulated three    │
│ fundamental principles that describe how         │
│ objects move and interact. These “Laws of Motion”│
│ are the cornerstone of classical mechanics and    │
│ underpin everything from everyday everyday       │
│ phenomena to engineering designs.                │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│                Definition                        │
│                                                   │
│ **First Law – Law of Inertia**                    │
│ An object at rest stays at rest, and an object    │
│ in motion continues in a straight line at constant│
│ speed unless acted upon by a net external force. │
│                                                   │
│ **Second Law – Law of Acceleration**             │
│ The acceleration of an object is directly         │
│ proportional to the net force acting on it and   │
│ inversely proportional to its mass.               │
│                                                   │
│ **Third Law – Action–Reaction**                  │
│ For every action there is an equal and opposite   │
│ reaction.                                         │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│                Key Concepts                      │
│                                                   │
│ 1️⃣ **First Law – Inertia**                       │
│    • No net force → no change in motion           │
│                                                   │
│ 2️⃣ **Second Law – F = ma**                       │
│    • Force equals mass times acceleration         │
│                                                   │
│ 3️⃣ **Third Law – Action & Reaction**             │
│    • Forces always occur in pairs                │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│                Formula Card                      │
│                                                   │
│          **Main Formula**                        │
│                                                   │
│          $$F = ma$$                               │
│                                                   │
│  • **F** – Net force (newtons, N)                │
│  • **m** – Mass of the object (kilograms, kg)    │
│  • **a** – Acceleration (meters per second², m/s²)│

┌───────────────────────────────────────────────┐
│                Examples                          │
│                                                   │
│ **First Law**                                     │
│ • A book resting on a table remains at rest       │
│   because the forces (gravity & table support)   │
│   cancel out.                                      │
│ • A hockey puck slides on ice and keeps moving    │
│   until friction (net force) slows it.           │
│                                                   │
│ **Second Law**                                    │
│ • Pushing a shopping cart: a larger push (greater│
│   force) makes it accelerate faster.             │
│ • A massive truck needs more force to achieve the│
│   same acceleration as a small car.              │
│                                                   │
│ **Third Law**                                     │
│ • When you jump, your legs exert a force on the   │
│   ground, and the ground exerts an equal opposite│
│   force that propels you upward.                  │
│ • A rocket expels gas backward; the gas pushes   │
│   the rocket forward.                             │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│                Applications                      │
│                                                   │
│ • **Vehicle safety** – seat belts and airbags     │
│   rely on inertia (first law) to protect passengers│
│ • **Engineering** – designing brakes, engines,    │
│   and elevators uses F = ma (second law)          │
│ • **Spaceflight** – rockets’ thrust follows the   │
│   action‑reaction principle (third law)           │
│ • **Sports** – understanding force and motion      │
│   improves performance (e.g., batting, swimming)│
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│                Summary                           │
│                                                   │
│ • **First Law** – Objects resist changes in motion│
│ • **Second Law** – Force, mass, and acceleration   │
│   are linked by **F = ma**                         │
│ • **Third Law** – Forces always come in equal      │
│   and opposite pairs                               │
│ • These laws together explain everyday motion and │
│   underpin countless technological advances.      │
