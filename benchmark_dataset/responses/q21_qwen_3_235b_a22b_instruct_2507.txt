┌─────────────────────────────────────────────────────┐
│           **Newton's Law of Gravitation**           │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **Quick Definition**                                │
│                                                     │
│ Newton’s Law of Gravitation states that every       │
│ mass in the universe attracts every other mass      │
│ with a force that is directly proportional to the   │
│ product of their masses and inversely proportional  │
│ to the square of the distance between their centers.│
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **Main Formula**                                    │
│                                                     │
│ $$ F = G \frac{m_1 m_2}{r^2} $$                     │
│                                                     │
│ [ Explain Formula ]    [ Open Formula Lab ]         │
└─────────────────────────────────────────────────────┘

**Where:**  
- $ F $ = Gravitational force between two objects (in newtons, N)  
- $ G $ = Universal gravitational constant $ \approx 6.674 \times 10^{-11} \, \text{N·m}^2/\text{kg}^2 $  
- $ m_1, m_2 $ = Masses of the two objects (in kilograms, kg)  
- $ r $ = Distance between the centers of the masses (in meters, m)

┌─────────────────────────────────────────────────────┐
│ **Key Concepts**                                    │
│                                                     │
│ • Applies to **all objects with mass**              │
│ • Force acts along the line joining the centers     │
│ • Always **attractive**, never repulsive            │
│ • Follows the **inverse-square law**               │
│ • Explains planetary motion and tides               │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **Characteristics**                                 │
│                                                     │
│ • Conservative force                                │
│ • Central force                                     │
│ • Long-range interaction                            │
│ • Weakest of the four fundamental forces            │
│ • Acts even at infinite distance (theoretically)    │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **Applications**                                    │
│                                                     │
│ • Calculating planetary orbits                      │
│ • Determining satellite trajectories                │
│ • Understanding tides on Earth                      │
│ • Estimating masses of celestial bodies             │
│ • Space mission planning                            │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **Important Notes**                                 │
│                                                     │
│ • Only **net gravitational force** is considered    │
│ • Assumes point masses or spherical symmetry        │
│ • Negligible for small masses, dominant at cosmic   │
│   scales                                              │
│ • Modified by Einstein’s General Relativity, but    │
│   Newton’s law remains highly accurate for most     │
│   purposes                                          │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ **Summary**                                         │
│                                                     │
│ Newton’s Law of Universal Gravitation provides a  │
│ simple yet powerful description of how gravity     │
│ works between any two masses. Though superseded    │
│ in extreme conditions by General Relativity, it     │
│ remains essential for understanding motion in the  │
│ solar system and engineering space travel.           │
└─────────────────────────────────────────────────────┘
