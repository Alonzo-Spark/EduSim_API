│ **Introduction**                                      │  
│                                                       │  
│ The principle of conservation of mechanical energy  │  
│ states that in a closed system where only conservative│  
│ forces (e.g., gravity) act, the sum of kinetic and   │  
│ potential energies remains constant over time.       │  
│                                                       │  
│ This concept is fundamental in physics and allows us│  
│ to predict motion without solving differential       │  
│ equations.                                            │  
└───────────────────────────────────────────────────────┘  

───────────────────────────────────────────────────────  
┌───────────────────────────────────────────────────────┐  
│ **Definition**                                         │  
│                                                       │  
│ *Mechanical energy* is the sum of kinetic energy (Eₖ)│  
│ and potential energy (Eₚ):                            │  
│                                                       │  
│ Eₘ = Eₖ + Eₚ                                           │  
│                                                       │  
│ When no non‑conservative forces do work, Eₘ stays      │  
│ unchanged.                                             │  
└───────────────────────────────────────────────────────┘  

───────────────────────────────────────────────────────  
┌───────────────────────────────────────────────────────┐  
│ **Key Concepts**                                       │  
│                                                       │  
│ • Kinetic Energy: ½ mv²                                 │  
│ • Gravitational Potential Energy: mgh                  │  
│ • Conservation Law: Eₖ + Eₚ = constant                 │  
│ • Work–Energy Theorem: W = ΔEₘ                         │  
│                                                       │  
└───────────────────────────────────────────────────────┘  

───────────────────────────────────────────────────────  
┌───────────────────────────────────────────────────────┐  
│ **Main Formula**                                       │  
│                                                       │  
│     Eₖ + Eₚ = E₀                                        │  
│                                                       │  
│ [ Explain Formula ]  [ Open Formula Lab ]              │  
└───────────────────────────────────────────────────────┘  

───────────────────────────────────────────────────────  
┌───────────────────────────────────────────────────────┐  
│ **Example**                                            │  
│                                                       │  
│ *A ball is released from rest at height h above the  │  
│ ground.*                                               │  
│                                                       │  
│ Initial energies (at t = 0):                          │  
│   Eₖ₀ = 0                                               │  
│   Eₚ₀ = mgh                                              │  
│   E₀  = mgh                                              │  
│                                                       │  
│ When the ball reaches the ground (h = 0):              │  
│   Eₚ = 0                                                │  
│   Eₖ = ½ mv² = mgh   →   v = √(2gh)                     │  
│   Eₖ + Eₚ = mgh = E₀                                     │  
│                                                       │  
│ The total mechanical energy remains mgh throughout the │  
│ fall, illustrating conservation.                       │  
└───────────────────────────────────────────────────────┘  

───────────────────────────────────────────────────────  
┌───────────────────────────────────────────────────────┐  
│ **Summary**                                            │  
│                                                       │  
│ • Mechanical energy is the sum of kinetic and        │  
│   potential energies.                                 │  
│ • In the absence of non‑conservative forces, this    │  
│   sum is constant.                                    │  
│ • The formula Eₖ + Eₚ = E₀ provides a quick check for │  
│   energy conservation.                                │  
│                                                       │  
└───────────────────────────────────────────────────────┘
