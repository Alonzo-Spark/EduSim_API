┌───────────────────────────────────────────────┐
│ Definition                                      │
│                                               │
│ Surface tension is the tendency of a liquid   │
│ to minimize its surface area, forming a thin   │
│ elastic film at the interface with another      │
│ phase (air, another liquid, solid, etc.). It   │
│ results from cohesive forces between molecules │
│ at the surface being stronger than those in    │
│ the bulk, causing the surface to contract.     │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Factors Affecting Surface Tension               │
│                                               │
│ • **Temperature** – ↑ temperature weakens       │
│   intermolecular cohesion, lowering tension.   │
│ • **Surfactants / Surface‑active agents** –    │
│   Molecules that accumulate at the surface     │
│   disrupt cohesive forces, markedly reducing    │
│   tension.                                      │
│ • **Purity of the liquid** – Impurities can    │
│   either increase (e.g., salts) or decrease    │
│   (e.g., organic contaminants) tension.        │
│ • **Nature of the liquid** – Liquids with       │
│   strong hydrogen bonding (e.g., water) have   │
│   higher surface tension than non‑polar ones.  │
│ • **Pressure** – At very high pressures,       │
│   molecular spacing changes, slightly altering │
│   tension.                                      │
│ • **Surface curvature** – Small droplets       │
│   exhibit higher apparent tension due to the   │
│   Laplace pressure.                             │
│ • **Dissolved gases** – Gases like air can      │
│   reduce tension by weakening intermolecular    │
│   attractions.                                 │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Summary                                         │
│                                               │
│ Surface tension reflects the cohesive forces   │
│ acting at a liquid’s interface. It is           │
│ influenced primarily by temperature, the       │
│ presence of surfactants or impurities, the     │
│ chemical nature of the liquid, pressure,       │
│ curvature, and dissolved gases. Understanding │
│ these factors is essential for applications    │
│ ranging from capillary action to droplet        │
│ formation and industrial processes.            │
└───────────────────────────────────────────────┘
