# Physics Module: Dynamics

┌──────────────────────────────────────────────────────────────────────────┐
│ **Introduction**                                                         │
│                                                                          │
│ This problem explores the relationship between force, mass, and the      │
│ resulting motion of an object, governed by Newton's Second Law of        │
│ Motion.                                                                  │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Given Parameters**                                                     │
│                                                                          │
│ • **Force ($F$):** $50\text{ N}$                                         │
│ • **Mass ($m$):** $10\text{ kg}$                                         │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Main Formula: Newton's Second Law**                                    │
│                                                                          │
│                         $$a = \frac{F}{m}$$                              │
│                                                                          │
│ **[ Explain Formula ]**                                                  │
│ Acceleration ($a$) is directly proportional to the net force acting on   │
│ an object and inversely proportional to its mass.                        │
│                                                                          │
│ **[ Open Formula Lab ]**                                                 │
│ Variables:                                                               │
│ - $F$ (Force in Newtons)                                                 │
│ - $m$ (Mass in Kilograms)                                                │
│ - $a$ (Acceleration in $m/s^2$)                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Step-by-Step Calculation**                                             │
│                                                                          │
│ 1. **Identify the Unknown:** We need to find Acceleration ($a$).         │
│ 2. **Substitute Values:**                                                │
│    $$a = \frac{50\text{ N}}{10\text{ kg}}$$                              │
│ 3. **Solve:**                                                            │
│    $$a = 5\text{ m/s}^2$$                                                │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Summary Table**                                                        │
│                                                                          │
│ | Property     | Value        | Unit      |                              │
│ |--------------|--------------|-----------|                              │
│ | Net Force    | 50           | Newtons   |                              │
│ | Total Mass   | 10           | Kilograms |                              │
│ | **Result**   | **5**        | **m/s²**  |                              │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Important Notes**                                                      │
│                                                                          │
│ • **Vector Nature:** Acceleration always occurs in the same direction    │
│   as the applied net force.                                              │
│ • **Unit Consistency:** Ensure mass is in kg and force is in N to        │
│   obtain acceleration in $m/s^2$.                                        │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Suggested Questions**                                                  │
│                                                                          │
│ 1. What would happen to the acceleration if the force was doubled to     │
│    100 N?                                                                │
│ 2. If the mass was increased to 20 kg while the force remained 50 N,     │
│    how would the acceleration change?                                    │
└──────────────────────────────────────────────────────────────────────────┘
