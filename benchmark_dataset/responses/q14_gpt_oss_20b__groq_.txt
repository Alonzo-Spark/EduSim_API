┌───────────────────────────────────────────────────────────────┐
│                     Introduction                               │
│                                                               │
│ Momentum is a fundamental quantity in physics that measures     │
│ the amount of motion an object possesses. It is a vector        │
│ quantity, meaning it has both magnitude and direction, and     │
│ is defined for any particle or system of particles.            │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                       Definition                                 │
│                                                               │
│ The linear momentum **p** of a particle is given by:           │
│                                                               │
│ **p** = **m** · **v**                                           │
│                                                               │
│ where **m** is the mass and **v** is the velocity vector.      │
│ The momentum of a system is the vector sum of the momenta of   │
│ all its constituent particles.                                 │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                     Key Concepts                               │
│                                                               │
│ •  Momentum is conserved in an isolated system.                │
│ •  It is proportional to mass and velocity.                    │
│ •  Momentum change equals impulse: Δ**p** = **J**.             │
│ •  Direction of momentum aligns with velocity.                 │
│ •  Relativistic momentum: **p** = γm**v** (γ = Lorentz factor)│
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                       Main Formula                              │
│                                                               │
│     p = m v                                                   │
│                                                               │
│ [ Explain Formula ]   [ Open Formula Lab ]                     │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                 Conservation of Momentum                       │
│                                                               │
│ In an isolated system the total momentum before an event       │
│ equals the total momentum after the event.                     │
│                                                               │
│ Δ**p**<sub>total</sub> = 0                                      │
│                                                               │
│ [ Explain Formula ]   [ Open Formula Lab ]                     │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                     Applications                               │
│                                                               │
│ •  Elastic and inelastic collisions                           │
│ •  Rocket propulsion                                           │
│ •  Projectile motion                                          │
│ •  Conservation checks in particle physics                     │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                      Advantages                               │
│                                                               │
│ •  Predictive power in dynamics                               │
│ •  Simple to compute in classical regimes                      │
│ •  Basis for impulse-momentum methods                         │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                     Disadvantages                              │
│                                                               │
│ •  Not invariant under Lorentz transformations (classical)   │
│ •  Requires knowledge of mass and velocity                       │
│ •  Limited to linear motion; angular momentum is separate      │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                     Important Notes                           │
│                                                               │
│ •  In relativistic contexts, use **p** = γm**v**.             │
│ •  Conservation applies only if no external forces act.       │
│ •  For continuous systems, use momentum density and flux.     │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                        Summary                                 │
│                                                               │
│ Momentum quantifies motion as a mass‑velocity product.        │
│ Its conservation in isolated systems provides a powerful     │
│ tool for analyzing collisions, propulsion, and many other     │
│ physical processes.                                          │
└───────────────────────────────────────────────────────────────┘
