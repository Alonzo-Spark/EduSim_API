┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Retardation is the process│
│ of reducing speed or      │
│ acceleration in motion.   │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ Initial Velocity (u): 20 m/s│
│ Final Velocity (v): 0 m/s │
│ Time (t): 10 s           │
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula              │
│                           │
│     \( a = \frac{v - u}{t} \)     │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

To calculate the retardation (deceleration), we can use the formula:

\[
a = \frac{v - u}{t}
\]

Where:
- \( v \) = final velocity (0 m/s, since the train stops)
- \( u \) = initial velocity (20 m/s)
- \( t \) = time taken to stop (10 seconds)

Substituting the values:

\[
a = \frac{0 - 20}{10} = \frac{-20}{10} = -2 \, \text{m/s}^2
\]

┌───────────────────────────┐
│ Summary                  │
│                           │
│ The retardation of the train is \( -2 \, \text{m/s}^2 \). This indicates a decrease in speed over the given time. │
└───────────────────────────┘
