Here is the explanation of Distance vs. Displacement, structured as an interactive textbook.

┌─────────────────────────────────────────────────────────────────┐
│ Introduction                                                    │
│                                                                 │
│ In the study of kinematics, describing how an object moves     │
│ requires precise language. While often used interchangeably in  │
│ casual conversation, **Distance** and **Displacement** have     │
│ fundamentally different meanings in physics.                   │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ Quick Definition                                                │
│                                                                 │
│ **Distance**                                                    │
│ The total length of the path covered by an object,              │
│ regardless of direction. It is a **Scalar Quantity**            │
│ (magnitude only).                                               │
│                                                                 │
│ **Displacement**                                                │
│ The shortest distance measured from the initial position to     │
│ the final position in a specific direction. It is a **Vector   │
│ Quantity** (magnitude and direction).                           │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ Main Formula                                                    │
│                                                                 │
│                                                                 │
│              $$ \Delta x = x_f - x_i $$                         │
│                                                                 │
│                                                                 │
│  Where:                                                         │
│  • $\Delta x$ = Displacement                                    │
│  • $x_f$ = Final Position                                       │
│  • $x_i$ = Initial Position                                     │
│                                                                 │

┌─────────────────────────────────────────────────────────────────┐
│ Real-World Examples                                             │
│                                                                 │
│ **Example 1: The Circular Track**                               │
│ Imagine an athlete runs one complete lap around a 400m          │
│ standard track.                                                 │
│                                                                 │
│ • **Distance:** 400 meters (The athlete actually ran the        │
│   entire length).                                               │
│ • **Displacement:** 0 meters (The athlete started at the        │
│   start line and finished at the exact same point).             │
│                                                                 │
│ **Example 2: Walking to School**                                │
│ You walk 10 meters East to a friend's house, then turn around   │
│ and walk 10 meters West back to your home.                      │
│                                                                 │
│ • **Distance:** 20 meters (10m + 10m).                          │
│ • **Displacement:** 0 meters (Final position = Initial          │
│   position).                                                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ Comparison                                                      │
│                                                                 │
│ ┌──────────────────┬──────────────────────┬───────────────────┐ │
│ │ Feature          │ Distance             │ Displacement      │ │
│ ├──────────────────┼──────────────────────┼───────────────────┤ │
│ │ Type             │ Scalar               │ Vector            │ │
│ │ Direction        │ No                   │ Yes               │ │
│ │ Path Dependence  │ Depends on path      │ Independent       │ │
│ │ Formula          │ Speed × Time         │ Δx = xf - xi      │ │
│ │ Can be zero?     │ No (if moving)       │ Yes               │ │
│ │ Always positive? │ Yes                  │ Can be negative   │ │
│ └──────────────────┴──────────────────────┴───────────────────┘ │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ Important Notes                                                 │
│                                                                 │
│ 1. **Magnitude:** Displacement can be equal to distance if the  │
│    object moves in a straight line without changing direction.  │
│                                                                 │
│ 2. **Sign Convention:** In one-dimensional motion, displacement │
│    is often represented with a sign (+ or -) to indicate       │
│    direction relative to a reference point.                     │
└─────────────────────────────────────────────────────────────────┘
