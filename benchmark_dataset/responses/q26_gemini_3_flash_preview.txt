┌──────────────────────────────────────────────────────────────────────────┐
│ **Introduction: Fluid Pressure**                                         │
├──────────────────────────────────────────────────────────────────────────┤
│ When a fluid (liquid or gas) is at rest, it exerts a force perpendicular │
│ to any surface in contact with it. This distributed force is what we    │
│ perceive as pressure. Unlike solids, fluids cannot sustain shear stress  │
│ at rest, so the force is always normal (perpendicular) to the surface.   │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Definition: Pressure**                                                 │
├──────────────────────────────────────────────────────────────────────────┤
│ **Pressure** is defined as the normal force (thrust) acting per unit     │
│ area of a surface. It is a scalar quantity because at any point inside   │
│ a fluid, pressure acts equally in all directions.                        │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Main Formula: Mathematical Expression**                                 │
│                                                                          │
│                 $$P = \frac{F_{\perp}}{A}$$                              │
│                                                                          │
│ **[ Explain Formula ]**                                                  │
│ • $P$: Pressure                                                          │
│ • $F_{\perp}$: Normal force (Thrust) acting on the surface               │
│ • $A$: Area of the surface over which the force is distributed           │
│                                                                          │

└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Units and Dimensions**                                                 │
├──────────────────────────────────────────────────────────────────────────┤
│ **SI Unit:** Pascal ($Pa$)                                               │
│ 1 Pascal is equivalent to 1 Newton per square meter ($N/m^2$).           │
│                                                                          │
│ **Dimensional Formula:** $[M^1 L^{-1} T^{-2}]$                           │
└──────────────────────────────────────────────────────────────────────────┤
│ **Other Common Units:**                                                  │
│ • **Atmosphere (atm):** $1 \, atm = 1.013 \times 10^5 \, Pa$             │
│ • **Bar:** $1 \, bar = 10^5 \, Pa$                                       │
│ • **Torr:** $1 \, torr = 133.3 \, Pa$                                    │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ **Key Characteristics**                                                  │
├──────────────────────────────────────────────────────────────────────────┤
│ 1. **Direction:** Pressure acts perpendicular to the boundary of the     │
│    fluid.                                                                │
│ 2. **Scalar Nature:** Even though force is a vector, pressure is a      │
│    scalar because it relates to the magnitude of the normal component.   │
│ 3. **Depth Dependency:** In a static fluid, pressure increases linearly  │
│    with depth due to the weight of the fluid column above.               │
└──────────────────────────────────────────────────────────────────────────┘
