## Conservation Laws

```
┌─────────────────────────────────────────────────────────┐
│  📐  Formula Card 1 · Conservation of Momentum          │
├─────────────────────────────────────────────────────────┤
│                                                          │
```

$$
m u_1 + m u_2 = m v_1 + m v_2
$$

$$
\boxed{u_1 + u_2 = v_1 + v_2}
$$

```
│                                                          │
│  Since masses cancel, momentum conservation reduces      │
│  to a simple velocity sum equation.                      │
│                                                          │
│  [ Explain Formula ]    [ Open Formula Lab ]             │
└─────────────────────────────────────────────────────────┘
```

---

```
┌─────────────────────────────────────────────────────────┐
│  📐  Formula Card 2 · Conservation of Kinetic Energy    │
│       (Elastic Collisions Only)                          │
├─────────────────────────────────────────────────────────┤
│                                                          │
```

$$
\frac{1}{2}m u_1^2 + \frac{1}{2}m u_2^2 = \frac{1}{2}m v_1^2 + \frac{1}{2}m v_2^2
$$

$$
\boxed{u_1^2 + u_2^2 = v_1^2 + v_2^2}
$$

```
│                                                          │
│  Masses again cancel. Energy is only conserved in        │
│  perfectly elastic collisions.                           │
│                                                          │
│  [ Explain Formula ]    [ Open Formula Lab ]             │
└─────────────────────────────────────────────────────────┘
```

## Collision Type Cards

```
┌─────────────────────────────────────────────────────────┐
│  💥  Case 1 · Perfectly Elastic Collision                │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  Solving momentum + energy equations simultaneously:     │
│                                                          │
```

$$
v_1 = u_2 \qquad v_2 = u_1
$$

```
│                                                          │
│  ✦ The velocities EXCHANGE completely.                   │
│  ✦ If u₂ = 0 (target at rest):                          │
│       → Mass 1 STOPS                                     │
│       → Mass 2 moves with u₁                            │
│                                                          │
│  Real-world example: Newton's Cradle (equal balls)       │
│                                                          │
│  [ Explain Formula ]    [ Open Formula Lab ]             │
└─────────────────────────────────────────────────────────┘
```

---

```
┌─────────────────────────────────────────────────────────┐
│  💥  Case 2 · Perfectly Inelastic Collision              │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  Bodies stick together after collision.                  │
│  Combined mass = 2m                                      │
│                                                          │
```

$$
v_{\text{common}} = \frac{u_1 + u_2}{2}
$$

```
│                                                          │
│  ✦ Both masses move together at the AVERAGE velocity.   │
│  ✦ Maximum kinetic energy is lost.                       │
│                                                          │
│  Energy Lost:                                            │
```

$$
\Delta KE = \frac{1}{4}m(u_1 - u_2)^2
$$

```
│                                                          │
│  [ Explain Formula ]    [ Open Formula Lab ]             │
└─────────────────────────────────────────────────────────┘
```

## Key Takeaways

```
┌─────────────────────────────────────────────────────────┐
│  📌  Summary Card                                        │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  1.  Equal masses → momentum conservation simplifies     │
│      to pure velocity equations (m cancels).             │
│                                                          │
│  2.  Elastic collision → velocities swap.                │
│                                                          │
│  3.  Inelastic collision → both move at average v.       │
│                                                          │
│  4.  Head-on elastic (target at rest) → projectile       │
│      stops, target inherits full velocity.               │
│                                                          │
│  5.  Momentum is ALWAYS conserved.                       │
│      Kinetic energy is only conserved if elastic.        │
│                                                          │
└─────────────────────────────────────────────────────────┘
```
