┌─────────────────────────────────────┐
│ Introduction                        │
│                                     │
│ Thermodynamics is the branch of      │
│ physics that deals with the          │
│ relationships between heat, work,   │
│ energy, and the properties of        │
│ matter. It provides a framework      │
│ for understanding how energy is      │
│ transferred and transformed in       │
│ physical systems.                    │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Definition                          │
│                                     │
│ A **law of thermodynamics** is a     │
│ fundamental principle that          │
│ describes how energy behaves in      │
│ macroscopic systems, independent of   │
│ the details of microscopic motion.   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Key Concepts                        │
│                                     │
│ • **System** – the part of the       │
│   universe under study.             │
│ • **Surroundings** – everything      │
│   outside the system.               │
│ • **State** – the set of properties  │
│   (pressure, volume, temperature)  │
│   that define the system at an       │
│   instant.                           │
│ • **Process** – a transformation    │
│   from one state to another.        │
│ • **Energy** – the capacity to       │
│   do work or transfer heat.          │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Zeroth Law of Thermodynamics         │
│                                     │
│ If two systems are each in thermal   │
│ equilibrium with a third system,    │
│ then they are in thermal equilibrium │
│ with each other. This law defines     │
│ temperature as a measurable property│
│ that determines thermal equilibrium.│
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ First Law of Thermodynamics          │
│                                     │
│ Energy cannot be created or destroyed│
│ – it can only be transferred or      │
│ converted from one form to another.  │
│ The change in internal energy (ΔU)   │
│ of a closed system equals the heat   │
│ added to the system (Q) minus the    │
│ work done by the system (W).         │
└─────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ First Law – Formula Card                         │
│                                                   │
│   $$\Delta U = Q - W$$                            │

└───────────────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Second Law of Thermodynamics        │
│                                     │
│ In any spontaneous process, the total│
│ entropy of an isolated system never   │
│ decreases; it either increases or   │
│ remains constant. Entropy (S) is a   │
│ measure of disorder or the number of │
│ microscopic configurations compatible│
│ with the macroscopic state.          │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Third Law of Thermodynamics          │
│                                     │
│ As the temperature of a perfect     │
│ crystal approaches absolute zero (0 │
│ K), its entropy approaches a constant│
│ minimum, which can be taken as zero.│
│ This provides a reference point for │
│ measuring absolute entropies.        │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Applications                         │
│                                     │
│ • Power plants and engines (heat →   │
│   work conversion)                  │
│ • Refrigeration and air‑conditioning│
│   (work → heat removal)             │
│ • Chemical reaction energetics       │
│ • Biological energy metabolism      │
│ • Material science (phase changes)  │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Important Notes                      │
│                                     │
│ • The laws are empirical; they hold │
│   for macroscopic systems regardless│
│   of composition.                   │
│ • They are independent of the        │
│   microscopic details of particles. │
│ • The “Zeroth” law was formulated    │
│   after the first three to give a    │
│   logical ordering.                 │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Summary                              │
│                                     │
│ 1️⃣ Zeroth – establishes temperature │
│    as a property of thermal equilibrium.│
│ 2️⃣ First – energy conservation;      │
│    ΔU = Q − W.                        │
│ 3️⃣ Second – entropy of an isolated   │
│    system never decreases.           │
│ 4️⃣ Third – entropy approaches zero   │
│    as T → 0 K for a perfect crystal. │
│ Together they form the backbone of   │
│ thermal physics and engineering.      │
└─────────────────────────────────────┘
