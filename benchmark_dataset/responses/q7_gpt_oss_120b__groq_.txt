┌──────────────────────────────────┐
│ Introduction                     │
│                                  │
│ We examine projectile motion and │
│ derive the expression for the    │
│ maximum vertical height an       │
│ object can reach when launched   │
│ at an angle θ with speed v₀.      │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│ Definition                       │
│                                  │
│ Maximum height (Hₘₐₓ) is the     │
│ greatest vertical displacement   │
│ of the projectile measured from  │
│ its launch point.                │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│ Key Concepts                     │
│                                  │
│ • Projectile motion = horizontal│
│   + vertical components.         │
│ • Vertical motion is uniformly   │
│   accelerated (g ≈ 9.81 m/s²).    │
│ • At the top of the trajectory, │
│   vertical velocity = 0.         │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│ Variables                        │
│                                  │
│ v₀   – initial speed (m s⁻¹)      │
│ θ    – launch angle (rad)         │
│ g    – acceleration due to       │
│        gravity (m s⁻²)            │
│ Hₘₐₓ – maximum height (m)        │
│ v₀ᵧ  – vertical component of v₀   │
│        (v₀ sinθ)                  │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│ Vertical Motion Equation         │
│                                  │
│ y(t) = v₀ᵧ·t – ½ g t²              │
│                                  │
│ [ Explain Formula ]              │
│ [ Open Formula Lab ]              │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│ Time to Reach Peak                │
│                                  │
│ Set vertical velocity = 0:       │
│ v(t) = v₀ᵧ – g t = 0 ⇒ tₚₑₐₖ =    │
│ v₀ᵧ / g = (v₀ sinθ)/g            │
│                                  │
│ [ Explain Formula ]              │
│ [ Open Formula Lab ]              │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│ Maximum Height Formula            │
│                                  │
│ Hₘₐₓ = v₀ᵧ·tₚₑₐₖ – ½ g tₚₑₐₖ²        │
│      = (v₀ sinθ)·(v₀ sinθ/g) –   │
│        ½ g·(v₀ sinθ/g)²           │
│      = (v₀² sin²θ)/(2g)          │
│                                  │
│ [ Explain Formula ]              │
│ [ Open Formula Lab ]              │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│ Applications                     │
│                                  │
│ • Sports (e.g., basketball,      │
│   golf) – estimating how high a  │
│   ball will rise.                │
│ • Engineering – trajectory       │
│   planning for rockets or drones.│
│ • Safety analysis – clearance    │
│   heights for projectiles.       │
└──────────────────────────────────┘

┌──────────────────────────────────┐
│ Summary                          │
│                                  │
│ The maximum height of a projectile│
│ launched with speed v₀ at angle θ │
│ is Hₘₐₓ = (v₀² sin²θ)/(2g). This   │
│ follows from the vertical motion │
│ equations and the condition that  │
│ vertical velocity is zero at the  │
│ apex.                            │
└──────────────────────────────────┘
