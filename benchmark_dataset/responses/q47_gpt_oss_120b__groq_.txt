┌─────────────────────────────────────────────┐
│ 📖 Introduction                              │
│                                             │
│ In electric circuits, resistors can be       │
│ connected in different ways. One of the      │
│ simplest configurations is the **series**   │
│ connection, where the same current flows     │
│ through each resistor one after another.     │
│ Understanding how to combine their          │
│ resistances into a single equivalent value   │
│ is essential for circuit analysis and design.│
└─────────────────────────────────────────────┘



┌─────────────────────────────────────────────┐
│ 📚 Definition                               │
│                                             │
│ **Series Connection** – A wiring arrangement│
│ where components share a common node at each  │
│ end, so the same current passes through each │
│ element sequentially.                        │
│                                             │
│ **Equivalent Resistance (Rₑₛ)** – A single    │
│ resistance that would draw the same total     │
│ current from the same voltage source as the   │
│ entire series network.                       │
└─────────────────────────────────────────────┘



┌─────────────────────────────────────────────┐
│ 🔑 Key Concepts                              │
│                                             │
│ • **Current Continuity** – In series, the    │
│   current I is identical through every       │
│   resistor.                                   │
│ • **Voltage Division** – The source voltage   │
│   V is split among the resistors:            │
│   V = V₁ + V₂ + … + Vₙ.                       │
│ • **Ohm’s Law** – Vᵢ = I·Rᵢ for each resistor.│
│ • **Additivity** – Because the same I flows, │
│   the total voltage drop is the sum of the   │
│   individual drops.                          │
└─────────────────────────────────────────────┘



┌─────────────────────────────────────────────┐
│ 📐 Main Formula                               │
│                                             │
│      Rₑₛ = Σᵢ₌₁ⁿ Rᵢ                         │

┌─────────────────────────────────────────────┐
│ 🧩 Derivation Steps                           │
│                                             │
│ 1. **Start with Ohm’s law** for each        │
│    resistor: Vᵢ = I·Rᵢ.                      │
│                                             │
│ 2. **Apply voltage sum** around the loop:   │
│    V_source = V₁ + V₂ + … + Vₙ.              │
│                                             │
│ 3. **Substitute** Vᵢ = I·Rᵢ into the sum:    │
│    V_source = I·R₁ + I·R₂ + … + I·Rₙ          │
│    = I·(R₁ + R₂ + … + Rₙ).                   │
│                                             │
│ 4. **Define** the equivalent resistance Rₑₛ│
│    by V_source = I·Rₑₛ.                     │
│                                             │
│ 5. **Equate** the two expressions for V_source:│
│    I·Rₑₛ = I·(R₁ + R₂ + … + Rₙ).            │
│                                             │
│ 6. **Cancel** the common current I (I ≠ 0): │
│    Rₑₛ = R₁ + R₂ + … + Rₙ.                  │
│                                             │
│ Hence, the equivalent resistance of n       │
│ resistors in series is the arithmetic sum   │
│ of their individual resistances.             │
└─────────────────────────────────────────────┘



┌─────────────────────────────────────────────┐
│ 🚀 Applications                               │
│                                             │
│ • **Designing voltage dividers** – Knowing   │
│   the total series resistance lets you set   │
│   the desired output voltage.                │
│ • **Power budgeting** – Total resistance      │
│   determines overall power dissipation: P =   │
│   I²·Rₑₛ.                                     │
│ • **Simplifying circuit analysis** – Replace  │
│   a chain of series resistors with a single  │
│   equivalent resistor to reduce complexity.  │
└─────────────────────────────────────────────┘



┌─────────────────────────────────────────────┐
│ 📌 Summary                                   │
│                                             │
│ • In a series circuit, the same current flows│
│   through every resistor.                   │
│ • The source voltage equals the sum of the   │
│   individual voltage drops.                 │
│ • By substituting Ohm’s law and cancelling   │
│   the common current, we obtain:            │
│   **Rₑₛ = R₁ + R₂ + … + Rₙ**.                │
│ • This simple additive rule is the basis for│
│   many practical circuit calculations.      │
└─────────────────────────────────────────────┘
