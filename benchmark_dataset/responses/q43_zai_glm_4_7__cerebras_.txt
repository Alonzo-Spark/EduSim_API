                </p>

                <div class="card-header">
                    <div class="card-icon">D</div>
                    <h2 class="card-title">Step-by-Step Derivation</h2>
                </div>
                
                <p><strong>1. Dependence on Charge Magnitude:</strong><br>
                Experimental evidence (such as the torsion balance experiment by Charles-Augustin de Coulomb) suggests that the force is directly proportional to the product of the magnitudes of the charges.
                $$ F \propto q_1 q_2 $$
                If either charge is doubled, the force doubles. If both are doubled, the force quadruples.</p>
                
                <br>

                <p><strong>2. Dependence on Distance:</strong><br>
                Similar to Newton's Law of Universal Gravitation, the force decreases as the distance between charges increases. Specifically, it follows an inverse-square law relative to the distance $r$.
                $$ F \propto \frac{1}{r^2} $$
                This means if the distance doubles, the force becomes one-fourth.</p>

                <br>

                <p><strong>3. Combining Proportionalities:</strong><br>
                Combining the two observations, we get the scalar relationship:
                $$ F \propto \frac{q_1 q_2}{r^2} $$</p>

                <br>

                <p><strong>4. Introducing the Proportionality Constant ($k$):</strong><br>
                To convert the proportionality into an equation, we introduce a constant $k$. In the SI system, this is often written in terms of the permittivity of free space ($\epsilon_0$).
                $$ k = \frac{1}{4\pi\epsilon_0} $$</p>
            </article>

                { symbol: 'F', name: 'Force', unit: 'N' },
                { symbol: 'k', name: 'Coulomb Constant', unit: 'N·m²/C²' },

        }

        // Close on clicking outside
        modal.addEventListener('click', (e) => {
            if (e.target === modal) closeFormulaLab();
        });

        // 4. FORMULA LAB SIMULATION LOGIC
        
        const k_const = 8.99; // Scaled down for visual simulation (Real k is 9e9)
        // To make numbers readable in the demo without scientific notation clutter, 
        // we treat inputs as MicroCoulombs and output directly, scaling k effectively.
        
        const inputs = {
            q1: document.getElementById('input-q1'),
            q2: document.getElementById('input-q2'),
            r: document.getElementById('input-r')
        };

        const displays = {
            q1: document.getElementById('val-q1'),
            q2: document.getElementById('val-q2'),
            r: document.getElementById('val-r'),
            result: document.getElementById('calc-result'),
            rText: document.getElementById('vis-r-text')
        };

        const visuals = {
            q1: document.getElementById('vis-q1'),
            q2: document.getElementById('vis-q2'),
            arrow: document.getElementById('vis-arrow')
        };

        // Add listeners
        Object.values(inputs).forEach(input => {
            input.addEventListener('input', updateLab);
        });

        function updateLab() {
            // Get values
            let q1 = parseFloat(inputs.q1.value);
            let q2 = parseFloat(inputs.q2.value);
            let r = parseFloat(inputs.r.value);

            // Update text displays
            displays.q1.textContent = q1;
            displays.q2.textContent = q2;
            displays.r.textContent = r.toFixed(1);
            displays.rText.textContent = r.toFixed(1);

            // Calculate Force (Magnitude)
            // F = k * |q1*q2| / r^2
            // Using a scaled k for visualization purposes so the number isn't huge
            const force = k_const * Math.abs(q1 * q2) / (r * r);
            displays.result.textContent = force.toFixed(2);

            // Update Visuals
            
            // 1. Positioning (Center them, separate by r)
            // Map r (1 to 10) to pixels (e.g., 50px to 250px separation)
            const centerOffset = (r / 10) * 120; 
            
            visuals.q1.style.transform = `translateX(-${centerOffset}px)`;
            visuals.q2.style.transform = `translateX(${centerOffset}px)`;

            // 2. Color/Sign
            visuals.q1.style.background = q1 < 0 ? '#ef4444' : '#3b82f6'; // Red for neg, Blue for pos
            visuals.q2.style.background = q2 < 0 ? '#ef4444' : '#3b82f6';
            
            // Update text inside balls
            visuals.q1.textContent = q1 > 0 ? `+${q1}` : q1;
            visuals.q2.textContent = q2 > 0 ? `+${q2}` : q2;

            // 3. Force Arrow
            const product = q1 * q2;
            
            if (product === 0) {
                visuals.arrow.style.opacity = '0';
            } else {
                visuals.arrow.style.opacity = '1';
                
                // Width of arrow based on force magnitude (clamped)
                const arrowWidth = Math.min(Math.max(force * 2, 20), 100); 
                visuals.arrow.style.width = `${arrowWidth}px`;

                // Direction Logic
                // If product > 0 (Like charges): Repel. Arrows point outward.
                // If product < 0 (Opposite): Attract. Arrows point inward.
                
                // We only draw one arrow on q1 for simplicity
                if (product > 0) {
                    // Repel: Arrow points Left (away from q2)
                    visuals.arrow.style.left = `calc(50% - ${centerOffset}px - ${arrowWidth}px)`;
                    visuals.arrow.style.transform = 'rotate(0deg)';
                    visuals.arrow.style.background = '#ef4444'; // Repulsive color
                } else {
                    // Attract: Arrow points Right (towards q2)
                    visuals.arrow.style.left = `calc(50% - ${centerOffset}px)`;
                    visuals.arrow.style.transform = 'rotate(0deg)';
                    visuals.arrow.style.background = '#10b981'; // Attractive color
                }
            }
        }
