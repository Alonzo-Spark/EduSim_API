┌───────────────────────────────────────────────────────────────────────┐
│ Introduction                                                          │
│                                                                       │
│ Waves are disturbances that transfer energy through a medium (or   │
│ vacuum) without transporting matter. Two fundamental categories are │
│ transverse and longitudinal waves, distinguished by the direction   │
│ of particle motion relative to the direction of wave propagation.    │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Definition                                                            │
│                                                                       │
│ **Transverse Wave** – The particles of the medium oscillate          │
│ perpendicular (at right angles) to the direction the wave travels.   │
│                                                                       │
│ **Longitudinal Wave** – The particles oscillate parallel to the      │
│ direction of wave travel, producing alternating compressions and      │
│ rarefactions.                                                         │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Key Concepts                                                          │
│                                                                       │
│ • **Direction of Particle Motion**:                                        │
│   – Transverse → side‑to‑side (up‑down, left‑right).                  │
│   – Longitudinal → back‑and‑forth along the travel path.               │
│                                                                       │
│ • **Medium Requirement**:                                            │
│   – Transverse can travel in solids and on surfaces; in fluids they │
│     need a restoring force (e.g., surface water waves).               │
│   – Longitudinal waves require a medium that can be compressed;      │
│     they travel through solids, liquids, and gases.                    │
│                                                                       │
│ • **Examples**:                                                       │
│   – Transverse: light (electromagnetic), string vibrations, water     │
│     surface waves.                                                    │
│   – Longitudinal: sound in air, seismic P‑waves, pressure waves in   │
│     pipes.                                                            │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Applications                                                          │
│                                                                       │
│ • **Transverse** – Antennas (radio waves), optical fibers (light),   │
│   seismic S‑waves for earthquake analysis, musical instruments.     │
│ • **Longitudinal** – Audio engineering (sound propagation),         │
│   medical ultrasonography, non‑destructive testing (ultrasonic    │
│   inspection), seismic P‑waves for probing Earth’s interior.        │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Important Notes                                                       │
│                                                                       │
│ – Not all waves fit neatly into one category; some (e.g., surface    │
│   water waves) exhibit both transverse and longitudinal components.  │
│ – Electromagnetic waves are purely transverse; they do not require   │
│   a material medium.                                                  │
│ – In solids, both transverse (shear) and longitudinal (compressional)│
│   waves can coexist, traveling at different speeds.                  │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Summary                                                               │
│                                                                       │
│ • Transverse waves: particle motion ⟂ direction of travel;          │
│   common in solids, surfaces, and electromagnetic radiation.          │
│ • Longitudinal waves: particle motion ∥ direction of travel;        │
│   propagate through any compressible medium (solids, liquids, gases).│
│ • Understanding the distinction helps explain phenomena from sound │
│   to light to seismic activity.                                       │
└───────────────────────────────────────────────────────────────────────┘
