┌───────────────────────────────────────────────┐
│                Definition                        │
│                                                   │
│ *Elastic Collision (equal masses)*: Two          │
│ objects, each of mass **m**, collide head‑on      │
│ and exchange their velocities without loss of    │
│ kinetic energy.                                    │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│                Key Concepts                      │
│                                                   │
│ • **Conservation of Linear Momentum**            │
│   \[ m v_{1i} + m v_{2i} = m v_{1f} + m v_{2f} \] │
│ • **Conservation of Kinetic Energy**            │
│   \[ \tfrac12 m v_{1i}^2 + \tfrac12 m v_{2i}^2   │
│      = \tfrac12 m v_{1f}^2 + \tfrac12 m v_{2f}^2 \]│
│ • For **equal masses** the equations simplify to │
│   \[ v_{1f} = v_{2i}, \quad v_{2f} = v_{1i} \]   │
└───────────────────────────────────────────────┘



┌───────────────────────────────────────────────┐
│                Main Formula                       │
│                                                   │
│   \[ m v_{1i} + m v_{2i} = m v_{1f} + m v_{2f} \] │
│   \[ \tfrac12 m v_{1i}^2 + \tfrac12 m v_{2i}^2   │
│      = \tfrac12 m v_{1f}^2 + \tfrac12 m v_{2f}^2 \]│
│                                                   │
│   **Reduced (m cancels)**                        │
│   \[ v_{1f} = v_{2i}, \qquad v_{2f} = v_{1i} \]   │
