┌─────────────────────────────────────────────┐
│ 📚 Introduction                              │
│                                             │
│ In electrostatics we describe how charges   │
│ influence the space around them. Two central │
│ ideas are the **electric field** and the     │
│ **electric potential**. Understanding these │
│ concepts lets us predict forces on charges  │
│ and the energy changes when charges move.   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 📖 Definition – Electric Field               │
│                                             │
│ The **electric field** **E** at a point in    │
│ space is the force **F** that a **positive**  │
│ test charge **q** would experience, divided  │
│ by the magnitude of that test charge:        │
│                                             │
│   **E** = **F** / **q**                      │
│                                             │
│ It is a vector quantity, pointing in the     │
│ direction a positive charge would be pushed  │
│ and measured in newtons per coulomb (N/C)    │
│ or volts per meter (V·m⁻¹).                  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🧮 Formula Card – Electric Field              │
│                                             │
│ $$\displaystyle \mathbf{E} = \frac{\mathbf{F}}{q}$$ │
│                                             │
│ **Variables**                               │
│ • **E** – electric field (N C⁻¹ or V m⁻¹)    │
│ • **F** – force on the test charge (N)      │
│ • **q** – magnitude of the test charge (C)  │
│                                             │

└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 📖 Definition – Electric Potential           │
│                                             │
│ The **electric potential** **V** at a point │
│ is the electric potential energy **U** per   │
│ unit charge **q**:                           │
│                                             │
│   **V** = **U** / **q**                      │
│                                             │
│ It represents how much work is needed to     │
│ bring a unit positive charge from a reference│
│ point (often infinity) to the location,     │
│ without acceleration. Measured in volts (V).│
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 🧮 Formula Card – Electric Potential          │
│                                             │
│ $$\displaystyle V = -\int_{\text{ref}}^{\mathbf{r}} \mathbf{E}\!\cdot\!d\mathbf{l}$$ │
│                                             │
│ **Variables**                               │
│ • **V** – electric potential (V)            │
│ • **E** – electric field (V m⁻¹)            │
│ • **dl** – infinitesimal displacement vector│
│ • **ref** – reference point (commonly ∞)    │
│                                             │
│ [ Explain Formula ]   [ Open Formula Lab ]  │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ 📌 Summary                                   │
│                                             │
│ • **Electric field** describes the **force** │
│   per unit charge at a point.               │
│ • **Electric potential** describes the **energy│
│   per unit charge** relative to a reference.│
│ • Both are related: the field is the spatial│
│   gradient of the potential ( E = –∇V ).      │
│                                             │
│ Understanding these links lets us analyze   │
│ electrostatic phenomena, from capacitors to  │
│ charge distributions, with clear physical   │
│ intuition.                                   │
