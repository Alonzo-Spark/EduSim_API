┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ Thermodynamics is the study of energy │
│ transformations and the relationships│
│ between heat, work, temperature, and │
│ entropy. It provides the foundation for│
│ understanding how physical systems    │
│ exchange energy and reach equilibrium.│
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Definition                             │
│                                       │
│ **Thermodynamics** – the science that│
│ describes the macroscopic behavior of │
│ systems in terms of energy, its       │
│ conversion, and the direction of      │
│ spontaneous processes.                │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ The Four Laws of Thermodynamics         │
│                                       │
│ 1️⃣ **Zeroth Law** – If system A is in │
│ thermal equilibrium with B, and B is   │
│ in thermal equilibrium with C, then A │
│ and C are also in thermal equilibrium.│
│                                       │
│ 2️⃣ **First Law** – Energy cannot be   │
│ created or destroyed, only transferred│
│ or converted.                          │
│                                       │
│ 3️⃣ **Second Law** – Entropy of an     │
│ isolated system never decreases;      │
│ processes occur in the direction of    │
│ increasing entropy.                    │
│                                       │
│ 4️⃣ **Third Law** – As temperature     │
│ approaches absolute zero, the entropy │
│ of a perfect crystal approaches zero. │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ First Law – Energy Conservation         │
│                                       │
│ The quantitative statement of the     │
│ First Law is:                           │
│                                       │
│     ΔU = Q − W                         │
│                                       │
│ where ΔU is the change in internal     │
│ energy, Q is heat added to the system, │
│ and W is work done by the system.      │
│                                       │

┌───────────────────────────────────────┐
│ Applications                           │
│                                       │
│ • Power generation (steam turbines)   │
│ • Refrigeration and heat pumps         │
│ • Internal combustion engines          │
│ • Chemical reaction energetics         │
│ • Cryogenics and low‑temperature physics│
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Important Notes                        │
│                                       │
│ • The Zeroth Law establishes temperature│
│   as an equivalence relation.          │
│ • The First Law is a statement of       │
│   energy conservation; it does not     │
│   specify the direction of processes.   │
│ • The Second Law introduces irreversibility│
│   and the concept of entropy.           │
│ • The Third Law provides a reference     │
│   point for entropy calculations.       │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Summary                                 │
│                                       │
│ • Thermodynamics rests on four fundamental│
│   laws that describe equilibrium, energy│
│   conservation, entropy increase, and   │
│   the absolute‑zero limit.               │
│ • Each law can be expressed mathematically│
│   and applied across physics, chemistry,│
│   and engineering.                      │
