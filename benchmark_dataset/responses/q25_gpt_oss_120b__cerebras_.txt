┌───────────────────────────────┐
│ Introduction                    │
│                                   │
│ Astronauts appear weightless not   │
│ because there is no gravity, but   │
│ because they are in a state of     │
│ continuous free‑fall while         │
│ orbiting Earth.  In orbit the       │
│ spacecraft and everything inside   │
│ it fall toward the planet at the   │
│ same rate, so no contact force      │
│ pushes on the astronauts – the      │
│ only force they feel is the        │
│ gravitational pull itself.         │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Definition                      │
│                                   │
│ **Weightlessness (micro‑gravity)**│
│ is the condition in which an      │
│ object experiences no net          │
│ contact (support) force.  In      │
│ practice this means the astronaut │
│ feels “weightless” while the       │
│ gravitational field still exists. │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Key Concepts                    │
│                                   │
│ • **Free‑fall** – motion under only │
│   gravity, with no other forces   │
│   acting on the object.           │
│ • **Orbital motion** – a circular │
│   free‑fall where the object's     │
│   sideways velocity provides the   │
│   centripetal acceleration needed │
│   to keep it from hitting Earth.   │
│ • **Inertial frame** – inside the │
│   spacecraft the astronauts share │
│   the same inertial frame, so they│
│   cannot feel the pull of gravity │
│   as a weight.                     │
│ • **Apparent weight** – the force │
│   you feel from a surface (the     │
│   floor).  In orbit this force is  │
│   zero.                            │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Main Formula                    │
│                                   │
│ $$                              │
│ F_\text{grav}= \frac{G M m}{r^{2}} │
│ $$                               │
│                                   │
│ $$                              │
│ a_\text{centripetal}= \frac{v^{2}}{r} │
│ $$                               │
│                                   │
│ Weightlessness occurs when      │
│ $$                              │
│ a_\text{centripetal}= g = \frac{G M}{r^{2}} │
│ $$                               │

┌───────────────────────────────┐
│ Applications                    │
│                                   │
│ • Satellite and space‑station     │
│   design relies on knowing the    │
│   micro‑gravity environment.      │
│ • Scientific experiments that     │
│   require near‑zero gravity, e.g.,│
│   fluid dynamics, crystal growth. │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Important Notes                 │
│                                   │
│ • “Zero‑gravity” is a misnomer –  │
│   gravity is only slightly weaker│
│   than on Earth’s surface.        │
│ • Astronauts still experience     │
│   tidal forces (very small).      │
│ • Weightlessness is felt only     │
│   when in free‑fall; on the       │
│   surface of a planet you feel    │
│   weight because the ground pushes│
│   up against you.                  │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Summary                         │
│                                   │
│ • Astronauts are in continuous   │
│   free‑fall around Earth.        │
│ • Their orbital speed provides    │
│   the exact centripetal          │
│   acceleration needed to match   │
│   the local gravitational pull.  │
│ • Because both the spacecraft and │
│   its occupants share the same   │
│   inertial frame, no contact force│
│   is felt – resulting in weightlessness. │
└───────────────────────────────┘
