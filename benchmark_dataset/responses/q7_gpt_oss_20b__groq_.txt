┌───────────────────────────────────────────────────────────────────────────────────────┐
│ **Introduction**                                                                   │
│                                                                                   │
│ Projectile motion is the motion of an object that is launched into the air and      │
│ then moves under the influence of gravity alone.  The path traced is a parabola   │
│ and its properties can be described using simple kinematic equations.             │
└───────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────┐
│ **Definition**                                                                     │
│                                                                                   │
│ The *maximum height* (or peak height) of a projectile is the greatest vertical     │
│ displacement it attains above the launch level during its flight.                  │
└───────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────┐
│ **Key Concepts**                                                                  │
│                                                                                   │
│ • **Initial velocity** \(v_0\) launched at an angle \(\theta\) above the horizontal.│
│ • **Vertical component** \(v_{0y}=v_0\sin\theta\).                                   │
│ • **Acceleration due to gravity** \(g\) (≈ 9.81 m s\(^{-2}\)).                      │
│ • **Vertical motion equation** \(y(t)=v_{0y}t-\tfrac12gt^2\).                       │
│ • **Peak occurs when vertical velocity becomes zero**.                              │
└───────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────┐
│ **Derivation**                                                                     │
│                                                                                   │
│ 1. **Break the launch speed into components**                                    │
│    \[
│    v_{0x}=v_0\cos\theta,\qquad
│    v_{0y}=v_0\sin\theta
│    \]                                                                            │
│                                                                                   │
│ 2. **Vertical motion**                                                         │
│    \[
│    y(t)=v_{0y}t-\frac12gt^2
│    \]                                                                            │
│                                                                                   │
│ 3. **Time to reach the peak**                                                  │
│    At the peak, the vertical velocity \(v_y\) is zero:                          │
│    \[
│    v_y=v_{0y}-gt=0 \;\;\Longrightarrow\;\; t_{\text{peak}}=\frac{v_{0y}}{g}
│    \]                                                                            │
│                                                                                   │
│ 4. **Substitute \(t_{\text{peak}}\) into \(y(t)\)**                              │
│    \[
│    H_{\max}=v_{0y}\left(\frac{v_{0y}}{g}\right)-\frac12g\left(\frac{v_{0y}}{g}\right)^2
│    =\frac{v_{0y}^2}{2g}
│    \]                                                                            │
│                                                                                   │
│ 5. **Express in terms of launch speed and angle**                               │
│    \[
│    H_{\max}=\frac{(v_0\sin\theta)^2}{2g}
│    =\frac{v_0^2\sin^2\theta}{2g}
│    \]                                                                            │
│                                                                                   │
│ This is the closed‑form expression for the maximum height of a projectile.        │
└───────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────┐
│ **Main Formula**                                                                   │
│                                                                                   │
│     \[
│     H_{\max}=\frac{v_0^2\sin^2\theta}{2g}
│     \]                                                                            │
│                                                                                   │
│ [Explain Formula]   [Open Formula Lab]                                            │
└───────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────┐
│ **Summary**                                                                        │
│                                                                                   │
│ The maximum height of a projectile launched with speed \(v_0\) at an angle          │
│ \(\theta\) above the horizontal is given by \(\displaystyle H_{\max}=\frac{v_0^2\sin^2\theta}{2g}\).  │
│ It depends only on the vertical component of the launch velocity and the          │
│ acceleration due to gravity.                                                      │
└───────────────────────────────────────────────────────────────────────────────────────┘
