┌─────────────────────────────────────┐  
│ Introduction                        │  
│                                     │  
│ When a solid material is heated, its      │  
│ constituent atoms vibrate more vigorously, │  
│ causing the average distance between them │  
│ to increase. This macroscopic increase   │  
│ in size is called **thermal expansion**. │  
│ For a metal rod, the length grows as the │  
│ temperature rises.                       │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Definition                          │  
│                                     │  
│ **Thermal expansion** is the tendency of │  
│ matter to change its shape, area, or     │  
│ volume in response to a change in       │  
│ temperature. For solids, the change is   │  
│ usually linear (length) or volumetric.   │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Key Concepts                        │  
│                                     │  
│ • **Coefficient of linear expansion (α)** – │  
│   material‑specific constant (°C⁻¹) that │  
│   relates temperature change to length  │  
│   change.                                 │  
│ • **Coefficient of volumetric expansion (β)** – │  
│   ≈ 3α for isotropic solids.               │  
│ • Expansion is **reversible** if the material │  
│   stays within its elastic limit.          │  
│ • Constraints (fixed ends, joints) lead to   │  
│   thermal stress.                           │  
└─────────────────────────────────────┘

┌─────────────────────────────────────┐  
│ Applications                        │  
│                                     │  
│ • **Railways** – Gaps between rails are │  
│   provided to accommodate expansion. │  
│ • **Bridges & Pipelines** – Expansion │  
│   joints prevent buckling.            │  
│ • **Precision Instruments** – Materials│  
│   with low α (e.g., Invar) are chosen │  
│   to maintain dimensional stability. │  
│ • **Thermometers** – Mercury column │  
│   rises with temperature due to volume │  
│   expansion.                         │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Important Notes                     │  
│                                     │  
│ • The linear approximation ΔL = α L₀ ΔT holds   │
│   only for modest temperature ranges; │  
│   α itself can vary with temperature. │  
│ • If a rod is **fixed at both ends**, │  
│   heating creates compressive stress │  
│   σ = α E ΔT (E = Young’s modulus).   │  
│ • Sudden temperature changes can cause │  
│   thermal shock and fracture.         │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Summary                             │  
│                                     │  
│ • Heating a metal rod makes it longer. │  
│ • Linear expansion is quantified by │  
│   ΔL = α L₀ ΔT, where α is material‑specific. │  
│ • Volumetric expansion uses β ≈ 3α. │  
│ • Engineers design gaps, joints, and │  
│   select low‑α materials to manage │  
│   the effects.                       │  
└─────────────────────────────────────┘
