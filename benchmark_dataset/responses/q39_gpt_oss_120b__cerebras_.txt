┌───────────────────────────────────────┐
│ Wavelength                             │
│                                       │
│ The distance between two consecutive   │
│ points of the same phase on a wave –  │
│ for example, crest‑to‑crest or trough‑│
│ to‑trough. It is usually denoted by λ   │
│ and measured in meters (m).            │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Frequency                              │
│                                       │
│ The number of complete wave cycles that│
│ pass a given point each second. It is  │
│ expressed in hertz (Hz), where 1 Hz =   │
│ one cycle per second. Frequency is the│
│ inverse of the period (T): f = 1/T.     │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Amplitude                               │
│                                       │
│ The maximum displacement of a point   │
│ on the wave from its equilibrium (rest│
│ position). It indicates the wave’s     │
│ energy or intensity and is measured in │
│ the same units as the quantity being   │
│ displaced (e.g., meters for a mechanical│
│ wave, volts for an electromagnetic wave).│
└───────────────────────────────────────┘
