│               Definition               │
│                                       │
│ **Work** is the transfer of energy     │
│ that occurs when a force causes a      │
│ displacement of an object in the       │
│ direction of the force.                │
│                                       │
│ **SI Unit:** Joule (J) – one joule is   │
│ the work done when a force of one newton│
│ moves an object one meter (1 J = 1 N·m).│
