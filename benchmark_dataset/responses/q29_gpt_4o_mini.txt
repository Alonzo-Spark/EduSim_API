┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Surface tension is the    │
│ cohesive force at the     │
│ surface of a liquid that  │
│ causes it to behave like a │
│ stretched elastic membrane.│
└───────────────────────────┘

┌───────────────────────────┐
│ Factors Affecting Surface  │
│ Tension                    │
│                           │
│ 1. **Temperature**:       │
│    As temperature increases,│
│    surface tension tends to │
│    decrease.              │
│                           │
│ 2. **Impurities**:        │
│    The presence of surfactants│
│    or other additives can  │
│    lower surface tension.  │
│                           │
│ 3. **Nature of the Liquid**:│
│    Different liquids have  │
│    different cohesive forces,│
│    affecting surface tension.│
│                           │
│ 4. **Pressure**:          │
│    Changes in pressure can │
│    influence surface tension,│
│    though this effect is often│
│    less significant.      │
└───────────────────────────┘
