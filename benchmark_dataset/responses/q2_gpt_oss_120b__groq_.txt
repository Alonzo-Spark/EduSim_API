┌───────────────────────────────────────────────┐
│ Introduction                                    │
│                                                   │
│ A car is initially at rest (velocity = 0 m/s) and   │
│ then moves forward with a constant (uniform)      │
│ acceleration of **2 m/s²** for a duration of 10 s. │
│ The goal is to determine the car’s velocity after │
│ this time interval.                               │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Definition                                      │
│                                                   │
│ **Uniform (constant) acceleration** is the rate   │
│ of change of velocity with time when the           │
│ acceleration value does not vary.                 │
│                                                   │
│ Mathematically:                                   │
│     a = Δv / Δt                                   │
│ where **a** is acceleration, **Δv** is the change  │
│ in velocity, and **Δt** is the elapsed time.       │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Key Concepts                                    │
│                                                   │
│ • With constant acceleration, velocity varies     │
│   linearly with time.                              │
│ • The primary kinematic relation is               │
│   **v = u + a·t**, where:                          │
│     - v = final velocity                           │
│     - u = initial velocity                         │
│     - a = constant acceleration                    │
│     - t = elapsed time                             │
│                                                   │
│ This relation directly links the known quantities │
│ (u, a, t) to the unknown final velocity v.         │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Given Data (Responsive Table)                   │
│                                                   │
│ ┌───────────────┬───────┐                         │
│ │ Quantity      │ Value │                         │
│ ├───────────────┼───────┤                         │
│ │ Initial speed u│ 0 m/s │                         │
│ │ Acceleration a │ 2 m/s²│                         │
│ │ Time t         │10 s   │                         │
│ └───────────────┴───────┘                         │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Main Formula                                     │
│                                                   │
│                v = u + a·t                        │
│                                                   │
│ [ Explain Formula ]   [ Open Formula Lab ]        │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Solution Steps                                   │
│                                                   │
│ 1. Identify the known values:                     │
│    • u = 0 m/s                                     │
│    • a = 2 m/s²                                    │
│    • t = 10 s                                      │
│                                                   │
│ 2. Substitute them into the formula **v = u + a·t**│
│                                                   │
│ 3. Compute:                                        │
│    v = 0 m/s + (2 m/s²)(10 s) = 20 m/s              │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Result                                           │
│                                                   │
│ The car’s velocity after 10 seconds is **20 m/s**.│
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Summary                                          │
│                                                   │
│ • Uniform acceleration means a constant a.        │
│ • The linear velocity‑time relation is v = u + a·t│
│ • Plugging u = 0 m/s, a = 2 m/s², t = 10 s gives   │
│   v = 20 m/s.                                      │
│                                                   │
│ This demonstrates how a simple kinematic formula   │
│ quickly yields the final speed for uniformly       │
│ accelerated motion.                               │
└───────────────────────────────────────────────┘
