┌───────────────────────────┐
│ Quick Definition           │
│                           │
│ Inertia is the property of matter that resists changes in its state of   │
│ motion. It is the tendency of an object to remain at rest or to keep      │
│ moving at a constant velocity unless acted upon by an external force.     │
└───────────────────────────┘

┌───────────────────────────┐
│ Types of Inertia           │
│                           │
│ 1. **Rest Inertia** – The resistance to starting motion. An object at   │
│    rest will stay at rest until a net external force is applied.          │
│ 2. **Translational Inertia** – The resistance to changes in linear      │
│    motion. It is proportional to the mass of the object and determines   │
│    how much force is needed to accelerate it.                              │
│ 3. **Rotational Inertia** – The resistance to changes in rotational     │
│    motion. Also known as the moment of inertia, it depends on both the     │
│    mass and how that mass is distributed relative to the axis of rotation.│
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes            │
│                           │
│ • Inertia is directly proportional to mass.                                │
│ • Newton’s first law (law of inertia) states that an object will remain   │
│   in uniform motion unless acted upon by a net external force.             │
│ • Rotational inertia is analogous to mass in linear motion but includes   │
│   geometry of the object.                                                 │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                    │
│                           │
│ Inertia is the innate resistance of matter to changes in motion,          │
│ encompassing rest, translational, and rotational aspects. It is the       │
│ foundational concept behind Newton’s first law and governs the dynamics   │
│ of all physical systems.                                                  │
└───────────────────────────┘
