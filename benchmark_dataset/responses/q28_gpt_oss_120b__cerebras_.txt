┌─────────────────────────────┐  
│          Introduction        │  
├─────────────────────────────┤  
│ Archimedes’ principle explains│  
│ how a fluid exerts an upward │  
│ force on any object immersed │  
│ in it. This upward force,    │  
│ called the **buoyant force**,│  
│ is equal to the weight of the│  
│ fluid that the object displaces.│  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│            Definition        │  
├─────────────────────────────┤  
│ *Archimedes’ principle*: The │  
│ magnitude of the buoyant     │  
│ force acting on a body immersed│  
│ in a fluid equals the weight  │  
│ of the fluid displaced by the │  
│ body.                         │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│          Key Concepts        │  
├─────────────────────────────┤  
│ • **Fluid** – liquid or gas that│  
│   can flow and transmit pressure.│  
│ • **Displaced volume (V)** –  │  
│   the volume of fluid that would│  
│   occupy the space taken by the│  
│   object.                     │  
│ • **Density (ρ)** – mass per   │  
│   unit volume of the fluid.   │  
│ • **Gravitational acceleration│  
│   (g)** – ≈ 9.81 m s⁻² on Earth.│  
│ • **Buoyant force (F_b)** –   │  
│   upward force given by the   │  
│   formula in the next card.   │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│            Formula           │  
├─────────────────────────────┤  
│ Main Formula                 │  
│                               │  
│  **F_b = ρ · V · g**           │  
│                               │  
│ [ Explain Formula ]          │  
│ [ Open Formula Lab ]          │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│          Applications        │  
├─────────────────────────────┤  
│ *Example*: A solid steel ball  │  
│ (ρ ≈ 7,800 kg m⁻³) is gently   │  
│ placed in water (ρ ≈ 1,000 kg│  
│ m⁻³). The ball sinks because │  
│ its weight (m g) exceeds the  │  
│ buoyant force.                │  
│                               │  
│ *Floating example*: A wooden │  
│ block (ρ ≈ 600 kg m⁻³) of volume │  
│ 0.020 m³ is placed in water.   │  
│ Displaced fluid mass = ρ_water│  
│·V = 1,000 kg m⁻³ · 0.020 m³ =  │  
│20 kg → weight of displaced   │  
│fluid = 20 kg·g ≈ 196 N.      │  
│ Block mass = ρ_wood·V = 600│  
│ kg m⁻³·0.020 m³ = 12 kg → weight│  
│≈ 118 N. Since 196 N > 118 N, │  
│the buoyant force lifts the    │  
│block, and it floats.          │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│          Advantages          │  
├─────────────────────────────┤  
│ • Simple, universal law that  │  
│   applies to all fluids.      │  
│ • Provides a direct way to    │  
│   determine unknown densities │  
│   or volumes.                  │  
│ • Basis for many engineering   │  
│   designs (ships, submarines).│  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│         Disadvantages        │  
├─────────────────────────────┤  
│ • Assumes fluid is incompress│  
│   ible and at rest – not true │  
│   for high‑speed or turbulent │  
│   flows.                       │  
│ • Surface tension effects are│  
│   ignored, which can be important│  
│   for very small objects.      │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│        Important Notes       │  
├─────────────────────────────┤  
│ • The principle holds for    │  
│   *any* fluid (liquid or gas).│  
│ • Buoyant force acts through│  
│   the center of pressure, which│  
│   coincides with the centroid │  
│   of the displaced volume.    │  
│ • If the object's density equals│  
│   the fluid density, it *neither*│  
│   sinks nor rises (neutral buoyancy).│  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│            Summary           │  
├─────────────────────────────┤  
│ Archimedes’ principle states │  
│ that an immersed object experiences│  
│ an upward buoyant force equal to│  
│ the weight of the fluid it displaces.│  
│ The magnitude is given by **F_b = ρ V g**.│  
│ This principle explains why objects│  
│ float, sink, or remain neutrally   │  
│ buoyant, and underpins designs of│  
│ ships, balloons, and hydrometers.│  
└─────────────────────────────┘
