┌───────────────────────────────────────────────────────────────────────┐  
│ **Introduction**                                                        │  
│                                                                           │  
│ The acceleration due to gravity, denoted \(g\), is the acceleration   │  
│ a body experiences when it is attracted toward a massive object, such   │  
│ as Earth, by the force of gravity. This quantity is constant at the    │  
│ surface of a uniform sphere but varies with distance from the center   │  
│ of the mass.                                                             │  
└───────────────────────────────────────────────────────────────────────┘  

┌───────────────────────────────────────────────────────────────────────┐  
│ **Key Concepts**                                                        │  
│                                                                           │  
│ • Newton’s law of universal gravitation: \(F = G\,\dfrac{m_1m_2}{r^2}\) │  
│ • Centripetal acceleration for a circular orbit: \(a = \dfrac{v^2}{r}\)   │  
│ • For a small body orbiting a massive body, \(m_1 \ll m_2\) and the     │  
│   acceleration of the small body is the same as the gravitational      │  
│   acceleration it would have if it fell freely.                         │  
└───────────────────────────────────────────────────────────────────────┘  

┌───────────────────────────────────────────────────────────────────────┐  
│ **Derivation**                                                          │  
│                                                                           │  
│ 1. **Start with Newton’s law of gravitation**:                         │  
│    \(\displaystyle F = G\,\frac{M\,m}{r^2}\)                              │  
│    where \(M\) is the mass of Earth, \(m\) is the mass of the falling    │  
│    body, and \(r\) is the distance from Earth’s center to the body.     │  
│                                                                           │  
│ 2. **Relate force to acceleration**: \(F = m\,a\).                       │  
│                                                                           │  
│ 3. **Equate the two expressions for \(F\)**:                             │  
│    \(\displaystyle m\,a = G\,\frac{M\,m}{r^2}\).                         │  
│                                                                           │  
│ 4. **Cancel the mass \(m\) of the falling body** (non‑zero):              │  
│    \(\displaystyle a = \frac{G\,M}{r^2}\).                               │  
│                                                                           │  
│ 5. **Define \(a\) as the acceleration due to gravity \(g\)**, and set    │  
│    \(r = R\), the radius of the Earth at the surface.                    │  
│                                                                           │  
│ 6. **Resulting formula**:                                               │  
│    \(\displaystyle g = \frac{G\,M}{R^2}\).                               │  
│                                                                           │  
│ This shows that the gravitational acceleration depends only on the mass │  
│ of the attracting body and the square of the distance from its center. │  
└───────────────────────────────────────────────────────────────────────┘

│ **Applications**                                                        │  
│                                                                           │  
│ • Calculating free‑fall time from a given height: \(t = \sqrt{2h/g}\).  │  
│ • Determining orbital speeds: \(v = \sqrt{gR}\).                         │  
│ • Engineering designs that rely on precise weight calculations.          │  
└───────────────────────────────────────────────────────────────────────┘  

┌───────────────────────────────────────────────────────────────────────┐  
│ **Summary**                                                             │  
│                                                                           │  
│ The acceleration due to gravity at a distance \(r\) from a massive body │  
│ is \(g = \dfrac{G\,M}{r^2}\). At Earth’s surface (where \(r = R\)), it │  
│ is approximately \(9.81\,\text{m/s}^2\). This result follows directly │  
│ from Newton’s law of universal gravitation and the definition of        │  
│ centripetal acceleration.                                               │
