┌──────────────────────────────────────────────────────────────┐
│ 1. Change of State (Phase Transition)                         │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│ **Quick Definition**                                         │
│ Change of state is the physical process in which matter      │
│ transitions from one state (solid, liquid, or gas) to        │
│ another. It does not involve a chemical change in the        │
│ substance.                                                    │
│                                                              │
│ **Key Characteristics**                                      │
│ • **Reversible:** Processes like melting and freezing are     │
│   reversible.                                                 │
│ • **Energy Transfer:** Energy is either absorbed or          │
│   released during the transition.                             │
│ • **Temperature Constancy:** During the actual change of     │
│   state, the temperature of the substance remains constant   │
│   until the transition is complete.                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 2. Latent Heat                                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│ **Definition**                                               │
│ Latent heat is the specific amount of heat energy absorbed   │
│ or released by a substance during a change of state at a     │
│ constant temperature.                                        │
│                                                              │
│ **Why "Latent"?**                                            │
│ The term comes from the Latin *latere* (to lie hidden).      │
│ Unlike "sensible heat," which causes a temperature change    │
│ that you can feel with a thermometer, latent heat is         │
│ "hidden" because it causes a phase change without a          │
│ change in temperature.                                       │
│                                                              │
│ **The Mechanism**                                            │
│ During melting or boiling, absorbed heat energy is used to   │
│ overcome the intermolecular forces holding particles         │
│ together (increasing potential energy) rather than           │
│ increasing the kinetic energy (speed) of the particles.      │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ Main Formula                                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                     $$ Q = m \cdot L $$                      │

┌──────────────────────────────────────────────────────────────┐
│ 3. Variables & Types of Latent Heat                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│ **Formula Variables**                                        │
│                                                              │
│ | Symbol | Quantity | Unit | Description                     │
│ | :--- | :--- | :--- | :--- |                                │
│ | $Q$ | Heat Energy | Joules (J) | Total energy absorbed     │
│ | | | | or released.                │
│ | $m$ | Mass | Kilograms (kg) | Mass of the substance.       │
│ | $L$ | Specific Latent Heat | J/kg | Energy per kg for      │
│ | | | | the specific phase change.   │
│                                                              │
│ **Common Types ($L$)**                                       │
│                                                              │
│ | Type | Process | Direction of Heat Flow | Description     │
│ | :--- | :--- | :--- | :--- |                                │
│ | **Fusion** | Melting / Freezing | Absorbed / Released |   │
│ | | | | Between Solid and Liquid.    │
│ | **Vaporization**| Boiling / Condensing| Absorbed / Released│
│ | | | | Between Liquid and Gas.      │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ Important Notes                                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│ • **Specific Latent Heat of Vaporization** is usually much   │
│   higher than **Specific Latent Heat of Fusion**. This is    │
│   because particles in a gas are completely separated,       │
│   requiring significantly more energy to overcome all        │
│   attractive forces compared to just weakening them in       │
│   a liquid.                                                   │
│                                                              │
│ • **Heating Curves:** If you graph temperature vs. time for  │
│   a heated substance, the "flat lines" (plateaus) represent  │
│   the latent heat at work (phase change), while the sloped   │
│   lines represent sensible heat (temperature rise).          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
