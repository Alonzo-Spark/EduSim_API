## Introduction
Electrical energy is one of the most widely used forms of energy in the modern world. From lighting up our homes to powering massive industrial machines, understanding how electrical energy is consumed and transferred is crucial. This module focuses specifically on **Electrical Power**—the rate at which this energy is used.

## Definition
**Electrical Power** is defined as the rate at which electrical energy is transferred by an electric circuit. The SI unit of power is the **Watt (W)**, named after James Watt. One watt is defined as the consumption of one joule of energy per second.

## Key Concepts
To understand power, we must revisit three fundamental quantities:
*   **Voltage (V):** The potential difference or electric pressure that pushes electrons.
*   **Current (I):** The flow of electric charge (electrons).
*   **Energy (W):** The total work done by the circuit.

Power tells us *how fast* energy is being used, not necessarily how much total energy is used.

## Derivation
We start with the basic definition of power in physics:
$$ P = \\frac{W}{t} $$
Where:
*   $P$ is Power
*   $W$ is Work Done (Electrical Energy)
*   $t$ is Time

We know from electric potential definitions that the work done to move a charge $Q$ across a potential difference $V$ is:
$$ W = V \\times Q $$

Substitute $W$ into the power equation:
$$ P = \\frac{V \\times Q}{t} $$

We also know that electric current is the rate of flow of charge ($I = Q/t$), which means $Q = I \\times t$.

Substituting $Q = I \\times t$ into our equation:
$$ P = \\frac{V \\times (I \\times t)}{t} $$

The time $t$ cancels out:
$$ P = V \\times I $$

## Main Formula
The relationship between Power, Voltage, and Current is one of the most fundamental formulas in electrical engineering.

$$ P = VI $$

## Applications
This formula is used universally to determine the power rating of appliances.
*   **Heaters:** High current at standard voltage produces high heating power.
*   **LEDs:** Low current results in low power consumption (efficiency).
*   **Computers:** Power supplies are rated in Watts (e.g., 500W) based on the max voltage and current they can handle.

## Important Notes
*   Power is a scalar quantity (it has magnitude but no direction).
*   1 Horsepower (HP) is approximately equal to 746 Watts.
*   The formula $P=VI$ applies to DC circuits and purely resistive AC circuits.

## Summary
In this lesson, we defined electrical power as the rate of energy consumption. By combining the definitions of Voltage ($V$), Current ($I$), and Work ($W$), we derived the fundamental relationship $$ P = VI $$.

## Suggested Questions
1.  Calculate the power of a bulb operating at 220V with a current of 0.5A.
2.  If a device has a power rating of 100W and operates at 5V, what is the current draw?
3.  Why does a high-power appliance typically need thicker wires?
`;

        // ==========================================
        // 3. PARSER & RENDERER

        function parseAndRender() {
            const app = document.getElementById('app');
            
            // Split content into sections based on "##"
            const rawSections = sourceContent.split(/^##\s+/gm).filter(s => s.trim() !== '');
            
            rawSections.forEach(sectionText => {
                // Extract Title (First Line)
                const firstLineBreak = sectionText.indexOf('\n');
                const title = sectionText.substring(0, firstLineBreak).trim();
                let body = sectionText.substring(firstLineBreak + 1).trim();

                // Check for Display Formulas ($$ ... $$)
                const formulaRegex = /\$\$(.*?)\$\$/gs;
                let match;
                let hasFormula = false;
                let extractedFormula = null;

                // We only extract the FIRST formula for the "Main Formula Card" logic 
                // or treat specific sections as Formula Cards.
                // For this system: If the section is "Main Formula" or "Derivation", we handle it specially.
                
                if ((title === "Main Formula" || title === "Derivation") && (match = formulaRegex.exec(body))) {
                    // Extract the formula string
                    const latex = match[1].trim();
                    
                    // Store in registry
                    const formulaId = `formula-${formulaRegistry.length}`;
                    formulaRegistry.push({
                        id: formulaId,
                        latex: latex,
                        title: title === "Main Formula" ? "Power Formula" : "Derivation Step",
                        context: title
                    });

                    // Remove formula from text body if we want to isolate it, 
                    // but for "Main Formula" we want ONLY the formula card.
                    if (title === "Main Formula") {
                        renderFormulaCard(title, latex, formulaId);
                        return; 
                    }
                }

                // Standard Section Rendering
                renderStandardCard(title, body);
            });
        }

        // ==========================================
        // 4. COMPONENT RENDERERS

        function getIconForTitle(title) {
            const map = {
                'Introduction': '📖',
                'Definition': '📝',
                'Key Concepts': '💡',
                'Derivation': '🧮',
                'Main Formula': '⚡',
                'Applications': '🔌',
                'Important Notes': '⚠️',
                'Summary': '📌',
                'Suggested Questions': '❓'
            };
            return map[title] || '📄';
        }

        function renderStandardCard(title, content) {
            const card = document.createElement('article');
            card.className = 'card';
            
            const icon = getIconForTitle(title);

            // Convert inline math ($...$) and basic markdown
            let processedContent = content
                .replace(/\$(.*?)\$/g, (match, math) => {
                    try { return katex.renderToString(math, { throwOnError: false, displayMode: false }); } catch(e) { return match; }
                })
                .replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>') // Bold
                .replace(/\n/g, '<br>'); // Line breaks

            // Handle lists simply
            if (processedContent.includes('* ')) {
                const lines = processedContent.split('<br>');
                const listItems = lines.filter(l => l.trim().startsWith('* ')).map(l => `<li>${l.replace('* ', '')}</li>`).join('');
                const nonList = lines.filter(l => !l.trim().startsWith('* ')).join('<br>');
                processedContent = nonList + (nonList && listItems ? '<br><ul>' : '<ul>') + listItems + '</ul>';
            }

            card.innerHTML = `
                <div class="card-header">
                    <div class="card-icon">${icon}</div>
                    <h2 class="card-title">${title}</h2>
                </div>
                <div class="card-content">
                    ${processedContent}
                </div>
            `;
            
            document.getElementById('app').appendChild(card);
        }

        function renderFormulaCard(title, latex, id) {
            const card = document.createElement('article');
            card.className = 'card formula-card';
            
            const renderedMath = katex.renderToString(latex, { throwOnError: false, displayMode: true });

            card.innerHTML = `
                <div class="card-header">
                    <div class="card-icon" style="color: var(--accent); background: #fffbeb;">⚡</div>
                    <h2 class="card-title">${title}</h2>
                </div>
                <div class="card-content">
                    <p>The fundamental relation for electrical power is:</p>
                    <div class="formula-display">
                        ${renderedMath}
                    </div>
                    <div class="formula-actions">
                        <button class="btn btn-outline" onclick="toggleExplanation(this)">
                            Explain Formula
                        </button>
                        <button class="btn btn-primary" onclick="openLab('${id}')">
                            Open Formula Lab
                        </button>
                    </div>
                    <div class="explanation-box">
                        <strong>Variables:</strong><br>
                        <strong>P</strong>: Power (Watts)<br>
                        <strong>V</strong>: Voltage (Volts)<br>
                        <strong>I</strong>: Current (Amperes)<br><br>
                        This equation states that the power consumed by a device is equal to the electrical potential difference across it multiplied by the current flowing through it.
                    </div>
                </div>
            `;
            
            document.getElementById('app').appendChild(card);
        }

        function toggleExplanation(btn) {
            const box = btn.parentElement.nextElementSibling;
            box.classList.toggle('visible');
            btn.textContent = box.classList.contains('visible') ? "Hide Explanation" : "Explain Formula";
        }

        function openLab(formulaId) {
            const formula = formulaRegistry.find(f => f.id === formulaId);
            if (!formula) return;

            const modal = document.getElementById('labModal');
            const content = document.getElementById('modalContent');

            const v = parseFloat(document.getElementById('input-v').value);

        // ==========================================
        window.addEventListener('DOMContentLoaded', () => {
            // Wait for KaTeX to be ready if needed, though script is defer
            if (window.katex) {
                parseAndRender();
            } else {
                // Fallback if CDN loads slowly (simple timeout check)
                setTimeout(() => {
                    if (window.katex) parseAndRender();
                    else console.error("KaTeX failed to load");
                }, 500);
            }
        });
