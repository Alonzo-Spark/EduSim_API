┌───────────────────────────────────────────────┐
│                     Introduction                │
│                                               │
│ The electric force is one of the fundamental   │
│ interactions in nature.  It describes how two   │
│ point charges influence each other through     │
│ the electric field they generate.  Understanding│
│ its quantitative form allows us to predict the │
│ behavior of everything from atomic nuclei to  │
│ everyday electrostatic phenomena.             │
└───────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│                     Definition                  │
│                                               │
│ **Electric force** is the force exerted by one │
│ point charge on another due to their electric │
│ fields.  For static (non‑moving) point charges,│
│ this force follows **Coulomb’s law**.          │
└───────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│                     Key Concepts                │
│                                               │
│ • **Charge (q₁, q₂)** – scalar quantities that │
│   can be positive or negative.                │
│ • **Separation (r)** – straight‑line distance  │
│   between the charge centers.                 │
│ • **Coulomb constant (k)** – a universal      │
│   constant \(k = \dfrac{1}{4\pi\varepsilon_0}\)│
│   ≈ 8.9875 × 10⁹ N·m²·C⁻².                     │
│ • **Medium permittivity (ε₀)** – vacuum         │
│   permittivity, the ability of free space to   │
│   permit electric field lines.                │
└───────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│                     Formula Card                │
│                                               │
│                 **Coulomb’s Law**              │
│                                               │
│   \[                                            │
│   \displaystyle F = k\,\frac{|q_{1}q_{2}|}{r^{2}} │
│   \]                                            │
│                                               │
│   • **F** – magnitude of the electric force   │
│   • **q₁, q₂** – magnitudes of the two charges│
│   • **r** – distance between the charges       │
│   • **k** – Coulomb constant (≈ 8.99 × 10⁹ N·m²│
│     ·C⁻²)                                      │
│                                               │
│   [ Explain Formula ]   [ Open Formula Lab ]   │
└───────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│                     Derivation                  │
│                                               │
│  1. **Start from the definition of electric   │
│     field (E)** produced by a point charge   │
│     q₁ at a distance r:                       │
│        \[ E = k\,\dfrac{|q_{1}|}{r^{2}} \]    │
│                                               │
│  2. **Force on a second charge q₂** placed in │
│     that field is:**                           │
│        \[ \mathbf{F} = q_{2}\,\mathbf{E} \]   │
│                                               │
│  3. **Insert the expression for E**:           │
│        \[ \mathbf{F} = q_{2}\,k\,\frac{|q_{1}|}{r^{2}} \] │
│                                               │
│  4. **Take the magnitude and combine the      │
│     absolute values:**                        │
│        \[ F = k\,\frac{|q_{1}q_{2}|}{r^{2}} \]│
│                                               │
│  5. **Direction** – the force is along the line│
│     joining the charges; it is attractive if │
│     the charges have opposite signs and       │
│     repulsive if they have the same sign.     │
└───────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│                     Applications                │
│                                               │
│ • Predicting the force between electrons in   │
│   atoms and molecules.                        │
│ • Designing electrostatic precipitators for   │
│   air‑cleaning systems.                       │
│ • Calculating forces in particle accelerators │
│   and beam dynamics.                          │
│ • Understanding static cling, lightning, and  │
│   everyday electrostatic phenomena.           │
└───────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│                     Summary                     │
│                                               │
│ The electric force between two point charges  │
│ follows Coulomb’s law:                        │
│                                               │
│   \[ F = k\,\dfrac{|q_{1}q_{2}|}{r^{2}} \]    │
│                                               │
│ It depends linearly on each charge, inversely │
│ on the square of their separation, and is      │
│ mediated by the universal constant k.  The     │
│ sign of the product \(q_{1}q_{2}\) determines   │
│ whether the interaction is attractive or       │
│ repulsive.                                     │
└───────────────────────────────────────────────┘
