┌───────────────────────────┐
│ Introduction          │
│                       │
│ Mass and weight are related │
│ but distinct concepts in   │
│ physics.                 │
└───────────────────────────┘

┌───────────────────────────┐
│ Definition            │
│                       │
│ Mass measures the amount   │
│ of matter.                 │
│                       │
│ Weight is the force exerted │
│ on an object due to gravity │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts          │
│                       │
│ Mass is a property         │
│                       │
│ Weight is a force that     │
│ depends on gravity.        │
└───────────────────────────┘

┌───────────────────────────┐
│ Characteristics      │
│                       │
│ Mass is constant regardless │
│ of location; weight varies │
│ with gravitational field.  │
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes      │
│                       │
│ On Earth, weight is often │
│                       │
│ approximated as mass times │
│ 9.81 m/s².           │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary              │
│                       │
│ Mass is measure of matter │
│                       │
│ weight is the gravitational │
│ force on that mass.       │
└───────────────────────────┘
