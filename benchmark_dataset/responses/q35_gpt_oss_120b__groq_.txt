┌─────────────────────────────┐
│ Definition                   │
│                               │
│ Latent heat is the amount of │
│ heat energy absorbed or      │
│ released by a substance       │
│ during a change of state      │
│ without a change in           │
│ temperature.                  │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Key Concepts                  │
│                               │
│ - Phase change occurs at      │
│   constant temperature.      │
│ - Energy goes into breaking   │
│   forming intermolecular      │
│   bonds.                      │
│ - No temperature rise until   │
│   transition complete.        │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Main Formula                  │
│                               │
│ Q = mL                        │
│                               │
│ Q: heat transferred (J)       │
│ m: mass (kg)                  │
│ L: latent heat (J / kg)       │
│                               │
│ [ Explain Formula ]           │
│ [ Open Formula Lab ]          │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Applications                  │
│                               │
│ - Melting ice (L_fus = 334 kJ/│
│   kg)                         │
│ - Boiling water (L_vap =      │
│   2260 kJ/kg)                 │
│ - Condensation of steam       │
│ - Sublimation of dry ice      │
└─────────────────────────────┘

┌─────────────────────────────┐
│ Important Notes               │
│                               │
│ • Latent heat depends on the  │
│   substance and on the type   │
│   of phase change.            │
│ • During a change of state,   │
│   temperature remains        │
│   constant despite heat input.│
│ • The same amount of heat     │
│   causes different temperature│
│   changes for different phases│
│   because energy is used to   │
│   alter molecular arrangement.│
└─────────────────────────────┘

┌─────────────────────────────┐
│ Summary                       │
│                               │
│ Latent heat is the energy     │
│ required for a substance to   │
│ change its phase without      │
│ changing temperature. The    │
│ relationship Q = mL links the│
│ heat transferred to the mass │
│ of material and its specific  │
│ latent heat. Phase changes    │
│ occur at fixed temperatures, │
│ with energy going into breaking│
│ or forming intermolecular     │
│ bonds.                         │
└─────────────────────────────┘
