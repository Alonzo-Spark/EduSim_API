┌───────────────────────────┐
│ Quick Definition           │
│                           │
│ Voltage is the electric   │
│ potential difference      │
│ between two points in a   │
│ circuit.                   │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concept                │
│                           │
│ Ohm’s Law relates voltage │
│ (V), current (I), and     │
│ resistance (R):           │
│ V = I × R.                 │
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula               │
│                           │
│ \(V = I \times R\)        │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

┌───────────────────────────┐
│ Application                │
│                           │
│ • Current, I = 2 A        │
│ • Resistance, R = 10 Ω   │
│ • Voltage, V = 2 A ×      │
│   10 Ω = 20 V             │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                    │
│                           │
│ A 2 A current through a   │
│ 10 Ω resistor produces a │
│ voltage of 20 V across    │
│ the resistor.             │
└───────────────────────────┘
