┌───────────────────────────────────────────────┐  
│ Quick Definition                              │  
│                                               │  
│ Projectile motion is the two‑dimensional      │  
│ trajectory of an object that is launched      │  
│ into the air and moves under the influence   │  
│ of gravity alone (ignoring air resistance). │  
│                                               │  
│ The motion can be decomposed into a horizontal│  
│ component that moves at constant velocity and │  
│ a vertical component that accelerates          │  
│ downward at 9.81 m s⁻².                       │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Key Concepts                                  │  
│                                               │  
│ • Initial speed \(v_0\) and launch angle      │  
│   \(\theta\) determine the trajectory.        │  
│ • Horizontal distance (range) depends on      │  
│   \(v_0^2\sin 2\theta\).                      │  
│ • Maximum height occurs when vertical speed   │  
│   becomes zero.                               │  
│ • Time of flight is independent of horizontal │  
│   motion.                                     │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Characteristics of Projectile Motion          │  
│                                               │  
│ 1. Parabolic trajectory: The path is a       │  
│    parabola described by quadratic equations.│  
│ 2. Independent horizontal and vertical        │  
│    motions: horizontal velocity is constant,  │  
│    vertical velocity changes linearly.        │  
│ 3. Symmetry: The ascent and descent are        │  
│    mirror images if air resistance is ignored.│  
│ 4. Range and height are maximized at 45°      │  
│    launch angle for a given initial speed.    │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Main Formula                                   │  
│                                               │  
│ \[ y = v_0 \sin\theta \, t \;-\; \tfrac12 g t^2 \] │  
│ \[ x = v_0 \cos\theta \, t \]                 │  
│                                               │  
│ [ Explain Formula ]   |   [ Open Formula Lab ]│  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Range Formula                                 │  
│                                               │  
│ \[ R = \frac{v_0^2 \sin 2\theta}{g} \]        │  
│                                               │  
│ [ Explain Formula ]   |   [ Open Formula Lab ]│  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Summary                                        │  
│                                               │  
│ Projectile motion is governed by simple        │  
│ kinematic equations once the initial speed     │  
│ and angle are known. The motion splits into    │  
│ independent horizontal and vertical motions,  │  
│ yielding a parabolic path. Key metrics such as │  
│ maximum height, time of flight, and range can  │  
│ be derived directly from the equations above. │  
└───────────────────────────────────────────────┘
