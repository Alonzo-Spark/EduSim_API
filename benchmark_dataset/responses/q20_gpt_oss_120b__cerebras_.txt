┌─────────────────────────────────────┐
│ Introduction                         │
│                                     │
│ Mechanical energy is the sum of     │
│ kinetic energy (KE) and potential    │
│ energy (PE) of a system. When only   │
│ conservative forces (like gravity)   │
│ act, the total mechanical energy       │
│ remains constant. This principle      │
│ underlies many everyday phenomena,    │
│ from roller‑coaster rides to          │
│ satellite orbits.                     │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Definition                           │
│                                     │
│ **Conservation of Mechanical Energy**│
│                                      │
│ The total mechanical energy (E_mech) │
│ of an isolated system stays the same │
│ over time if no non‑conservative forces│
│ (e.g., friction, air resistance) do   │
│ work on the system.                    │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Key Concepts                         │
│                                     │
│ • **Kinetic Energy (KE)**            │
│   \( KE = \dfrac{1}{2} m v^{2} \)    │
│ • **Potential Energy (PE)**          │
│   For gravity: \( PE = m g h \)      │
│ • **Conservative Force** – a force   │
│   whose work depends only on         │
│   initial and final positions.       │
│ • **Non‑conservative Force** –       │
│   dissipates mechanical energy (e.g.,│
│   friction).                         │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Main Formula                         │
│                                     │
│   \[ KE_i + PE_i = KE_f + PE_f \]   │
│                                     │
│   (Total mechanical energy is       │
│   conserved.)                       │
│                                     │

┌─────────────────────────────────────┐
│ Example – Falling Object             │
│                                     │
│ **Scenario**: A 2 kg ball is dropped   │
│ from a height of 5 m. Ignoring air      │
│ resistance, find its speed just before   │
│ it hits the ground.                     │
│                                     │
│ **Step‑by‑Step**                       │
│ 1. At the top (initial):                │
│    • \( v_i = 0 \) → \( KE_i = 0 \)     │
│    • \( h_i = 5 \text{m} \) →           │
│      \( PE_i = m g h_i = 2·9.8·5 = 98 J \)│
│ 2. At the bottom (final):               │
│    • \( h_f = 0 \) → \( PE_f = 0 \)     │
│    • Unknown \( v_f \) → \( KE_f = \dfrac{1}{2} m v_f^{2} \)│
│ 3. Apply conservation:                  │
│    \[ KE_i + PE_i = KE_f + PE_f \]      │
│    \[ 0 + 98 = \dfrac{1}{2}·2·v_f^{2} + 0 \]│
│    \[ 98 = v_f^{2} \]                   │
│    \[ v_f = \sqrt{98} ≈ 9.9 \text{m/s} \]│
│                                     │
│ **Result**: The ball hits the ground   │
│ at about **9.9 m/s**.                  │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Applications                         │
│                                     │
│ • Roller‑coaster design – ensuring    │
│   that the sum of KE and PE remains    │
│   constant for safe speed limits.      │
│ • Satellite motion – orbital energy   │
│   stays constant absent atmospheric drag│
│ • Pendulum swings – exchange between   │
│   KE and PE.                           │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Advantages                           │
│                                     │
│ • Provides a simple way to predict    │
│   speeds and heights without solving    │
│   differential equations.              │
│ • Highlights the interchangeable       │
│   nature of kinetic and potential       │
│   energy.                               │
│ • Works for any conservative force    │
│   field (gravity, spring).              │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Disadvantages                        │
│                                     │
│ • Breaks down when friction or air    │
│   resistance is significant.          │
│ • Does not account for energy lost to  │
│   heat, sound, or deformation.        │
│ • Requires identification of all       │
│   conservative forces present.        │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Important Notes                      │
│                                     │
│ • Always define the zero level for   │
│   potential energy (commonly ground).│
│ • Conservation applies only to       │
│   isolated systems – check for       │
│   external work.                      │
│ • In many real‑world problems, add   │
│   a term for work done by non‑conservative│
│   forces: \( KE_i+PE_i+W_{nc}=KE_f+PE_f \).│
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Summary                              │
│                                     │
│ The conservation of mechanical energy│
│ states that, in the absence of         │
│ non‑conservative forces, the total     │
│ kinetic plus potential energy of a     │
│ system remains unchanged. Using the    │
│ formula \( KE_i+PE_i = KE_f+PE_f \) we│
│ can solve for unknown speeds or heights│
│ in many scenarios, such as the falling │
│‑ball example above.                    │
└─────────────────────────────────────┘
