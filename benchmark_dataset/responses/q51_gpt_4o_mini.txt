Let's explore how changing the mass of a simple pendulum affects its period through structured sections.

┌───────────────────────────┐
│ Quick Introduction         │
│                           │
│ The period of a simple    │
│ pendulum is influenced by  │
│ its length and the force   │
│ of gravity, but is         │
│ independent of mass.      │
└───────────────────────────┘

┌───────────────────────────┐
│ Definition                │
│                           │
│ A simple pendulum is a    │
│ weight (or bob) attached   │
│ to a string of fixed length │
│ that swings back and forth.│
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ - **Period (T)**: Time   │
│   taken for one complete   │
│   cycle of motion.       │
│ - **Length (L)**: Distance│
│   from the pivot to the    │
│   center of mass of the    │
│   bob.                    │
│ - **Gravity (g)**: Acceleration│
│   due to gravity.        │
└───────────────────────────┘

┌───────────────────────────┐
│ Formula                   │
│                           │
│ The period of a simple    │
│ pendulum is given by:     │
│                           │
┌───────────────────────────┐
│ Main Formula              │
│                           │
│     $$T = 2\pi \sqrt{\frac{L}{g}}$$       │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

┌───────────────────────────┐
│ Applications              │
│                           │
│ Simple pendulums are used │
│ in clocks, amusement park  │
│ rides, and various scientific│
│ experiments.              │
└───────────────────────────┘

┌───────────────────────────┐
│ Advantages                │
│                           │
│ - Simple to understand and│
│   demonstrate.            │
│ - Useful in various real-  │
│   world applications.      │
└───────────────────────────┘

┌───────────────────────────┐
│ Disadvantages             │
│                           │
│ - Assumes no air resistance│
│   and a massless string.   │
│ - Not suitable for large   │
│   angles.                 │
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes           │
│                           │
│ - The mass does not impact │
│   the period; only the     │
│   length and gravity do.   │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                   │
│                           │
│ Changing the mass of a    │
│ simple pendulum does not   │
│ affect its period. The     │
│ period depends solely on   │
│ the length of the pendulum │
│ and acceleration due to    │
│ gravity.                  │
└───────────────────────────┘
