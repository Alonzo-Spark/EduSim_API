┌───────────────────────────────────────────────────────┐
│ Introduction                                         │
│                                                       │
│ Archimedes’ principle is a foundational law of       │
│ fluid mechanics that explains why objects float or   │
│ sink when placed in a fluid. It was discovered by    │
│ the ancient Greek mathematician Archimedes in the    │
│ 3rd century BCE. The principle has wide applications │
│ ranging from ship design to buoyancy calculations   │
│ in everyday life.                                    │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Definition                                            │
│                                                       │
│ The buoyant force acting on an object immersed in a  │
│ fluid is equal to the weight of the fluid displaced  │
│ by the object. In other words, the upward force     │
│ that prevents an object from sinking is exactly the │
│ weight of the fluid that would occupy the same space │
│ as the submerged portion of the object.             │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Key Concepts                                          │
│                                                       │
│ •  **Displaced Volume (V)** – the volume of fluid    │
│    that the object pushes aside.                     │
│ •  **Fluid Density (ρ)** – mass per unit volume of   │
│    the fluid.                                        │
│ •  **Acceleration Due to Gravity (g)** – 9.81 m/s²   │
│    (standard value).                                 │
│ •  **Buoyant Force (F_b)** – the upward force that   │
│    counteracts the object's weight.                  │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Main Formula                                          │
│                                                       │
│ $$F_b = \rho\,V\,g$$                                 │
│                                                       │
│ [ Explain Formula ]   [ Open Formula Lab ]           │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Example                                               │
│                                                       │
│ **Floating Boat**                                     │
│ A small wooden boat displaces 5 m³ of water. The     │
│ density of water is 1000 kg/m³ and g = 9.81 m/s².     │
│                                                       │
│ •  Weight of displaced water:                           │
│    \(W = \rho\,V\,g = 1000\,\text{kg/m}^3 \times 5\,\text{m}^3 \times 9.81\,\text{m/s}^2 = 49\,050\,\text{N}\).│
│ •  If the boat’s weight is less than 49 050 N, it will │
│    float; if more, it will sink until the buoyant    │
│    force balances its weight.                        │
│                                                       │
│ This illustrates how the principle predicts the       │
│ floating behavior of objects in fluids.               │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Summary                                               │
│                                                       │
│ Archimedes’ principle states that the upward buoyant │
│ force equals the weight of displaced fluid. The       │
│ formula \(F_b = \rho V g\) quantifies this force,     │
│ enabling predictions of floating or sinking for any   │
│ object in a fluid.                                    │
└───────────────────────────────────────────────────────┘
