┌───────────────────────────────────────────────┐  
│ Problem Statement                               │  
│                                                 │  
│ A force of 50 N acts on a body of mass 10 kg.   │  
│ Find the acceleration of the body.             │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Main Formula                                    │  
│                                                 │  
│          F = m a                                 │  
│                                                 │  
│          a = \frac{F}{m}                         │  
│                                                 │  
│ [ Explain Formula ]   [ Open Formula Lab ]      │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Solution Steps                                  │  
│                                                 │  
│ 1. Identify given values:                       │  
│    • Force (F) = 50 N                           │  
│    • Mass (m) = 10 kg                           │  
│                                                 │  
│ 2. Use the rearranged formula a = F/m.          │  
│                                                 │  
│ 3. Substitute: a = 50 N / 10 kg = 5 m/s².       │  
│                                                 │  
│ 4. Result: Acceleration a = 5 m/s².             │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Summary                                         │  
│                                                 │  
│ The acceleration of a 10 kg body under a 50 N   │  
│ force is 5 m/s², obtained by dividing the force │  
│ by the mass (a = F/m).                          │  
└───────────────────────────────────────────────┘
