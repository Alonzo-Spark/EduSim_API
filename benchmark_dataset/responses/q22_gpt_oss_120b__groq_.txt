┌─────────────────────────────────────┐
│ Introduction                        │
│                                     │
│ Acceleration due to gravity ( g )   │
│ describes how quickly an object’s   │
│ speed increases when it falls under │
│ the influence of a massive body’s   │
│ gravitational pull.  Understanding │
│ its derivation connects Newton’s     │
│ law of universal gravitation with   │
│ the concept of acceleration.        │
└─────────────────────────────────────┘



┌─────────────────────────────────────┐
│ Definition                          │
│                                     │
│ **Acceleration due to gravity** –   │
│ the rate of change of velocity of a │
│ test mass m at a distance r from a   │
│ larger mass M, assuming only the     │
│ gravitational force acts on m.       │
└─────────────────────────────────────┘



┌─────────────────────────────────────┐
│ Key Concepts                        │
│                                     │
│ • **Universal Gravitational Constant** G = 6.67430×10⁻¹¹ N·m²·kg⁻² │
│ • **Mass of the attracting body** M │
│ • **Distance between centers** r   │
│ • **Test mass** m (cancels out)    │
│ • **Newton’s Second Law** F = ma   │
└─────────────────────────────────────┘



┌─────────────────────────────────────┐
│ Derivation – Step 1: Newton’s Law    │
│ of Universal Gravitation            │
│                                     │
│ The gravitational force between   │
│ two point masses is                │
│                                     │
│   F = \frac{G M m}{r^{2}}          │
│                                     │

└─────────────────────────────────────┘



┌─────────────────────────────────────┐
│ Derivation – Step 2: Newton’s Second │
│ Law                                 │
│                                     │
│ Relate force to acceleration of the │
│ test mass:                         │
│                                     │
│   F = m a                         │
│                                     │
│ [ Explain Formula ]                │
│ [ Open Formula Lab ]               │
└─────────────────────────────────────┘



┌─────────────────────────────────────┐
│ Derivation – Step 3: Combine & Solve │
│ for g                               │
│                                     │
│ Set the two expressions for F equal │
│ and cancel the test mass m:         │
│                                     │
│   \frac{G M m}{r^{2}} = m a        │
│   \Rightarrow a = \frac{G M}{r^{2}}│
│                                     │
│ By definition, a ≡ g, so the final │
│ expression for the acceleration due │
│ to gravity is:                     │
│                                     │
│   g = \frac{G M}{r^{2}}            │
│                                     │
│ [ Explain Formula ]                │
│ [ Open Formula Lab ]               │
└─────────────────────────────────────┘



┌─────────────────────────────────────┐
│ Main Formula                         │
│                                     │
│   g = \frac{G M}{r^{2}}            │
│                                     │
│ • G – universal gravitational constant │
│ • M – mass of the attracting body   │
│ • r – distance from the body’s centre│

┌─────────────────────────────────────┐
│ Summary                             │
│                                     │
│ • Gravity’s acceleration is derived │
│   from the universal law of         │
│   gravitation and Newton’s second   │
│   law.                               │
│ • The compact formula g = GM/r² captures │
│   how g depends only on the mass M  │
│   of the central body and the distance│
│   r.                                 │
│ • The same relationship underpins   │
│   many practical calculations in     │
│   physics and engineering.          │
