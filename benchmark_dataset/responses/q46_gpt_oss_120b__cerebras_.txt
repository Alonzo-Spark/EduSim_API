┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ In the study of current electricity,   │
│ the relationship between voltage,      │
│ current, and resistance is a          │
│ cornerstone for analysing circuits.  │
│ Understanding its scope and limits    │
│ is essential for accurate design and   │
│ troubleshooting.                       │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Definition                             │
│                                       │
│ **Ohm’s Law** states that the electric │
│ current flowing through a conductor   │
│ is directly proportional to the       │
│ applied voltage, provided the          │
│ temperature and material remain        │
│ constant.                               │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Main Formula                           │
│                                       │
│   $$V = I\,R$$                         │
│                                       │
│ [ Explain Formula ]                    │
│ [ Open Formula Lab ]                   │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Variables                               │
│                                       │
│ • **V** – Voltage (volts, V)           │
│ • **I** – Current (amperes, A)         │
│ • **R** – Resistance (ohms, Ω)         │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Limitations                            │
│                                       │
│ 1. **Temperature Dependence** –       │
│    Resistance changes with temperature│
│    (most conductors increase).         │
│ 2. **Non‑Ohmic Materials** –          │
│    Semiconductors, diodes, transistors│
│    do not obey a linear V‑I relation. │
│ 3. **High‑Field Effects** –            │
│    At very high electric fields,      │
│    carriers gain energy and the       │
│    relationship becomes non‑linear.   │
│ 4. **Contact & Interface Resistance** │
│    Real connections add extra resistance│
│    that may vary with current.         │
│ 5. **Frequency Dependence** –          │
│    At AC or very fast transients,     │
│    inductive and capacitive reactance │
│    dominate, breaking the simple law. │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Applications                           │
│                                       │
│ • Designing resistive circuits         │
│ • Calculating power (P = V·I)           │
│ • Sizing conductors and protective      │
│   devices                               │
│ • Teaching fundamental circuit theory │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Summary                                 │
│                                       │
│ Ohm’s law (V = I R) provides a simple   │
│ linear link between voltage, current,   │
│ and resistance, but it holds only under │
│ constant temperature, low‑field, and    │
│ linear‑material conditions. Real‑world  │
│ components often deviate, requiring      │
│ more complex models.                     │
└───────────────────────────────────────┘
