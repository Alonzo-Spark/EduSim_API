┌───────────────────────────────────────────────────────────────────────┐
│ Quick Definition                                                          │
│                                                                             │
│ A projectile is any object that is thrown, launched, or otherwise moved   │
│ through the air (or any other fluid) under the influence of gravity and    │
│ other forces such as drag. The classic textbook model assumes a vacuum,   │
│ but real‑world trajectories must account for air resistance.              │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Key Concepts                                                              │
│                                                                             │
│ • **Drag Force** – A resistive force that opposes the motion of the       │
│   projectile, proportional to the square of its speed.                     │
│ • **Velocity Vector** – The direction and magnitude of motion, which       │
│   determines the direction of the drag.                                     │
│ • **Trajectory** – The path traced by the projectile’s center of mass,     │
│   which is altered by the presence of drag.                               │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Main Formula                                                              │
│                                                                             │
│     $$\mathbf{F}_d = -\frac12 C_d \,\rho \,A \,v^2\,\hat{\mathbf{v}}$$   │

┌───────────────────────────────────────────────────────────────────────┐
│ Visual Effect of Air Resistance                                          │
│                                                                             │
│ 1. **Reduced Range** – Drag dissipates kinetic energy, shortening the      │
│    horizontal distance the projectile travels.                            │
│ 2. **Lower Apex** – The upward component of velocity is damped faster,     │
│    so the highest point of the flight is lower than in a vacuum.           │
│ 3. **Altered Shape** – The trajectory becomes more “rounded” rather than   │
│    the ideal parabolic arc, often resembling a steep “hill” that quickly   │
│    flattens.                                                               │
│ 4. **Time of Flight** – Depending on launch angle, the projectile may      │
│    spend less or more time in the air; typically, drag reduces the overall │
│    flight time.                                                            │
│ 5. **Terminal Velocity** – For very long flights or very heavy objects,   │
│    the projectile may approach a constant speed where drag balances       │
│    gravity.                                                               │
│                                                                             │
│ These visual differences become especially noticeable for high‑speed      │
│ projectiles (e.g., bullets, rockets) or objects with large surface areas   │
│ (e.g., paper planes).                                                     │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Summary                                                                    │
│                                                                             │
│ Adding air resistance transforms the ideal parabolic trajectory into a    │
│ more complex path: the projectile travels a shorter distance, reaches a   │
│ lower peak, and the overall shape is more rounded. The drag force,        │
│ depending on speed, continually reduces the projectile’s kinetic energy, │
│ leading to the visual effects described above.                             │
└───────────────────────────────────────────────────────────────────────┘
