┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ The concepts of **electric field**   │
│ and **electric potential** describe   │
│ how electric forces act over space   │
│ and how energy is stored in a system. │
│ Both are fundamental to electrostatics│
│ and are linked by a simple mathematical│
│ relationship.                          │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Electric Field – Definition            │
│                                       │
│ An electric field **E** at a point   │
│ in space is the force **F** that a   │
│ positive test charge **q** would feel│
│ per unit charge:                      │
│                                       │
│ \[ \mathbf{E} = \frac{\mathbf{F}}{q} \]│
│                                       │
│ It points in the direction that a    │
│ positive charge would be pushed.      │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Electric Potential – Definition       │
│                                       │
│ Electric potential **V** at a point  │
│ is the potential energy **U** per unit│
│ charge:                               │
│                                       │
│ \[ V = \frac{U}{q} \]                 │
│                                       │
│ It represents how much work would be │
│ required to bring a unit charge from   │
│ infinity to that point.                │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐

┌───────────────────────────────────────┐
│ Summary                                │
│                                       │
│ • **Electric field** = force per unit │
│   charge ( F / q ).                     │
│ • **Electric potential** = energy per │
│   unit charge ( U / q ).                │
│ • The two are linked by               │
│   **E = –∇V**, meaning the field is the│
│   spatial rate of change of potential.│
│                                       │
│ Understanding both allows analysis of│
│ how charges interact and how energy is│
│ moves in electric circuits and fields.│
└───────────────────────────────────────┘
