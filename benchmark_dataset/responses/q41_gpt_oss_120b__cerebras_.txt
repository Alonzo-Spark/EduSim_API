┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ Electrostatics studies the behavior  │
│ of electric charges at rest. Central   │
│ to this field is Coulomb’s law, which │
│ describes the force between two point │
│ charges.                               │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Definition                             │
│                                       │
│ Coulomb’s law states that the magnitude│
│ of the electrostatic force ( F ) between│
│ two point charges is directly proportional│
│ to the product of the charges and invers│
│ emently proportional to the square of   │
│ the distance separating them.           │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Main Formula                           │
│                                       │
│ $$\displaystyle F = k\,\frac{q_1 q_2}{r^{2}}$$ │
│                                       │
│ [ Explain Formula ]                    │
│ [ Open Formula Lab ]                   │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Formula Explanation                     │
│                                       │
│ • **F** – Electrostatic force (newtons, N)│
│ • **k** – Coulomb constant (≈ 8.9875 × 10⁹ N·m²·C⁻²)│
│ • **q₁, q₂** – Magnitudes of the two point │
│   charges (coulombs, C)               │
│ • **r** – Distance between the charges (meters, m)│
│                                       │
│ The force is attractive if the charges │
│ have opposite signs and repulsive if   │
│ they have the same sign.                │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Applications                           │
│                                       │
│ • Predicting forces in atomic and     │
│   molecular structures                │
│ • Designing electrostatic equipment   │
│   (e.g., capacitors, spray printers)  │
│ • Understanding phenomena such as     │
│   lightning and static cling          │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Advantages                             │
│                                       │
│ • Simple, closed‑form expression       │
│ • Works for point charges at any      │
│   separation (in vacuum)              │
│ • Foundation for more complex electro│
│   static models                        │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Limitations                            │
│                                       │
│ • Assumes point charges (real charges │
│   have finite size)                   │
│ • Valid only in vacuum; in media the  │
│   constant **k** changes with permitt│
│   ivec permittivity ε_r                │
│ • Does not account for relativistic   │
│   effects at very high speeds         │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Summary                                │
│                                       │
│ Coulomb’s law quantifies the electro- │
│ static force between two point charges│
│ as **F = k q₁q₂ / r²**, linking charge │
│ magnitude and separation. It underpins│
│ much of electrostatics, from atomic to │
│ macroscopic scales.                    │
└───────────────────────────────────────┘
