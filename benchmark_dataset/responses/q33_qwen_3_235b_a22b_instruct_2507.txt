┌─────────────────────────────────────┐
│           Introduction              │
├─────────────────────────────────────┤
│ Heat transfer is a fundamental     │
│ concept in thermodynamics, describing│
│ how thermal energy moves from one  │
│ place to another. There are three  │
│ primary mechanisms: conduction,    │
│ convection, and radiation. Each    │
│ operates under different physical  │
│ principles and occurs in distinct  │
│ environments. This guide explains  │
│ their differences clearly and      │
│ systematically.                    │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│        Quick Definition             │
├─────────────────────────────────────┤
│ • **Conduction**: Heat transfer    │
│   through direct contact between   │
│   particles in solids or stationary│
│   fluids.                          │
│                                    │
│ • **Convection**: Heat transfer    │
│   via the movement of fluids       │
│   (liquids or gases) due to        │
│   density differences.             │
│                                    │
│ • **Radiation**: Heat transfer     │
│   through electromagnetic waves,   │
│   requiring no medium.             │
└─────────────────────────────────────┘

---

### Key Concepts

┌─────────────────────────────────────┐
│         Conduction                  │
├─────────────────────────────────────┤
│ Occurs primarily in solids,        │
│ especially metals. Involves transfer│
│ of kinetic energy between adjacent │
│ atoms or free electrons without    │
│ bulk motion of the material.       │
│                                    │
│ 🔹 Example: A metal spoon gets hot │
│     when left in a hot soup.       │
│                                    │
│ 🔹 Best in: Solids (especially     │
│     conductors like copper, silver)│
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│         Convection                  │
├─────────────────────────────────────┤
│ Involves the physical movement of  │
│ heated fluid (liquid or gas). Warm │
│ regions rise, cool regions sink,   │
│ creating convection currents.      │
│                                    │
│ 🔹 Example: Boiling water in a pot,│
│     warm air rising in a room.     │
│                                    │
│ 🔹 Types: Natural (buoyancy-driven)│
│     and Forced (fan/pump-assisted) │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│         Radiation                   │
├─────────────────────────────────────┤
│ Transfer of energy via infrared    │
│ electromagnetic waves. Does not    │
│ require any medium — works even in │
│ a vacuum.                          │
│                                    │
│ 🔹 Example: Heat from the Sun      │
│     reaching Earth.                │
│                                    │
│ 🔹 All objects emit radiation;     │
│     hotter objects emit more.      │
└─────────────────────────────────────┘

### Important Notes

┌─────────────────────────────────────┐
│        Common Misconceptions        │
├─────────────────────────────────────┤
│ ❌ "Radiation is always harmful."   │
│ → FALSE: Thermal radiation (like   │
│    from a heater) is harmless and  │
│    natural.                         │
│                                     │
│ ❌ "Convection can occur in solids."│
│ → FALSE: Solids don’t flow;         │
│    convection requires fluid motion.│
│                                     │
│ ❌ "Conduction needs flowing        │
│     material."                      │
│ → FALSE: Conduction relies on       │
│    particle collisions, not flow.   │
└─────────────────────────────────────┘

### Applications

| Mechanism    | Real-World Applications                          |
|--------------|---------------------------------------------------|
| **Conduction** | Cooking pans, thermal insulation, heat sinks     |
| **Convection** | HVAC systems, weather systems, boiling liquids   |
| **Radiation**  | Solar heaters, infrared cameras, space heating   |

### Summary

┌─────────────────────────────────────┐
│            Summary                  │
├─────────────────────────────────────┤
│ • **Conduction**: Direct contact,  │
│   particle-to-particle transfer.   │
│                                    │
│ • **Convection**: Fluid motion     │
│   carries heat; driven by density. │
│                                    │
│ • **Radiation**: Electromagnetic   │
│   waves; works in vacuum.          │
│                                    │
│ These three methods often occur    │
│ simultaneously but dominate under  │
│ different conditions.              │
