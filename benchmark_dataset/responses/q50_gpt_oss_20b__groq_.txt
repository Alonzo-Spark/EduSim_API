───────────────────────────────────────────────────────────────────────  
│                           Introduction                                 │  
│                                                                 │  
│ In electricity, power is the rate at which electrical energy is   │  
│ transferred or converted. It tells us how quickly work can be     │  
│ done or heat can be generated in a circuit.                       │  
───────────────────────────────────────────────────────────────────────  

───────────────────────────────────────────────────────────────────────  
│                           Definition                                    │  
│                                                                 │  
│ **Electrical power** (P) is defined as the amount of energy (E)    │  
│ transferred per unit time (t). Mathematically, it is expressed as: │  
│                                                                 │  
│ *P = dE/dt*                                                    │  
│                                                                 │  
│ where *E* is energy in joules and *t* is time in seconds.         │  
───────────────────────────────────────────────────────────────────────  

───────────────────────────────────────────────────────────────────────  
│                           Key Concepts                                 │  
│                                                                 │  
│ • **Voltage (V)** – the electric potential difference that drives │  
│   electrons through a circuit.                                   │  
│ • **Current (I)** – the flow rate of electric charge, measured in  │  
│   amperes (A).                                                    │  
│ • **Power (P)** – the product of voltage and current, indicating │  
│   how much electrical energy is being used per second.            │  
───────────────────────────────────────────────────────────────────────  

───────────────────────────────────────────────────────────────────────  
│                           Main Formula                                 │  
│                                                                 │  
│     P = V · I                                                  │  
│                                                                 │

───────────────────────────────────────────────────────────────────────  
│                           Summary                                      │  
│                                                                 │  
│ Electrical power quantifies the rate of energy transfer in a     │  
│ circuit. By definition, power equals the product of the voltage   │  
│ across a component and the current flowing through it:           │  
│                                                                 │  
│ *P = V · I*                                                     │  
│                                                                 │  
│ This simple yet powerful relationship underlies all electrical   │  
│ engineering, from household wiring to high‑speed computing.      │
