┌─────────────────────────────────────┐
│ Introduction                        │
│                                     │
│ A block slides on a horizontal      │
│ surface. The only horizontal force  │
│ opposing the motion is kinetic       │
│ friction, which depends on the      │
│ coefficient of friction μ.  We will │
│ explore what happens as μ → 0,      │
│ i.e. when the surface becomes      │
│ perfectly smooth.                   │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Definition                          │
│                                     │
│ • Sliding Block – a rigid body that │
│   moves without rolling.            │
│ • Coefficient of Kinetic Friction   │
│   (μ) – dimension‑less ratio that    │
│   relates the friction force to the │
│   normal force:  F_f = μ N.          │
│ • μ → 0 – the limit of a friction‑   │
│   less (ideal) surface.             │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Key Concepts                        │
│                                     │
│ 1. **Normal Force (N)** – for a      │
│    horizontal surface, N = m g.      │
│ 2. **Kinetic Friction Force**        │
│    F_f = μ N.                         │
│ 3. **Net Horizontal Force**          │
│    F_net = F_push – F_f.             │
│ 4. **Acceleration**                  │
│    a = F_net / m.                    │
│ 5. **Limit μ → 0** → F_f → 0, so     │
│    a → F_push / m (maximum).         │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐

┌─────────────────────────────────────┐
│ Important Notes                     │
│                                     │
│ • μ = 0 is an idealization; real    │
│   materials always have some       │
│   microscopic adhesion.            │
│ • Energy dissipation → 0, so kinetic│
│   energy is conserved (ignoring air│
│   resistance).                     │
│ • The block will continue moving    │
│   indefinitely if no other forces   │
│   act (Newton’s first law).         │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Summary                             │
│                                     │
│ * As μ → 0, the friction force vanishes │
│   (F_f → 0).                         │
│ * The net horizontal force becomes   │
│   the applied push alone, giving the │
│   maximum possible acceleration      │
│   a_max = F_push / m.                │
│ * In the friction‑less limit the     │
│   block would glide forever (ignoring│
│   other dissipative effects).        │
└─────────────────────────────────────┘
