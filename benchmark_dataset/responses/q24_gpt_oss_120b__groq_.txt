│ **Introduction**                            │  
│                                             │  
│ In this example we will determine the       │  
│ gravitational attraction between two identical│  
│ point masses using Newton’s law of universal │  
│ gravitation.                                 │  
└─────────────────────────────────────────────┘  

┌─────────────────────────────────────────────┐  
│ **Formula Card**                            │  
│                                             │  
│ **Newton’s Law of Universal Gravitation**   │  
│                                             │  
│ $$F = G\;\frac{m_{1}\,m_{2}}{r^{2}}$$        │  
│                                             │  
│ • **G** – gravitational constant,           │  
│   \(6.67430\times10^{-11}\ \text{N·m}^2\!/\text{kg}^2\) │  
│ • \(m_{1}, m_{2}\) – the two masses (kg)    │  
│ • \(r\) – distance between their centres (m)│  
│                                             │  
│ [ Explain Formula ]   [ Open Formula Lab ]  │  
└─────────────────────────────────────────────┘  

┌─────────────────────────────────────────────┐  
│ **Given Data**                              │  
│                                             │  
│ • \(m_{1}=5\ \text{kg}\)                     │  
│ • \(m_{2}=5\ \text{kg}\)                     │  
│ • \(r = 2\ \text{m}\)                        │  
│ • \(G = 6.67430\times10^{-11}\ \text{N·m}^2\!/\text{kg}^2\) │  
└─────────────────────────────────────────────┘  

┌─────────────────────────────────────────────┐  
│ **Step‑by‑Step Calculation**                │  
│                                             │  
│ 1. Plug the values into the formula:        │  
│    $$F = 6.67430\times10^{-11}\;\frac{5\times5}{2^{2}}$$ │  
│                                             │  
│ 2. Compute the numerator:                   │  
│    \(5\times5 = 25\)                         │  
│                                             │  
│ 3. Compute the denominator:                 │  
│    \(2^{2}=4\)                               │  
│                                             │  
│ 4. Combine:                                 │  
│    $$F = 6.67430\times10^{-11}\;\frac{25}{4}$$ │  
│                                             │  
│ 5. Evaluate the fraction:                   │  
│    \(\frac{25}{4}=6.25\)                     │  
│                                             │  
│ 6. Final multiplication:                    │  
│    $$F = 6.67430\times10^{-11}\times6.25$$   │  
│    $$F \approx 4.17144\times10^{-10}\ \text{N}$$ │  
└─────────────────────────────────────────────┘  

┌─────────────────────────────────────────────┐  
│ **Result**                                   │  
│                                             │  
│ The gravitational force between the two     │  
│ 5‑kg masses separated by 2 m is               │  
│ $$\boxed{F \approx 4.2\times10^{-10}\ \text{N}}$$ │  
│ (approximately 0.42 nanonewtons).           │  
└─────────────────────────────────────────────┘  

┌─────────────────────────────────────────────┐  
│ **Summary**                                  │  
│                                             │  
│ • Use \(F = G\,m_{1}m_{2}/r^{2}\).           │  
│ • Insert the given masses and distance.     │  
│ • The force is extremely weak at everyday   │  
│   scales – on the order of \(10^{-10}\) N.   │  
└─────────────────────────────────────────────┘
