┌───────────────────────────┐
│ Quick Definition          │
├───────────────────────────┤
│ Conservation of mechanical│
│ energy: Total mechanical  │
│ energy (KE + PE) remains  │
│ constant in isolated       │
│ systems with only          │
│ conservative forces acting│
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
├───────────────────────────┤
│ 1. Mechanical Energy =    │
│    Kinetic Energy (KE) +  │
│    Potential Energy (PE)  │
│ 2. Applies only when:     │
│    - No air resistance    │
│    - No friction          │
│    - Only conservative    │
│      forces (gravity,     │
│      springs)             │
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula              │
├───────────────────────────┤
│ KE₁ + PE₁ = KE₂ + PE₂     │
│                           │
│          1                │
│ KE = ½mv²      PE = mgh   │
│          2                │
└───────────────────────────┘

┌───────────────────────────┐
│ Practical Example         │
├───────────────────────────┤
│ Scenario: Dropping a 5kg  │
│ mass from 20m height      │
│                           │
│ 1. At top (Point A):      │
│    PE = 5×9.8×20 = 980J   │
│    KE = 0                 │
│                           │
│ 2. Mid-fall (Point B):    │
│    PE = 5×9.8×10 = 490J   │
│    KE = 980 - 490 = 490J  │
│    → v = √(2KE/m) = 14m/s│
│                           │
│ 3. At ground (Point C):   │
│    PE = 0                 │
│    KE = 980J              │
│    → v = √(2×980/5)=19.8m/s│
└───────────────────────────┘
