┌───────────────────────────────────────────────┐
│ Problem Statement                               │
│                                                 │
│ A body of mass **5 kg** is lifted to a height   │
│ of **10 m**. Calculate its gravitational       │
│ potential energy.                              │
└─────────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│ Main Formula                                    │
│                                                 │
│            **U = m g h**                        │
│                                                 │
│ • **U** – Gravitational potential energy (J)    │
│ • **m** – Mass of the object (kg)               │
│ • **g** – Acceleration due to gravity (9.81 m/s²)│
│ • **h** – Height above reference point (m)      │
│                                                 │
│ [ Explain Formula ]   [ Open Formula Lab ]      │
└─────────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│ Calculation                                     │
│                                                 │
│ Plug the given values into **U = m g h**:       │
│                                                 │
│   m = 5 kg                                      │
│   g = 9.81 m/s²                                 │
│   h = 10 m                                      │
│                                                 │
│   U = 5 kg × 9.81 m/s² × 10 m                    │
│     = 5 × 9.81 × 10                            │
│     = 490.5 J                                   │
│                                                 │
│ [ Show Step‑by‑Step ]   [ Open Calculator ]    │
└─────────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│ Answer                                          │
│                                                 │
│ The gravitational potential energy of the       │
│ 5 kg body lifted 10 m high is **≈ 4.9 × 10² J**   │
│ (or **490 J** when rounded to three significant │
│ figures).                                       │
│                                                 │
