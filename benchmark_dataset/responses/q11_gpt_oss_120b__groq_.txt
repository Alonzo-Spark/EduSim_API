┌───────────────────────────────────────────────┐
│ Introduction                                    │
│                                                   │
│ Newton’s Laws of Motion form the foundation of   │
│ classical mechanics. They describe how objects   │
│ respond to forces and how motion changes.        │
│                                                   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Definition                                      │
│                                                   │
│ *Newton’s First Law*: An object at rest stays    │
│ at rest, and an object in motion continues in   │
│ a straight line at constant speed unless acted │
│ upon by a net external force.                    │
│                                                   │
│ *Newton’s Second Law*: The acceleration of an    │
│ object is directly proportional to the net      │
│ force acting on it and inversely proportional to │
│ its mass.                                        │
│                                                   │
│ *Newton’s Third Law*: For every action force,    │
│ there is an equal and opposite reaction force.  │
│                                                   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Key Concepts                                    │
│                                                   │
│ • **Inertia** – resistance of an object to       │
│   changes in its state of motion.                │
│ • **Force (F)** – any interaction that changes    │
│   motion.                                         │
│ • **Mass (m)** – measure of an object’s inertia. │
│ • **Acceleration (a)** – rate of change of       │
│   velocity.                                       │
│                                                   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Law 1 – Law of Inertia                           │
│                                                   │
│ **Statement**: An object will remain at rest or  │
│ move with constant velocity unless a net force  │
│ acts on it.                                       │
│                                                   │
│ **Everyday Example**: A book resting on a table  │
│ stays put until you push it.                     │
│                                                   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Law 2 – Law of Acceleration                      │
│                                                   │
│ **Statement**: The net force on an object equals │
│ the product of its mass and acceleration.        │
│                                                   │
│ **Formula Card**                                 │
│ ┌─────────────────────────────────────────────┐ │
│ │ Main Formula                                 │ │
│ │                                             │ │
│ │      \[ F = m a \]                           │ │
│ │                                             │ │
│ │ [ Explain Formula ]   [ Open Formula Lab ] │ │
│ └─────────────────────────────────────────────┘ │
│                                                   │
│ **Everyday Example**: Pushing a shopping cart –  │
│ the harder you push (greater F), the faster it   │
│ accelerates; a heavier cart (greater m) needs more│
│ force for the same acceleration.                │
│                                                   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Law 3 – Action & Reaction                        │
│                                                   │
│ **Statement**: For every action force there is   │
│ an equal and opposite reaction force.            │
│                                                   │
│ **Everyday Example**: When you jump, your feet   │
│ push down on the ground (action) and the ground   │
│ pushes you upward (reaction), propelling you into │
│ the air.                                          │
│                                                   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Applications                                    │
│                                                   │
│ • Designing vehicle safety systems (airbags,     │
│   crumple zones) using the second law.           │
│ • Spacecraft trajectory planning – applying all   │
│   three laws.                                     │
│ • Sports technique – understanding force and      │
│   reaction (e.g., tennis serve).                 │
│                                                   │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Summary                                         │
│                                                   │
│ 1️⃣ **First Law** – Inertia keeps motion unchanged │
│     without net force.                           │
│ 2️⃣ **Second Law** – \(F = m a\) links force, mass │
│     and acceleration.                           │
│ 3️⃣ **Third Law** – Forces occur in equal‑opposite │
│     pairs.                                        │
│ Understanding these laws lets us predict and      │
│ control motion in everyday life and engineering. │
│                                                   │
└───────────────────────────────────────────────┘
