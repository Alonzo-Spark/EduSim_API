┌─────────────────────────────────────┐  
│ Introduction                        │  
│                                     │  
│ Projectile motion describes the     │  
│ motion of an object that is launched │  
│ into the air and moves under the     │  
│ influence of gravity alone (ignoring │  
│ air resistance). It is a classic    │  
│ example of two‑dimensional motion   │  
│ where the horizontal and vertical   │  
│ components are independent.         │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Definition                          │  
│                                     │  
│ **Projectile motion** is the        │  
│ trajectory of an object that        │  
│ follows a parabolic path after being│  
│ given an initial velocity at an     │  
│ angle to the horizontal, with only  │  
│ gravity acting on it.               │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Key Concepts                        │  
│                                     │  
│ • **Initial velocity** \( \mathbf{v}_0 \) – magnitude and launch   │  
│   angle \( \theta \).               │  
│ • **Horizontal component**          │  
│   \( v_{0x}=v_0\cos\theta \).        │  
│ • **Vertical component**            │  
│   \( v_{0y}=v_0\sin\theta \).        │  
│ • **Independence of motions** – horizontal motion is uniform, │  
│   vertical motion is uniformly accelerated. │  
│ • **Trajectory** – a parabola.      │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Characteristics                     │  
│                                     │  
│ 1. **Parabolic path** – the set of   │  
│    points \((x,y)\) satisfies a     │  
│    quadratic relation.              │  
│ 2. **Horizontal motion** is          │  
│    constant‑velocity (no horizontal  │  
│    acceleration).                    │  
│ 3. **Vertical motion** experiences   │  
│    constant downward acceleration   │  
│    \( g \approx 9.81\;{\rm m/s^2} \). │  
│ 4. **Time of flight**, **range**, and │  
│    **maximum height** can be         │  
│    expressed analytically.          │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Horizontal Motion Formula            │  
│                                     │  
│          \( x = v_{0x}\,t \)        │  
│                                     │

┌─────────────────────────────────────┐  
│ Vertical Motion Formula              │  
│                                     │  
│          \( y = v_{0y}\,t - \frac{1}{2}gt^{2} \) │

└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Time of Flight Formula               │  
│                                     │  
│          \( T = \frac{2v_{0y}}{g} = \frac{2v_{0}\sin\theta}{g} \) │  
│                                     │  
│ [ Explain Formula ]   [ Open Formula Lab ] │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Maximum Height Formula               │  
│                                     │  
│          \( H = \frac{v_{0y}^{2}}{2g}= \frac{v_{0}^{2}\sin^{2}\theta}{2g} \) │  
│                                     │  
│ [ Explain Formula ]   [ Open Formula Lab ] │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Range Formula                        │  
│                                     │  
│          \( R = \frac{v_{0}^{2}\sin 2\theta}{g} \) │  
│                                     │  
│ [ Explain Formula ]   [ Open Formula Lab ] │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Applications                         │  
│                                     │  
│ • Sports (e.g., basketball shots,   │  
│   javelin throws).                  │  
│ • Ballistics and artillery.        │  
│ • Spacecraft launch trajectories   │  
│   (initial phase approximated as    │  
│   projectile motion).              │  
│ • Engineering analyses of water     │  
│   fountains and fireworks.          │  
└─────────────────────────────────────┘  

┌─────────────────────────────────────┐  
│ Summary                              │  
│                                     │  
│ Projectile motion is a two‑dimensional │  
│ motion where the horizontal component   │  
│ moves with constant velocity and the    │  
│ vertical component accelerates uniformly│  
│ under gravity, producing a parabolic    │  
│ trajectory. The core formulas for      │  
│ displacement, time of flight, maximum   │  
│ height, and range allow quick prediction│  
│ of the object's path.                  │  
└─────────────────────────────────────┘
