┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ Electrostatics studies the forces    │
│ between stationary electric charges. │
│ One of its fundamental principles is │
│ Coulomb’s law, which quantifies the   │
│ interaction between two point charges.│
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Definition                             │
│                                       │
│ **Coulomb’s law** states that the      │
│ magnitude of the electrostatic force   │
│ between two point charges is directly │
│ proportional to the product of the    │
│ absolute values of the charges and     │
│ inversely proportional to the square  │
│ of the distance separating them.       │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Coulomb’s Law (Formula)                │
│                                       │
│ $$                                   │
│ F = k \frac{|q_1 q_2|}{r^{2}}        │
│ $$                                   │
│                                       │
│ [ Explain Formula ]   [ Open Formula Lab ] │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Variables                              │
│                                       │
│ • **F** – Electrostatic force (N)      │
│ • **k** – Coulomb’s constant            │
│   \(k \approx 8.9875 \times 10^{9}\ \text{N·m²/C²}\) │
│ • **q₁, q₂** – Point charges (C)        │
│ • **r** – Distance between charges (m) │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Applications                           │
│                                       │
│ • Predicting forces in atoms and      │
│   molecules                           │
│ • Designing capacitors and electro‑   │
│   static devices                      │
│ • Understanding phenomena such as     │
│   lightning and triboelectric charging│
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Summary                                │
│                                       │
│ • Coulomb’s law gives the quantitative│
│   relationship for electrostatic      │
│   attraction or repulsion.            │
│ • Force ∝ (product of charges) /      │
│   (distance)².                         │
│ • The constant \(k\) ties the equation │
│   to the SI system.                    │
└───────────────────────────────────────┘
