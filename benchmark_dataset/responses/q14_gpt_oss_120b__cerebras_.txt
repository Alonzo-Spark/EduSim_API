┌─────────────────────────────────┐
│ Introduction                     │
│                                 │
│ Momentum is a fundamental│
│ concept in physics that        │
│ describes the quantity of      │
│ motion an object possesses.    │
│ It combines how much matter     │
│ there is (mass) with how fast   │
│ it is moving (velocity).        │
│                                 │
│ Understanding momentum is key  │
│ for analyzing collisions,      │
│ vehicle safety, sports, and    │
│ many engineering problems.      │
└─────────────────────────────────┘



┌─────────────────────────────────┐
│ Definition                       │
│                                 │
│ **Momentum (p)** is defined as │
│ the product of an object's      │
│ mass (m) and its velocity (v):  │
│                                 │
│   p = m v                        │
│                                 │
│ It is a vector quantity,       │
│ pointing in the same direction │
│ as the velocity.                │
└─────────────────────────────────┘



┌─────────────────────────────────┐
│ Key Concepts                     │
│                                 │
│ • Mass (m) – measure of         │
│   inertia, scalar quantity.     │
│ • Velocity (v) – speed and      │
│   direction, vector quantity.   │
│ • Momentum (p) – vector;       │
│   units: kg·m/s.                │
│ • Closed system – no external   │
│   forces act on the total        │
│   momentum of the system.       │
│ • Conservation – total momentum │
│   remains constant if the system│
│   is isolated.                  │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ Derivation of Conservation       │
│ Law of Momentum                  │
│                                 │
│ Consider two objects, A and B, │
│ interacting within an isolated   │
│ system. Let their masses be m₁, │
│ m₂ and velocities v₁, v₂ before │
│ collision, and v₁′, v₂′ after.   │
│                                 │
│ 1. **Newton’s Third Law**:      │
│    The forces they exert on     │
│    each other are equal and     │
│    opposite: F₁₂ = –F₂₁.        │
│                                 │
│ 2. **Impulse–Momentum Theorem**:│
│    ∆p = ∫F dt. For each object, │
│    Δp₁ = ∫F₁₂ dt, Δp₂ = ∫F₂₁ dt.│
│                                 │
│ 3. Adding the two impulses:     │
│    Δp₁ + Δp₂ = ∫(F₁₂ + F₂₁) dt = 0 │
│    → (p₁′ – p₁) + (p₂′ – p₂) = 0 │
│    → p₁ + p₂ = p₁′ + p₂′         │
│                                 │
│ This shows that the vector sum   │
│ of the momenta before interaction │
│ equals the sum after interaction, │
│ i.e., momentum is conserved.    │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│ Applications                     │
│                                 │
│ • **Collisions** – Predict       │
│   outcomes of car crashes,      │
│   billiard balls, particle      │
│   physics experiments.          │
│ • **Rocket Propulsion** – Uses   │
│   momentum change of expelled   │
│   gases to generate thrust.      │
│ • **Sports** – Analyzing        │
│   momentum transfer in          │
│   tackles, swings, and jumps.    │
│ • **Astronomy** – Orbital        │
│   transfers and gravitational   │
│   assists.                       │
└─────────────────────────────────┘



┌─────────────────────────────────┐
│ Summary                          │
│                                 │
│ • Momentum (p) = m v.            │
│ • It is a conserved vector       │
│   quantity for an isolated system.│
│ • Conservation follows from      │
│   Newton’s third law and the     │
│   impulse–momentum theorem.      │
│ • Widely used in engineering,    │
│   astrophysics, sports, and      │
│   everyday problem solving.      │
