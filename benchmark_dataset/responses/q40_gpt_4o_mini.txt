┌───────────────────────────┐
│ Introduction              │
│                           │
│ Waves are disturbances that │
│ transfer energy through a  │
│ medium or space. They can  │
│ be classified into two     │
│ main types: transverse and │
│ longitudinal waves.        │
└───────────────────────────┘

┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Transverse waves are waves  │
│ in which the motion of the   │
│ medium is perpendicular to   │
│ the direction of the wave.   │
│ Longitudinal waves are waves  │
│ in which the motion of the    │
│ medium is parallel to the     │
│ direction of the wave.       │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ - In transverse waves,     │
│   particle displacement    │
│   occurs up and down or    │
│   side to side, creating   │
│   crests and troughs.      │
│ - In longitudinal waves,    │
│   particle displacement is  │
│   back and forth, forming   │
│   compressions and rarefactions. │
└───────────────────────────┘

┌───────────────────────────┐
│ Characteristics           │
│                           │
│ Transverse Waves:         │
│ - Can travel through solids│
│ - Examples: light waves,  │
│   waves on a string       │
│                           │
│ Longitudinal Waves:       │
│ - Can travel through solids,│
│   liquids, and gases      │
│ - Examples: sound waves    │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                  │
│                           │
│ Transverse and longitudinal waves differ primarily in how the medium's particles move in relation to the wave's direction. Transverse waves move perpendicularly, while longitudinal waves move parallel to the direction of wave propagation. Understanding these differences is crucial in fields such as physics and engineering. │
└───────────────────────────┘
