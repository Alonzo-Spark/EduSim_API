┌─────────────────────────────────────────────────────────┐
│ Key Concepts                                            │
│                                                         │
│ • **Inelastic Interaction**: The attachment is modeled   │
│   as a perfectly inelastic collision where the two      │
│   objects merge.                                        │
│                                                         │
│ • **Conservation of Momentum**: The total momentum of   │
│   the system remains constant immediately before and    │
│   after the attachment.                                 │
│                                                         │
│ • **Velocity Reduction**: As the total mass ($m$)       │
│   increases, the velocity ($v$) must decrease to        │
│   conserve momentum.                                    │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ Velocity Update Formula                                 │
│                                                         │
│                                                         │
│           $$ v_{new} = \frac{m_{old} \cdot v_{old}}{m_{total}} $$ │
│                                                         │
│                                                         │
