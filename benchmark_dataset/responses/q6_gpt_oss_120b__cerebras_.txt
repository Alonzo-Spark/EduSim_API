┌──────────────────────────────────────────────────────────────┐
│ Introduction                                                   │
│                                                                  │
│ Projectile motion describes the motion of an object that is   │
│ launched into the air and moves under the influence of          │
│ gravity alone (ideal case: no air resistance). It is a classic │
│ example of two‑dimensional (planar) motion where the horizontal │
│ and vertical motions are coupled only through time.             │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ Definition                                                     │
│                                                                  │
│ **Projectile Motion** – the motion of a body that is           │
│ projected into a uniform gravitational field with an initial   │
│ velocity that has both horizontal and vertical components.     │
│ The only force acting after launch is the constant acceleration │
│ due to gravity ( g ≈ 9.81 m·s⁻² downward).                        │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ Characteristics                                                │
│                                                                  │
│ • **Two‑dimensional trajectory** – the path lies in a vertical  │
│   plane; the horizontal (x) and vertical (y) motions are        │
│   independent except for sharing the same time variable.       │
│                                                                  │
│ • **Horizontal motion** – constant velocity (no horizontal      │
│   acceleration) when air resistance is neglected.             │
│                                                                  │
│ • **Vertical motion** – uniformly accelerated motion with      │
│   acceleration = ‑g (downward).                                 │
│                                                                  │
│ • **Parabolic path** – the combination of linear horizontal     │
│   displacement and quadratic vertical displacement yields a      │
│   parabola.                                                     │
│                                                                  │
│ • **Time of flight** – determined solely by the vertical       │
│   component of the initial velocity and the launch angle.      │
│                                                                  │
│ • **Range and maximum height** – both depend on the magnitude   │
│   and direction (angle) of the initial velocity.               │
│                                                                  │
│ • **Independence of components** – horizontal distance covered │
│   does not affect vertical motion and vice‑versa.               │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ Summary                                                        │
│                                                                  │
│ • Projectile motion is a planar, two‑dimensional motion       │
│   governed only by gravity after launch.                        │
│ • Horizontal component: constant speed; vertical component:   │
│   constant acceleration (‑g).                                    │
│ • The resulting trajectory is a parabola, and key quantities   │
│   (time of flight, range, maximum height) are functions of the │
│   initial speed and launch angle.                               │
└──────────────────────────────────────────────────────────────┘
