┌───────────────────────────┐
│ Spring Stretched Event    │
│                           │
│ A 'spring_stretched' peak │
│ limit event occurs when   │
│ the spring is extended     │
│ beyond its elastic limit.  │
│ This can lead to          │
│ permanent deformation or   │
│ failure of the spring.    │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ - **Elastic Limit**: The  │
│   maximum extent to which  │
│   a spring can be stretched│
│   without permanent damage.│
│ - **Hooke's Law**: States  │
│   that the force needed to  │
│   extend or compress a      │
│   spring is proportional to  │
│   the distance it is       │
│   stretched or compressed. │
└───────────────────────────┘
