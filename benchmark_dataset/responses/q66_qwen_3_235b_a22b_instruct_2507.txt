### 🧪 Concept Simulation: Boundary Reflection Event

Instead of direct sandbox manipulation, let's model a **reflection event** as a physics-based interaction — like a particle bouncing off a constrained boundary.

---

#### Quick Definition

A **bounce boundary reflection** models how a moving entity responds when it encounters a confined system limit, reversing direction with modified momentum — similar to light reflecting off a mirror or gas molecules bouncing off container walls.

---

#### Main Formula

$$
v_{\text{final}} = -e \cdot v_{\text{initial}}
$$

#### Simulation Example

```python
def reflect(position, velocity, bounds, elasticity=1.0):
    min_b, max_b = bounds
    if position >= max_b or position <= min_b:
        return -elasticity * velocity
    return velocity

# Test
vel = 10
pos = 11
new_vel = reflect(pos, vel, (0, 10), elasticity=0.9)
print(new_vel)  # Output: -9.0
```
