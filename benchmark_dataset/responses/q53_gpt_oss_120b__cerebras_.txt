┌───────────────────────────────────────┐  
│               Introduction              │  
│───────────────────────────────────────│  
│ In this sandbox we explore how the       │  
│ **stiffness constant** ( *k* ) of a       │  
│ spring‑mass oscillator influences its   │  
│ motion.  By **doubling** *k* we will see   │  
│ the change in the *shape* and *speed*   │  
│ of the oscillation.                       │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│               Quick Definition          │  
│───────────────────────────────────────│  
│ A **spring oscillator** consists of a    │  
│ mass *m* attached to a spring with        │  
│ stiffness *k*.  When displaced, it       │  
│ executes simple harmonic motion (SHM).   │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│               Key Concepts               │  
│───────────────────────────────────────│  
│ • **Stiffness (k)** – force needed per    │  
│   unit extension (N m⁻¹).                 │  
│ • **Mass (m)** – the inertial element.    │  
│ • **Angular frequency (ω)** –            │  
│   √(k/m) (rad s⁻¹).                       │  
│ • **Period (T)** – 2π/ω (s).               │  
│ • **Amplitude (A)** – maximum displacement│  
│   (set by initial energy).                │  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│               Main Formula               │  
│───────────────────────────────────────│  
│            ω = √(k / m)                  │  
│                                           │  
│  • *ω* – angular frequency (rad s⁻¹)       │  
│  • *k* – spring stiffness (N m⁻¹)          │  
│  • *m* – mass (kg)                        │  
│                                           │  
│ [ Explain Formula ]   [ Open Formula Lab ]│  
└───────────────────────────────────────┘  

┌───────────────────────────────────────┐  
│               Visual Explanation         │  
│───────────────────────────────────────│  
│ When *k* is **doubled** (k → 2k):        │  
│                                           │  
│ • **Frequency** ↑  →  ω' = √(2k/m) = √2·ω │  
│   → period T' = T/√2 (oscillation **faster**)│  
│ • **Amplitude** stays the same if the    │  
│   initial energy is unchanged (energy   │  
│   → ½ k A², so larger *k* gives same A). │  
│ • The **curve** looks “tighter” – more   │  
│   cycles per unit time.                  │  
│                                           │  
│ Imagine a sinusoidal animation:         │  
│   - Original: 1 Hz (blue)                │  
│   - Doubled k: ≈1.41 Hz (red) – tighter   │  
│                                           │  
│ The sandbox updates the animation in real│  
│ time as you toggle the *k* slider.       │  
└───────────────────────────────────────┘

┌───────────────────────────────────────┐  
│               Summary                     │  
│───────────────────────────────────────│  
│ • Doubling the spring stiffness **increases**│  
│   the angular frequency by √2.            │  
│ • The period shortens to 1/√2 of its       │  
│   original value.                         │  
│ • Amplitude (for fixed energy) stays the   │  
│   same, but the system feels “stiffer”.   │  
│ • The sandbox lets you see these changes   │  
│   instantly.                               │
