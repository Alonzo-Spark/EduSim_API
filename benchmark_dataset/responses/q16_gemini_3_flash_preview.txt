┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ **Introduction: The Physics of Work**                                                     │
├───────────────────────────────────────────────────────────────────────────────────────────┤
│ In everyday language, "work" refers to any physical or mental effort. However, in physics, │
│ work has a very specific definition involving the application of force and the resulting  │
│ displacement of an object.                                                                │
└───────────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ **Definition**                                                                            │
├───────────────────────────────────────────────────────────────────────────────────────────┤
│ **Work** is defined as the product of the component of the force in the direction of the  │
│ displacement and the magnitude of this displacement.                                      │
│                                                                                           │
│ *Work is done only when a force applied to an object causes that object to move.*         │
└───────────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ **Main Formula**                                                                          │
├───────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                           │
│   $$W = F \cdot d \cdot \cos(\theta)$$                                                    │
│                                                                                           │
├───────────────────────────────────────────────────────────────────────────────────────────┤
│ **Variables:**                                                                            │
│ • $W$: Work done                                                                          │
│ • $F$: Magnitude of force applied                                                         │
│ • $d$: Magnitude of displacement                                                          │
│ • $\theta$: Angle between the force and displacement vectors                              │
│                                                                                           │
│ [ 🔬 Open Formula Lab ]                                                                   │
└───────────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ **SI Unit & Measurement**                                                                 │
├───────────────────────────────────────────────────────────────────────────────────────────┤
│ The standard unit for measuring work is the **Joule (J)**.                                │
│                                                                                           │
│ > **1 Joule** is defined as the amount of work done when a force of **1 Newton**          │
│ > displaces an object by **1 meter** in the direction of the force.                       │
│                                                                                           │
│ **Dimensional Formula:** $[ML^2T^{-2}]$                                                  │
└───────────────────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────────────────┐
│ **Characteristics of Work**                                                               │
├───────────────────────────────────────────────────────────────────────────────────────────┤
│ • **Scalar Quantity:** Work has magnitude but no direction.                               │
│ • **Positive Work:** When force and displacement are in the same direction ($0^\circ$).   │
│ • **Negative Work:** When force opposes motion (e.g., friction).                          │
│ • **Zero Work:** When force is perpendicular to displacement (e.g., carrying a bucket).   │
└───────────────────────────────────────────────────────────────────────────────────────────┘
