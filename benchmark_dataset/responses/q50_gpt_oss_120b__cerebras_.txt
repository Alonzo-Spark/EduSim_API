┌───────────────────────────────────────────────┐
│ Introduction                                    │
│                                               │
│ Electrical power is the rate at which         │
│ electrical energy is transferred or           │
│ converted.  In everyday life it tells us how   │
│ much work can be done by an electrical         │
│ device per unit time.                           │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Quick Definition                               │
│                                               │
│ **Electrical Power (P)** – the amount of      │
│ energy transferred per second, measured in     │
│ watts (W).                                      │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Derivation                                     │
│                                               │
│ 1. **Work‑Energy Principle**                  │
│    The work done by a charge *q* moving       │
│    through a potential difference *V* is      │
│       W = q V.                                 │
│                                               │
│ 2. **Current Definition**                     │
│    Electric current *I* is the rate of flow   │
│    of charge:  I = dq/dt.                      │
│                                               │
│ 3. **Power as Work per Unit Time**             │
│    Power is the time‑derivative of work:       │
│       P = dW/dt.                               │
│                                               │
│ 4. **Substitute W = q V** into the power        │
│    expression:**                               │
│       P = d(q V)/dt = V · dq/dt   (V is constant) │
│                                               │
│ 5. **Replace dq/dt with I**:                  │
│       P = V · I.                               │
│                                               │
│ Hence the fundamental relationship            │
│ **P = V I**.                                    │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Main Formula                                   │
│                                               │
│               P = V I                         │
│                                               │
│ [ Explain Formula ]   –   The formula states  │
│ that electrical power equals the product of   │
│ voltage (potential difference) and current.  │
│                                               │
│ [ Open Formula Lab ]   –   Experiment with    │
│ varying V or I to see the effect on P.        │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Applications                                   │
│                                               │
│ • Household appliances – rating (W) tells    │
│   how much energy they consume per hour.      │
│ • Electrical utilities – power (MW)          │
│   indicates the capacity of generators.       │
│ • Electronics – design of circuits to meet   │
│   power budgets and thermal limits.           │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Summary                                        │
│                                               │
│ • Power = energy per unit time (W).            │
│ • Derived from work‑energy principle and       │
│   definition of current.                      │
│ • Simple, universal relation: **P = V I**.    │
└───────────────────────────────────────────────┘
