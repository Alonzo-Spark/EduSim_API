┌───────────────────────────┐  
│ Quick Definition          │  
│                           │  
│ Inertia is the property   │  
│ of an object to resist any│  
│ change in its state of    │  
│ motion.                  │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Types of Inertia          │  
│                           │  
│ 1. **Inertia of Rest**   │  
│    - This refers to the   │  
│      tendency of an object│  
│      to remain at rest    │  
│      unless acted upon by │  
│      an external force.   │  
│                           │  
│ 2. **Inertia of Motion**  │  
│    - This is the tendency  │  
│      of an object in motion│  
│      to continue moving at │  
│      a constant velocity   │  
│      in a straight line    │  
│      unless acted upon by  │  
│      an external force.   │  
│                           │  
│ 3. **Inertia of Direction**│  
│    - This refers to the    │  
│      tendency of an object │  
│      to maintain its      │  
│      direction of motion.  │  
└───────────────────────────┘
