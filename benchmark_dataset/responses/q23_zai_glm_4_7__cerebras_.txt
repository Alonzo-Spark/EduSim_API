Here is the explanation of the difference between mass and weight, structured as an interactive textbook.

┌─────────────────────────────────────────────────────┐
│ INTRODUCTION                                         │
│                                                      │
│ It is a common misconception that mass and weight   │
│ are the same thing. In physics, they represent two  │
│ fundamentally different properties of matter. While │
│ your weight might change depending on where you are  │
│ in the universe, your mass remains constant.        │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ QUICK DEFINITION                                    │
│                                                      │
│ **Mass**                                             │
│ The quantity of matter in an object. It is a        │
│ measure of an object's resistance to acceleration   │
│ (inertia).                                           │
│                                                      │
│ **Weight**                                           │
│ The force exerted on an object due to gravity. It   │
│ is the measure of the pull of gravity on that mass. │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ KEY CONCEPTS                                        │
│                                                      │
│ • **Inertia:** Mass is the quantitative measure of  │
│   inertia. The more mass an object has, the harder  │
│   it is to move or stop.                            │
│                                                      │
│ • **Gravitational Field:** Weight exists because of │
│   gravity. If there is no gravity (like in deep     │
│   space), an object has mass but is weightless.     │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ APPLICATION: THE MOON VS. EARTH                     │
│                                                      │
│ If you travel to the Moon:                           │
│                                                      │
│ 1. Your **Mass** stays exactly the same. You still  │
│    have the same amount of atoms in your body.      │
│                                                      │
│ 2. Your **Weight** decreases significantly (about   │
│    1/6th of your Earth weight) because the Moon's   │
│    gravitational pull ($g$) is much weaker.         │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ SUMMARY                                             │
│                                                      │
│ Mass is the "stuff" (matter), while Weight is the   │
│ "pull" (force). Mass is intrinsic and constant;     │
│ Weight is extrinsic and depends on gravity.         │
└─────────────────────────────────────────────────────┘
