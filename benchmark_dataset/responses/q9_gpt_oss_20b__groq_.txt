┌───────────────────────────┐
│ **Introduction**           │
│                           │
│ Uniform circular motion     │
│ occurs when an object moves  │
│ along a circular path with   │
│ constant speed. The motion  │
│ is “uniform” because the     │
│ speed (magnitude of velocity)│
│ does not change, though the  │
│ direction of the velocity    │
│ vector continuously changes │
│ due to the curvature of the │
│ path.                        │
└───────────────────────────┘

┌───────────────────────────┐
│ **Definition**             │
│                           │
│ A particle undergoing       │
│ uniform circular motion has  │
│ a constant speed \(v\) and a │
│ velocity vector that always  │
│ points tangent to the circle│
│ and whose magnitude remains │
│ unchanged. The acceleration │
│ that keeps the particle on │
│ the circular path is called │
│ centripetal acceleration.  │
└───────────────────────────┘

┌───────────────────────────┐
│ **Key Concepts**           │
│                           │
│ • Tangential speed \(v\)   │
│ • Angular speed \(\omega\) │
│ • Radius of curvature \(r\)│
│ • Centripetal acceleration│
│   \(a_c\)                   │
│ • Centripetal force \(F_c\)│
└───────────────────────────┘

┌───────────────────────────┐
│ **Characteristics**        │
│                           │
│ • Speed is constant, but   │
│   velocity direction changes│
│ • Acceleration is always   │
│   directed toward the center│
│   of the circle (inward).  │
│ • Magnitude of acceleration│
│   depends on speed and     │
│   radius: \(a_c = v^2/r\). │
└───────────────────────────┘

┌───────────────────────────┐
│ **Formula**                │
│                           │
│ The centripetal acceleration and force are given by: │
└───────────────────────────┘

┌───────────────────────────┐
│ **Main Formula**           │
│                           │
│     \[ a_c = \frac{v^2}{r} \]          │

┌───────────────────────────┐
│ **Applications**           │
│                           │
│ • Planetary orbits (idealized) │
│ • Satellites in orbit        │
│ • Roller‑coaster loops       │
│ • Centrifugal machines (e.g., centrifuges) │
│ • Projectiles in circular tracks │
└───────────────────────────┘

┌───────────────────────────┐
│ **Advantages**             │
│                           │
│ • Provides a clear link between speed, radius, and required force │
│ • Useful for designing circular motion systems (e.g., rides, vehicles) │
│ • Fundamental to understanding orbital dynamics | 
└───────────────────────────┘

┌───────────────────────────┐
│ **Disadvantages**          │
│                           │
│ • Assumes no friction or external forces other than centripetal force │
│ • Real systems often involve additional forces (drag, gravity, etc.) │
│ • Requires precise control of speed and radius for safety | 
└───────────────────────────┘

┌───────────────────────────┐
│ **Important Notes**        │
│                           │
│ • Centripetal acceleration is not a separate force; it is the result of the net force toward the center │
│ • The direction of acceleration is always radial inward, perpendicular to the velocity vector │
│ • For constant radius, higher speeds increase the required centripetal force quadratically │
└───────────────────────────┘

┌───────────────────────────┐
│ **Summary**                │
│                           │
│ Uniform circular motion is a motion with constant speed around a circle. The inward acceleration that keeps the particle on the path is called centripetal acceleration, calculated by \(a_c = v^2/r\) or \(a_c = r\,\omega^2\). The corresponding force is \(F_c = m v^2 / r\). These relationships are essential for analyzing any system that involves circular motion. │
└───────────────────────────┘
