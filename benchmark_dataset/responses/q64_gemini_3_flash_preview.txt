┌────────────────────────────────────────────────────────────────────────────────┐
│ 📘 Quick Definition                                                            │
│                                                                                │
│ The **Spring Stretched Peak Limit** occurs when a mechanical or simulated      │
│ spring reaches its **Elastic Limit**. Beyond this point, the material will no  │
│ longer return to its original shape, entering the phase of plastic deformation.│
└────────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────────┐
│ 📐 Main Formula: Hooke's Law (Limit State)                                     │
│                                                                                │
│                     $$F_{max} = k \cdot \Delta x_{peak}$$                      │
│                                                                                │
│ ℹ️ **Explanation**: This formula calculates the maximum restorative force      │
│ exerted by the spring at the exact moment the peak displacement is triggered.  │
│                                                                                │

┌────────────────────────────────────────────────────────────────────────────────┐
│ 🔑 Key Concepts                                                                │
│                                                                                │
│ ● **Restoring Force ($F$):** The counter-force acting against the stretch.      │
│ ● **Spring Constant ($k$):** The stiffness of the spring (N/m).                │
│ ● **Displacement ($x$):** The distance from the equilibrium position.          │
│ ● **Elastic Potential Energy ($U$):** The energy stored at the peak limit.     │
└────────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────────┐
│ ⚡ Energy Calculation                                                          │
│                                                                                │
│                     $$U_e = \frac{1}{2} k x^2$$                                │
│                                                                                │
│ ℹ️ **Explanation**: Represents the total work done to stretch the spring to    │
│ the current peak. Any further displacement results in energy loss via heat.    │
