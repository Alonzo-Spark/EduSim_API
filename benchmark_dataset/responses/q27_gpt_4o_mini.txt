┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Pascal's law states that  │
│ a change in pressure      │
│ applied to an enclosed    │
│ fluid is transmitted      │
│ undiminished to all parts │
│ of the fluid and to the   │
│ walls of its container.   │
└───────────────────────────┘

┌───────────────────────────┐
│ Applications              │
│                           │
│ 1. Hydraulic Systems:     │
│    Used in hydraulic      │
│    presses and lifts.     │
│                           │
│ 2. Brake Systems:         │
│    Hydraulic brakes in    │
│    vehicles utilize       │
│    Pascal's law to apply  │
│    force evenly.          │
│                           │
│ 3. Hydraulic Jacks:      │
│    Used for lifting heavy  │
│    loads using minimal     │
│    input force.           │
│                           │
│ 4. Fluid Power Systems:   │
│    Utilized in machinery   │
│    where fluid pressure    │
│    is harnessed for work. │
└───────────────────────────┘
