┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ Simple Harmonic Motion (SHM) is a      │
│ foundational concept in the study of   │
│ oscillations and waves. It describes   │
│ the motion of a system that experiences │
│ a restoring force proportional to its │
│ displacement from an equilibrium       │
│ position. This idealized motion appears│
│ in many physical systems, from pendulums│
│ to mass‑spring systems and even          │
│ electromagnetic waves.                 │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Definition                             │
│                                       │
│ **Simple Harmonic Motion** is the      │
│ motion of a particle for which the     │
│ restoring force **F** satisfies        │
│ **F = –k x**, where **k** is a positive │
│ constant and **x** is the displacement │
│ from equilibrium. Consequently, the    │
│ acceleration **a** is directly         │
│ proportional to the negative of the    │
│ displacement: **a = –ω² x**.            │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Key Concepts                           │
│                                       │
│ • **Restoring Force** – pulls the system│
│   back toward equilibrium.            │
│ • **Angular Frequency (ω)** –          │
│   ω = √(k/m) for a mass‑spring system. │
│ • **Period (T)** – time for one full    │
│   oscillation, T = 2π/ω.               │
│ • **Amplitude (A)** – maximum          │
│   displacement from equilibrium.      │
│ • **Phase (φ)** – determines the        │
│   starting point of the motion.        │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Characteristics                        │
│                                       │
│ • Motion is sinusoidal in time.        │
│ • Energy oscillates between kinetic   │
│   and potential forms, but total       │
│   mechanical energy remains constant. │
│ • Frequency and period are independent │
│   of amplitude (for ideal SHM).        │
│ • Phase determines the temporal shift  │
│   of the sinusoid.                     │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Main Formula                           │
│                                       │
│     x(t) = A cos(ω t + φ)              │

└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Applications                           │
│                                       │
│ • Pendulums (small angles)             │
│ • Mass‑spring oscillators               │
│ • LC circuits (electric analogues)     │
│ • Vibrations of molecules               │
│ • Acoustic resonators (musical      │
│   instruments)                         │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Advantages                             │
│                                       │
│ • Simple analytical solutions          │
│ • Predictable periodic behavior        │
│ • Forms the basis for more complex      │
│   oscillatory systems (e.g., damped,  │
│   driven).                             │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Disadvantages                          │
│                                       │
│ • Real systems exhibit damping,       │
│   non‑linearity, and external forces, │
│   deviating from ideal SHM.            │
│ • Assumes small angles for pendulums, │
│   limiting its range of applicability.│
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Important Notes                        │
│                                       │
│ • The term “simple” refers to the      │
│   linear restoring force, not the      │
│   simplicity of the system.            │
│ • For a mass‑spring system, ω = √(k/m)│
│   and T = 2π√(m/k).                    │
│ • Phase φ can be set by initial        │
│   conditions: x(0) = A cos φ,          │
│   v(0) = –A ω sin φ.                   │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Summary                                │
│                                       │
│ Simple Harmonic Motion describes a     │
│ sinusoidal oscillation where the       │
│ restoring force is proportional to     │
│ displacement. Its hallmark is the       │
│ equation **x(t)=A cos(ω t+φ)**, with    │
│ constant amplitude, frequency, and     │
│ phase. SHM underpins many physical      │
│ phenomena, serving as the stepping stone│
│ toward understanding more complex      │
│ vibrational behavior.                  │
└───────────────────────────────────────┘
