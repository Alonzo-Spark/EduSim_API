┌─────────────────────────────────────────────┐
│ Quick Definition                            │
│                                             │
│ Retardation is the negative acceleration   │
│ that slows a moving object until it comes   │
│ to rest. It is measured in meters per second│
│ squared (m/s²).                             │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ Main Formula                                │
│                                             │
│     a = Δv / Δt                             │
│                                             │
│ [ Explain Formula ]  [ Open Formula Lab ]   │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ Example Problem                             │
│                                             │
│ A train is moving at 20 m/s and applies     │
│ brakes. It comes to a complete stop after   │
│ 10 s. Find the retardation.                 │
│                                             │
│ **Solution**                                │
│ • Initial velocity, v₀ = 20 m/s              │
│ • Final velocity, v = 0 m/s                 │
│ • Time interval, Δt = 10 s                  │
│                                             │
│ a = (v – v₀) / Δt = (0 – 20) / 10 = –2      │
│ m/s²                                       │
│                                             │
│ **Answer**                                  │
│ The train’s retardation is 2 m/s² (negative │
│ sign indicates slowing).                    │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ Summary                                     │
│                                             │
│ • Retardation is a negative acceleration.   │
│ • Formula: a = Δv / Δt.                     │
│ • In the example, a = –2 m/s², magnitude   │
│   2 m/s².                                   │
└─────────────────────────────────────────────┘
