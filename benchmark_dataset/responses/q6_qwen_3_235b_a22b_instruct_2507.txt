┌───────────────────────────┐  
│      Introduction         │  
│                           │  
│ Projectile motion is a   │  
│ fundamental example of   │  
│ motion in two dimensions │  
│ under the influence of   │  
│ gravity. It describes    │  
│ the curved path followed │  
│ by an object launched    │  
│ into the air.            │  
└───────────────────────────┘  

┌───────────────────────────┐  
│   Quick Definition        │  
│                           │  
│ **Projectile motion** is │  
│ the two-dimensional      │  
│ motion of an object that │  
│ moves along a curved     │  
│ (parabolic) path under   │  
│ the influence of gravity │  
│ alone, after being given │  
│ an initial velocity.     │  
└───────────────────────────┘  

┌───────────────────────────┐  
│    Key Characteristics    │  
│                           │  
│ • Occurs in a vertical   │  
│   plane (2D motion).      │  
│ • Horizontal motion is   │  
│   uniform (constant       │  
│   velocity).              │  
│ • Vertical motion is     │  
│   uniformly accelerated  │  
│   (due to gravity).       │  
│ • The only force acting  │  
│   is gravity (air        │  
│   resistance neglected).  │  
│ • Path followed is       │  
│   parabolic (under        │  
│   uniform gravity).      │  
│ • Independent horizontal │  
│   and vertical motions.  │  
└───────────────────────────┘  

┌───────────────────────────┐  
│       Formula             │  
│                           │  
│     $$                     │  
│     x(t) = v_0 \cos\theta \cdot t  
│     $$                     │  
│                           │  
│ [ Explain Formula ]       │  
│ [ Open Formula Lab ]      │  
└───────────────────────────┘  

┌───────────────────────────┐  
│       Formula             │  
│                           │  
│     $$                     │  
│     y(t) = v_0 \sin\theta \cdot t - \frac{1}{2}gt^2  
│     $$                     │  
│                           │  
│ [ Explain Formula ]       │  
│ [ Open Formula Lab ]      │  
└───────────────────────────┘  

┌───────────────────────────┐  
│   Motion Components       │  
│                           │  
│ Horizontal:               │  
│   - No acceleration       │  
│   - \( a_x = 0 \)         │  
│   - \( v_x = v_0\cos\theta \) │  
│                           │  
│ Vertical:                 │  
│   - Constant acceleration │  
│   - \( a_y = -g \)        │  
│   - \( v_y = v_0\sin\theta - gt \) │  
└───────────────────────────┘  

┌───────────────────────────┐  
│   Important Notes         │  
│                           │  
│ • The horizontal and      │  
│   vertical motions are    │  
│   completely independent. │  
│   This is known as the    │  
│   **principle of         │  
│   independence of motions**.│  
│ • The time of flight,     │  
│   maximum height, and     │  
│   range depend on initial │  
│   speed and launch angle. │  
│ • At the highest point of │  
│   trajectory, vertical    │  
│   velocity becomes zero.  │  
│ • Symmetry: Time to rise  │  
│   equals time to fall (for│  
│   same launch and landing │  
│   height).                │  
└───────────────────────────┘  

┌───────────────────────────┐  
│     Applications          │  
│                           │  
│ • Sports (kicking,        │  
│   throwing balls)         │  
│ • Military (trajectory of│  
│   shells, missiles)       │  
│ • Space launches and      │  
│   re-entry paths          │  
│ • Fountains and water     │  
│   jets                    │  
│ • Design of roller        │  
│   coasters and jumps      │  
└───────────────────────────┘  

┌───────────────────────────┐  
│    Advantages of Model    │  
│                           │  
│ • Simplifies real-world   │  
│   motion using idealized  │  
│   physics.                │  
│ • Enables accurate        │  
│   predictions of position │  
│   and time.               │  
│ • Foundation for more     │  
│   complex dynamics (e.g., │  
│   with air resistance).   │  
└───────────────────────────┘  

┌───────────────────────────┐  
│    Limitations            │  
│                           │  
│ • Neglects air resistance │  
│   (significant at high    │  
│   speeds).                │  
│ • Assumes flat Earth and  │  
│   uniform gravity.        │  
│ • Does not account for    │  
│   wind or rotation of     │  
│   Earth (Coriolis effect).│  
│ • Real projectiles may    │  
│   spin or have variable   │  
│   mass.                   │  
└───────────────────────────┘  

┌───────────────────────────┐  
│       Summary             │  
│                           │  
│ Projectile motion is a   │  
│ classic case of 2D motion│  
│ where horizontal velocity│  
│ remains constant and     │  
│ vertical motion is       │  
│ accelerated by gravity.  │  
│ The trajectory is         │  
│ parabolic, and motion can │  
│ be analyzed by resolving │  
│ into independent x and y  │  
│ components.               │  
└───────────────────────────┘  

### Suggested Questions for Practice  
- What is the time of flight of a projectile launched and landing at the same height?  
- Derive the expression for maximum height.  
- At what angle is the range of a projectile maximized?  
- How does doubling the initial speed affect the range?  
- Why is the path parabolic? Prove it from the equations.
