## Physics Response Engine

When **g = 0**, the following transformations apply across all active simulations:

---

### Core Formula Update

$$
F_g = mg \quad \Rightarrow \quad F_g = m \cdot 0 = 0
$$

$$
W = mg = 0 \text{ N} \quad \forall \text{ objects}
$$

$$
a_{net} = \frac{F_{net}}{m} \quad \text{(gravity term removed)}
$$

### Overlay Runtime Patch

```js
// gravity_changed event handler
sandbox.on("gravity_changed", (event) => {
  const { g } = event.payload; // g = 0

  physics.setGravity(g);                  // → 0
  renderer.updateTrajectories();          // → linear paths
  formulas.invalidate("pendulum");        // → undefined period
  formulas.invalidate("fluid_pressure"); // → zero gradient
  ui.showOverlay("zero-g-mode");          // → banner active
});
```

---

### Simulation Behavior Changes

**Projectile Motion**
- Path changes from **parabolic → straight line**
- Horizontal velocity persists indefinitely
- Vertical velocity component: unchanged (no deceleration)

**Pendulum**
- Period formula $T = 2\pi\sqrt{\dfrac{L}{g}}$ → **undefined** (division by zero)
- Simulation suspended, warning flag raised

**Fluid Statics**
- Pressure gradient $\Delta P = \rho g h$ collapses to **zero**
- Fluids form **spherical droplets** (surface tension dominant)

**Orbital Mechanics**
- All objects enter **free-float** state
- Relative motion governed by **initial velocity vectors only**
