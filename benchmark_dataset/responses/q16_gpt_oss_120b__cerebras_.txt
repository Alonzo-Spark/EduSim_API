┌───────────────────────────────────────┐
│               Topic Overview           │
│                                       │
│ Work, Energy, and Power are core       │
│ concepts in physics that describe       │
│ how forces cause displacement and      │
│ how that displacement is quantified.   │
│                                       │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│               Definition               │
│                                       │
│ **Work** is the transfer of energy      │
│ that occurs when a force causes an       │
│ object to move a certain distance.      │
│ Mathematically, it is the scalar        │
│ product of the force vector and the      │
│ displacement vector.                    │
│                                       │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│               Main Formula              │
│                                       │
│          W = **F**·**d** = F d cosθ      │
│                                       │
│ • **W** – Work (Joules)                  │
│ • **F** – Magnitude of the force (N)     │
│ • **d** – Displacement magnitude (m)    │
│ • **θ** – Angle between **F** and **d**  │
│                                       │
│ [ Explain Formula ]   [ Open Formula Lab ] │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│               SI Unit of Work           │
│                                       │
│ The SI unit of work is the **joule**    │
│ (symbol: **J**).                         │
│ 1 J = 1 N·m = 1 kg·m²·s⁻²                │
│                                       │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│               Summary                   │
│                                       │
│ • Work = force × displacement × cosθ   │
│ • Measured in joules (J)               │
│ • Represents energy transferred by a   │
│   force acting through a distance       │
│                                       │
└───────────────────────────────────────┘
