┌───────────────────────────┐  
│ Ohm's Law                 │  
│                           │  
│ Ohm's Law states that the │  
│ current (I) flowing through │  
│ a conductor between two    │  
│ points is directly         │  
│ proportional to the       │  
│ voltage (V) across the    │  
│ two points and inversely   │  
│ proportional to the       │  
│ resistance (R) of the     │  
│ conductor. This can be    │  
│ expressed mathematically as:  │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Main Formula              │  
│                           │  
│     $$ V = I \cdot R $$   │  
│                           │  
│ [ Explain Formula ]       │  
│ [ Open Formula Lab ]      │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Limitations of Ohm's Law  │  
│                           │  
│ 1. **Non-linear materials**: Ohm's law is applicable only for materials that have a constant resistance. Non-linear components like diodes and transistors do not follow Ohm's law.  │  
│                           │  
│ 2. **Temperature dependence**: Resistance can change with temperature, affecting the linear relationship between voltage and current.  │  
│                           │  
│ 3. **High frequencies**: At very high frequencies, the behavior of materials can deviate from Ohm's law due to factors like skin effect and capacitance. │  
│                           │  
│ 4. **Complex materials**: In certain materials, such as superconductors or alloys, Ohm's law does not hold true under certain conditions. │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Important Notes           │  
│                           │  
│ Understanding the limits  │  
│ of Ohm's law is crucial   │  
│ for designing and         │  
│ analyzing electrical       │  
│ circuits, especially when  │  
│ working with non-linear    │  
│ components.               │  
└───────────────────────────┘
