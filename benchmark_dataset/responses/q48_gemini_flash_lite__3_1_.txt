**Definition**

```
┌───────────────────────────┐
│ Definition                │
│                           │
│ A parallel combination of │
│ resistors is a circuit    │
│ configuration where all   │
│ resistors are connected   │
│ across the same two nodes.│
└───────────────────────────┘
```

**Key Concepts**

```
┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ 1.  Voltage: The voltage  │
│     across each resistor  │
│     in a parallel circuit │
│     is the same.          │
│ 2.  Current: The total    │
│     current is the sum of │
│     the individual        │
│     currents through each │
│     resistor.             │
└───────────────────────────┘
```

**Derivation**

```
┌───────────────────────────┐
│ Derivation                │
│                           │
│ Let's derive the formula  │
│ for equivalent resistance │
│ in a parallel circuit.    │
└───────────────────────────┘
```

**Step 1: Define Variables**

```
┌───────────────────────────┐
│ Step 1: Define Variables  │
│                           │
│ *   `V` = Voltage across  │
│     the parallel          │
│     combination           │
│ *   `I` = Total current   │
│     through the circuit   │
│ *   `R_eq` = Equivalent   │
│     resistance            │
│ *   `R_1`, `R_2`, ...,    │
│     `R_n` = Individual    │
│     resistor values       │
└───────────────────────────┘
```

**Step 2: Apply Ohm's Law**

```
┌───────────────────────────┐
│ Step 2: Apply Ohm's Law   │
│                           │
│ According to Ohm's Law:   │
│                           │
│     V = I * R_eq          │
│                           │
│ Therefore:                │
│     I = V / R_eq          │
└───────────────────────────┘
```

**Step 3: Current Division**

```
┌───────────────────────────┐
│ Step 3: Current Division  │
│                           │
│ In a parallel circuit,    │
│ the total current `I` is  │
│ the sum of currents      │
│ through each resistor:    │
│                           │
│     I = I_1 + I_2 + ... + I_n │
└───────────────────────────┘
```

**Step 4: Apply Ohm's Law to each resistor**

```
┌───────────────────────────┐
│ Step 4: Apply Ohm's Law   │
│ to each resistor        │
│                           │
│ Using Ohm's Law for each  │
│ resistor:                 │
│                           │
│     I_1 = V / R_1         │
│     I_2 = V / R_2         │
│     ...                   │
│     I_n = V / R_n         │
└───────────────────────────┘
```

**Step 5: Substitute and Simplify**

```
┌───────────────────────────┐
│ Step 5: Substitute and   │
│ Simplify                  │
│                           │
│ Substitute the individual │
│ currents into the total   │
│ current equation:         │
│                           │
│     V / R_eq = V / R_1 + V / R_2 + ... + V / R_n │
│                           │
│ Divide both sides by `V`: │
│                           │
│     1 / R_eq = 1 / R_1 + 1 / R_2 + ... + 1 / R_n │
└───────────────────────────┘
```

**Advantages**

```
┌───────────────────────────┐
│ Advantages                │
│                           │
│ 1.  If one component     │
│     fails, the others     │
│     continue to function. │
│ 2.  Each component        │
│     receives the full     │
│     source voltage.       │
└───────────────────────────┘
```

**Disadvantages**

```
┌───────────────────────────┐
│ Disadvantages             │
│                           │
│ 1.  The total current    │
│     drawn from the source │
│     increases as more     │
│     components are added. │
└───────────────────────────┘
```

```

│     resistance in a       │
│     parallel circuit is   │

└───────────────────────────┘
```
