### 📘 Physics Module: Conservation of Mechanical Energy

┌──────────────────────────────────────────────────────────────────┐
│ **Introduction**                                                 │
│                                                                  │
│ The Principle of Conservation of Mechanical Energy states that   │
│ in an isolated system where only conservative forces (like       │
│ gravity or spring force) are acting, the total mechanical energy │
│ remains constant over time.                                      │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Definition**                                                   │
│                                                                  │
│ **Mechanical Energy ($E$)** is the sum of the potential energy    │
│ ($U$) and the kinetic energy ($K$) of an object.                 │
│                                                                  │
│ > "Energy can neither be created nor destroyed; it can only be   │
│ > transformed from one form to another."                         │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Main Formula**                                                 │
│                                                                  │
│ $$ E_{total} = K + U = \text{Constant} $$                        │
│                                                                  │
│ [ **Explain Formula** ]                                          │
│ $K = \frac{1}{2}mv^2$ (Kinetic Energy)                           │
│ $U = mgh$ (Gravitational Potential Energy)                       │
│                                                                  │
│ [ **Open Formula Lab** ]                                         │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Key Concepts**                                                 │
│                                                                  │
│ • **Conservative Forces:** Forces like gravity where work done   │
│   depends only on initial and final positions.                   │
│ • **Energy Transformation:** As an object falls, $U$ decreases   │
│   while $K$ increases, but their sum stays the same.             │
│ • **Isolated System:** No external friction or air resistance.   │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Example: The Free-Falling Ball**                               │
│                                                                  │
│ Consider a ball of mass $m$ dropped from a height $H$.           │
│                                                                  │
│ **1. At Maximum Height ($H$):**                                  │
│ Velocity is zero, so $K = 0$. Total Energy = $mgH$.              │
│                                                                  │
│ **2. During the Fall:**                                          │
│ Height decreases (Potential $\downarrow$), Speed increases       │
│ (Kinetic $\uparrow$).                                            │
│                                                                  │
│ **3. Just Before Impact:**                                       │
│ Height is zero ($U = 0$). All energy has converted to Kinetic.   │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Energy Distribution Table**                                    │
│                                                                  │
│ | Position | Potential ($mgh$) | Kinetic ($\frac{1}{2}mv^2$) | Total ($E$) |
│ | :--- | :--- | :--- | :--- |
│ | Top | Max | 0 | $E_{total}$ |
│ | Mid-way | $1/2$ Max | $1/2$ Max | $E_{total}$ |
│ | Bottom | 0 | Max | $E_{total}$ |
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Important Notes**                                              │
│                                                                  │
│ ⚠️ In the real world, "lost" energy usually turns into heat or   │
│ sound due to friction. In these cases, Mechanical Energy is NOT  │
│ conserved, but Total Energy (including heat) always is.          │
└──────────────────────────────────────────────────────────────────┘
