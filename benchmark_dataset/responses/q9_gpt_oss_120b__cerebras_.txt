┌─────────────────────────────────────────────┐
│               Introduction                  │
│                                             │
│ Uniform Circular Motion (UCM) describes a   │
│ motion where an object travels along a       │
│ circle at a constant speed. Even though the   │
│ speed (the magnitude of velocity) is constant│
│, the direction of the velocity continuously   │
│ changes, which means the object is accelerating│
│ toward the centre of the circle. This       │
│ inward‑pointing acceleration is called       │
│ **centripetal acceleration**.                │
└─────────────────────────────────────────────┘


┌─────────────────────────────────────────────┐
│                Definition                    │
│                                             │
│ • **Uniform Circular Motion (UCM)** –       │
│   Motion along a circular path with constant│
│   linear speed *v* (or constant angular      │
│   speed *ω*).                                 │
│                                             │
│ • **Centripetal Acceleration** – The        │
│   acceleration that constantly points       │
│   toward the centre of the circular path,   │
│   keeping the object in circular motion.    │
└─────────────────────────────────────────────┘


┌─────────────────────────────────────────────┐
│               Key Concepts                  │
│                                             │
│ - **Radius (r)** – Distance from the centre  │
│   of the circle to the moving object.        │
│ - **Linear Speed (v)** – Tangential speed     │
│   along the path (|v| = constant).            │
│ - **Angular Speed (ω)** – Rate of rotation,   │
│   ω = dθ/dt (rad·s⁻¹).                         │
│ - **Period (T)** – Time for one full circuit,│
│   T = 2π/ω = 2πr/v.                           │
│ - **Frequency (f)** – Revolutions per second,│
│   f = 1/T.                                    │
│ - **Centripetal Force (F_c)** – The net      │
│   inward force required: F_c = m a_c.        │
└─────────────────────────────────────────────┘


┌─────────────────────────────────────────────┐
│               Main Formula                  │
│                                             │
│               a_c = v² / r                 │
│               a_c = ω² r                    │
│                                             │

└─────────────────────────────────────────────┘


┌─────────────────────────────────────────────┐
│                Applications                 │
│                                             │
│ • Planetary orbits – gravity provides the   │
│   centripetal force.                         │
│ • Car turning a curve – friction supplies   │
│   the required centripetal force.           │
│ • Satellite motion – tension in a rope or   │
│   electromagnetic force keeps it in orbit. │
│ • Rotating amusement rides – riders feel    │
│   a “pseudo‑centrifugal” effect opposite to  │
│   the real centripetal acceleration.        │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│                  Summary                    │
│                                             │
│ • In Uniform Circular Motion the speed is   │
│   constant, but the velocity direction       │
│   changes, producing a centripetal           │
│   acceleration toward the centre.            │
│ • The magnitude of that acceleration is      │
│   a_c = v² / r = ω² r.                       │
│ • Any force that provides the required       │
│   inward pull (gravity, tension, friction)  │
│   acts as the centripetal force.             │
└─────────────────────────────────────────────┘
