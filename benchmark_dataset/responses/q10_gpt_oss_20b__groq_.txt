┌───────────────────────────────────────────────────────────────┐
│                         Definition                           │
│                                                               │
│ A **scalar** is a physical quantity that is completely        │
│ described by a magnitude (numerical value) and a unit. It     │
│ has no direction.                                            │
│                                                               │
│ A **vector** is a physical quantity that is described by     │
│ both a magnitude and a direction. It is represented by a     │
│ magnitude, a direction (often an angle or a set of          │
│ components), and a unit.                                      │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                       Key Concepts                           │
│                                                               │
│ • **Components**: Scalars have one component (the magnitude). │
│   Vectors have multiple components (e.g., horizontal and    │
│   vertical components).                                       │
│ • **Transformation**: Scalars remain unchanged under           │
│   coordinate transformations. Vectors transform according to  │
│   the rules of vector algebra.                                 │
│ • **Addition**: Scalars add algebraically (e.g., 5 m + 3 m = 8 m). │
│   Vectors add vectorially, requiring both magnitude and       │
│   direction (e.g., 5 m i + 3 m j).                             │
│ • **Physical Interpretation**: Scalars often represent       │
│   quantities like mass, temperature, or energy. Vectors       │
│   represent quantities like velocity, force, or displacement. │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                          Examples                            │
│                                                               │
│ **Scalars**:                                                     │
│   • Mass (kg)                                                   │
│   • Temperature (°C)                                            │
│   • Speed (m/s) – note: speed is the magnitude of velocity     │
│   • Energy (J)                                                  │
│   • Time (s)                                                    │
│                                                               │
│ **Vectors**:                                                     │
│   • Velocity (m/s) – magnitude + direction                    │
│   • Force (N)                                                   │
│   • Displacement (m)                                            │
│   • Acceleration (m/s²)                                         │
│   • Electric field (N/C)                                        │
│   • Momentum (kg·m/s)                                           │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                          Summary                              │
│                                                               │
│ Scalars: single number + unit, no direction. Vectors: number   │
│ + direction, represented by components or arrows. The choice   │
│ between scalar and vector depends on whether direction is     │
│ essential to the physical description.                        │
└───────────────────────────────────────────────────────────────┘
