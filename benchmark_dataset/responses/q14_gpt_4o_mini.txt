┌───────────────────────────┐  
│ Introduction              │  
│                           │  
│ Momentum is a fundamental  │  
│ concept in physics that   │  
│ describes the quantity of  │  
│ motion an object possesses.│  
│ It is defined as the      │  
│ product of an object's     │  
│ mass and its velocity.     │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Quick Definition          │  
│                           │  
│ Momentum (p) is defined as│  
│ the product of an object's │  
│ mass (m) and its velocity  │  
│ (v):                       │  
│                           │  
│ \( p = mv \)              │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Key Concepts              │  
│                           │  
│ 1. **Mass (m)**: The amount│  
│    of matter in an object. │  
│ 2. **Velocity (v)**: The   │  
│    speed of an object in a │  
│    specific direction.     │  
│ 3. **Momentum (p)**: A     │  
│    vector quantity that    │  
│    depends on both mass and│  
│    velocity.              │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Derivation of the Law of  │  
│ Conservation of Momentum   │  
│                           │  
│ The law of conservation of │  
│ momentum states that the   │  
│ total momentum of a closed │  
│ system remains constant    │  
│ if no external forces act  │  
│ on it.                    │  
│                           │  
│ Consider two objects, A   │  
│ and B, colliding with each │  
│ other. Let:               │  
│ - \( m_A \) and \( m_B \) │  
│   be the masses of A and B │  
│ - \( u_A \) and \( u_B \) │  
│   be the initial velocities │  
│ - \( v_A \) and \( v_B \) │  
│   be the final velocities   │  
│                           │  
│ According to the law of    │  
│ conservation of momentum:  │  
│                           │  
│ \( m_A u_A + m_B u_B = m_A v_A + m_B v_B \)  │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Main Formula              │  
│                           │  
│     Rendered Formula      │  
│                           │  
│ \[ m_A u_A + m_B u_B = m_A v_A + m_B v_B \] │  
│                           │  
│ [ Explain Formula ]       │  
│ [ Open Formula Lab ]      │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Characteristics           │  
│                           │  
│ - **Vector Quantity**:    │  
│   Momentum has both       │  
│   magnitude and direction. │  
│ - **Depends on Mass and   │  
│   Velocity**: An increase  │  
│   in either mass or velocity│  
│   results in an increase    │  
│   in momentum.             │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Applications              │  
│                           │  
│ - **Collision Analysis**:  │  
│   Used to analyze collisions│  
│   in sports, car accidents, │  
│   and particle physics.    │  
│ - **Rocket Propulsion**:   │  
│   Momentum conservation is  │  
│   fundamental to rocket    │  
│   launches and space travel.│  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Advantages                │  
│                           │  
│ - Simplifies complex       │  
│   interactions into a     │  
│   manageable framework.    │  
│ - Helps in predicting the  │  
│   outcome of collisions.   │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Disadvantages             │  
│                           │  
│ - Only applicable in closed │  
│   systems or in systems    │  
│   with negligible external  │  
│   forces.                 │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Important Notes           │  
│                           │  
│ - The total momentum before│  
│   an interaction equals the│  
│   total momentum after the │  
│   interaction if no external│  
│   forces are present.     │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Summary                   │  
│                           │  
│ Momentum is the product of │  
│ mass and velocity, and the │  
│ law of conservation of     │  
│ momentum states that in a  │  
│ closed system, the total   │  
│ momentum remains constant. │  
└───────────────────────────┘
