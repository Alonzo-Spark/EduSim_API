│ Quick Definition                                            │
│                                                             │
│ **Weightlessness** (or microgravity) is not the absence of  │
│ gravity. It is the state where an object is in a constant   │
│ state of **freefall**. Because the spacecraft and the       │
│ astronaut are falling at the same rate, the astronaut does  │
│ not push against the floor, creating the sensation of       │
│ floating.                                                    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Key Concepts                                                │
│                                                             │
│ • **Gravity is Present:** At the altitude of the ISS        │
│   (approx. 400 km), Earth's gravity is still about 90% as   │
│   strong as it is on the surface.                           │
│                                                             │
│ • **Freefall:** The spacecraft is constantly falling toward  │
│   Earth. However, it is also moving sideways at a very      │
│   high velocity (approx. 28,000 km/h).                      │
│                                                             │
│ • **The Curve:** As the spacecraft falls, the Earth curves  │
│   away beneath it. The spacecraft never gets closer to the  │
│   ground; it continuously "misses" the Earth.               │

┌─────────────────────────────────────────────────────────────┐
│ Characteristics                                             │
│                                                             │
│ **Why do they feel weightless?**                            │
│                                                             │
│ On Earth, you feel your weight because the floor pushes     │
│ up against you (Normal Force). In orbit, the floor is       │
│ falling away at the same speed you are. You are not         │
│ pressing against the floor, so you feel no weight.          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Summary                                                     │
│                                                             │
│ 1. Astronauts are not "outside" the pull of gravity.        │
│ 2. They are in a constant state of freefall around the      │
│    planet.                                                   │
│ 3. Weightlessness occurs because they and their ship fall   │
│    at the same rate, eliminating the sensation of support.  │
└─────────────────────────────────────────────────────────────┘
