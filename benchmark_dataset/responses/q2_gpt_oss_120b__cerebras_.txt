┌─────────────────────────────────────┐
│ Introduction                        │
│                                     │
│ A car starts from rest (initial      │
│ velocity \(u = 0\)) and accelerates │
│ uniformly with acceleration          │
│ \(a = 2\ \text{m/s}^2\). We want to   │
│ determine its velocity after        │
│ \(t = 10\ \text{s}\).                │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Main Formula                        │
│                                     │
│ \[ v = u + a\,t \]                  │
│                                     │
│ [ Explain Formula ]                 │
│ [ Open Formula Lab ]                │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Calculation                         │
│                                     │
│ Given:                              │
│   \(u = 0\)                         │
│   \(a = 2\ \text{m/s}^2\)           │
│   \(t = 10\ \text{s}\)              │
│                                     │
│ Apply the formula:                  │
│   \(v = 0 + (2)(10) = 20\ \text{m/s}\)│
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Answer                              │
│                                     │
│ The car’s velocity after 10 seconds │
│ is \(\boxed{20\ \text{m/s}}\).       │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Summary                             │
│                                     │
│ • Uniform acceleration formula:     │
│   \(v = u + a t\)                    │
│ • Plug‑in the known values           │
│ • Result: \(20\ \text{m/s}\)         │
└─────────────────────────────────────┘
