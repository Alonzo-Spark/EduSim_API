┌───────────────────────────┐
│ Introduction              │
│                           │
│ When a block slides down  │
│ an inclined plane, its     │
│ motion is influenced by    │
│ the angle of the incline,  │
│ the force of gravity, and  │
│ friction. Gravity preset   │
│ scaling refers to the      │
│ adjustment of gravitational │
│ force acting on the block, │
│ which can significantly     │
│ impact its range.          │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ 1. **Inclined Plane**: A  │
│    flat surface tilted at  │
│    an angle to the ground. │
│ 2. **Gravity**: The force  │
│    that pulls objects      │
│    towards the center of   │
│    the Earth.              │
│ 3. **Range**: The horizontal│
│    distance traveled by the │
│    block from the base of  │
│    the incline to where it  │
│    lands.                  │
└───────────────────────────┘

┌───────────────────────────┐
│ Characteristics           │
│                           │
│ - The angle of the incline │
│   affects the component of  │
│   gravitational force acting │
│   along the plane.         │
│ - Increased gravity scaling │
│   results in a greater     │
│   force down the incline.  │
│ - The absence of friction   │
│   simplifies the analysis,  │
│   allowing for theoretical   │
│   calculations.            │
└───────────────────────────┘
