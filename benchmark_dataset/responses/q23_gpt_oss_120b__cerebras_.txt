┌───────────────────────────────────────┐
│               Introduction              │
│                                         │
│ Mass and weight are fundamental concepts│
│ in physics, everyday life, and engineering.│
│ Though often used interchangeably in   │
│ casual conversation, they describe      │
│ distinct physical properties.           │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│                Definition                │
│                                         │
│ • **Mass** – the amount of matter contained│
│   in an object. It is an intrinsic property│
│   that does not change with location.      │
│ • **Weight** – the force exerted on that   │
│   mass by gravity. It depends on both the │
│   object's mass and the local gravitational│
│   acceleration.                             │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│               Key Concepts               │
│                                         │
│ 1. **Scalar vs. Vector**                 │
│    – Mass is a scalar (has magnitude only).│
│    – Weight is a vector (has magnitude   │
│      and direction, toward the planet's │
│      center).                             │
│                                         │
│ 2. **Units**                             │
│    – Mass: kilograms (kg)                │
│    – Weight: newtons (N)                 │
│                                         │
│ 3. **Location Dependence**               │
│    – Mass remains the same on Earth,    │
│      Moon, or in deep space.             │
│    – Weight changes with gravitational   │
│      field strength (e.g., lighter on    │
│      the Moon).                           │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│               Formula Card               │
│                                           │
│                 Weight Formula            │
│                                           │
│            **W = m·g**                     │
│                                           │
│   • *W* – weight (N)                       │
│   • *m* – mass (kg)                        │
│   • *g* – acceleration due to gravity      │
│         (≈9.81 m/s² on Earth)              │
│                                           │

┌───────────────────────────────────────┐
│               Applications               │
│                                           │
│ • Engineering: designing structures that│
│   must support loads (weight)            │
│ • Astronomy: calculating planetary masses│
│   from orbital data (mass)               │
│ • Everyday life: understanding why you  │
│   feel lighter on a high‑altitude hike   │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│               Advantages                 │
│                                           │
│ • Distinguishing mass and weight avoids  │
│   calculation errors in physics problems │
│ • Clarifies why objects behave differently│
│   in varying gravitational fields         │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│               Disadvantages              │
│                                           │
│ • Common misuse in everyday language can │
│   lead to misconceptions (e.g., “heavy │
│   vs. massive”)                           │
│ • Requires careful unit handling when    │
│   converting between mass and weight      │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│               Important Notes            │
│                                           │
│ • Mass is conserved; weight is not.      │
│ • In Einstein’s relativity, mass and     │
│   energy are interchangeable (E = mc²). │
│ • Weight can be zero (e.g., in free space│
│   or at a gravitational null point).     │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│                 Summary                  │
│                                           │
│ • Mass = amount of matter (scalar, kg)   │
│ • Weight = gravitational force (vector, │
│   N) = m·g                                 │
│ • Mass is invariant; weight varies with  │
│   gravity.                                 │
│ • Proper distinction is crucial in       │
│   science, engineering, and daily life.  │
└───────────────────────────────────────┘
