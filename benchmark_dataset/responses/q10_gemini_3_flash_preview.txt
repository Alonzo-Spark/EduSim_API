### 📘 Physics Module: Physical Quantities

┌──────────────────────────────────────────────────────────────────┐
│ **Quick Definition**                                             │
│                                                                  │
│ Physics uses two primary types of quantities to describe the     │
│ physical world based on whether they require direction to be     │
│ fully understood: **Scalars** and **Vectors**.                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Key Concepts: Scalar Quantities**                              │
│                                                                  │
│ A **Scalar** quantity is defined entirely by its **magnitude**   │
│ (size or numerical value) and a unit.                            │
│                                                                  │
│ • **Algebra:** Follows simple arithmetic rules (2kg + 2kg = 4kg).│
│ • **Change:** Changes only when magnitude changes.               │
│ • **Examples:** Mass, Time, Temperature, Energy, Speed, Distance.│
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Key Concepts: Vector Quantities**                              │
│                                                                  │
│ A **Vector** quantity is defined by both **magnitude** and       │
│ **direction**.                                                   │
│                                                                  │
│ • **Representation:** Shown by an arrow ($\vec{A}$).             │
│ • **Algebra:** Requires vector addition (Head-to-Tail rule).     │
│ • **Change:** Changes if magnitude, direction, or both change.   │
│ • **Examples:** Force, Velocity, Acceleration, Momentum, Weight. │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Main Formula: Vector Representation**                          │
│                                                                  │
│ $$\vec{V} = |V| \cdot \hat{u}$$                                  │
│                                                                  │
│ **[ Explain Formula ]**                                          │
│ $\vec{V}$ is the vector, $|V|$ is the magnitude (scalar part),   │
│ and $\hat{u}$ is the unit vector indicating direction.           │
│                                                                  │
│ **[ Open Formula Lab ]**                                         │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Comparative Analysis**                                         │
│                                                                  │
│ | Feature | Scalar Quantity | Vector Quantity |                  │
│ | :--- | :--- | :--- |                                           │
│ | **Requirement** | Magnitude only | Magnitude and Direction |      │
│ | **Dimension** | One-dimensional | Multi-dimensional |           │
│ | **Notation** | Ordinary letter ($m$) | Arrow over letter ($\vec{F}$) |│
│ | **Resultant** | Simple Sum | Vector Sum |                      │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ **Important Notes: The "Direction" Trap**                        │
│                                                                  │
│ Not every quantity with direction is a vector. For example,      │
│ **Electric Current** has direction but is a **Scalar** because   │
│ it does not follow the laws of vector addition (it follows      │
│ Kirchhoff's Junction Law).                                       │
└──────────────────────────────────────────────────────────────────┘
