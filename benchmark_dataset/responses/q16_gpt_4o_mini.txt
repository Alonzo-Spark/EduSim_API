┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Work is defined as the    │
│ measure of energy transfer  │
│ that occurs when an object │
│ is moved over a distance   │
│ by an external force.      │
└───────────────────────────┘

┌───────────────────────────┐
│ SI Unit of Work          │
│                           │
│ The SI unit of work is    │
│ the Joule (J), which is   │
│ defined as the amount of   │
│ energy transferred when    │
│ a force of one newton     │
│ moves an object one meter. │
└───────────────────────────┘
