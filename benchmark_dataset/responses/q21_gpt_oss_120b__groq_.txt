┌─────────────────────────────────────┐
│ Definition                          │
│                                     │
│ Newton’s law of universal gravitation │
│ states that every two point masses   │
│ attract each other with a force that │
│ is directly proportional to the     │
│ product of their masses and inversely│
│ proportional to the square of the   │
│ distance between them.               │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Main Formula                        │
│                                     │
│   F = G \frac{m_{1}\,m_{2}}{r^{2}}   │
│                                     │
│ [ Explain Formula ]                 │
│ [ Open Formula Lab ]                │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Key Concepts                        │
│                                     │
│ • **F** – Gravitational force (vector)│
│ • **G** – Gravitational constant (≈ 6.674×10⁻¹¹ N·m²·kg⁻²)│
│ • **m₁, m₂** – Masses of the two bodies│
│ • **r** – Distance between the centers│
│ • Force is attractive and acts along │
│   the line joining the two masses.   │
└─────────────────────────────────────┘
