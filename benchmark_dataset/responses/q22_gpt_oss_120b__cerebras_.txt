┌───────────────────────────────────────────────────────────────┐
│ Introduction                                                     │
│                                                                   │
│ Acceleration due to gravity (commonly denoted **g**) is the      │
│ rate at which an object’s velocity increases as it falls          │
│ freely under the influence of a massive body such as a planet.   │
│ It is a fundamental constant in classical mechanics and varies   │
│ with the mass of the attracting body and the distance from its    │
│ centre.                                                            │
└───────────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────┐
│ Key Concepts                                                     │
│                                                                   │
│ • **Newton’s Law of Universal Gravitation** –                     │
│   \[F = \frac{G M m}{r^{2}}\]                                    │
│   where \(G\) is the gravitational constant, \(M\) and \(m\)     │
│   are the interacting masses, and \(r\) is the separation between │
│   their centres.                                                 │
│                                                                   │
│ • **Newton’s Second Law** –                                      │
│   \[F = m a\]                                                    │
│                                                                   │
│ • **Acceleration due to gravity** –                              │
│   The acceleration a body experiences when the only force acting │
│   on it is gravity.                                               │
└───────────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────┐
│ Main Formula                                                     │
│                                                                   │
│                \[ g = \frac{G\,M}{r^{2}} \]                      │
│                                                                   │
│ [ Explain Formula ]   [ Open Formula Lab ]                        │
└───────────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────┐
│ Derivation                                                       │
│                                                                   │
│ 1️⃣ Start with Newton’s law of universal gravitation:            │
│                                                                   │
│    ┌───────────────────────────────────────┐                    │
│    │ Formula Card                           │                    │
│    │                                         │                    │
│    │ \[F = \frac{G M m}{r^{2}}\]            │                    │
│    │                                         │                    │
│    │ [ Explain Formula ]   [ Open Formula Lab ] │                    │
│    └───────────────────────────────────────┘                    │
│                                                                   │
│ 2️⃣ Apply Newton’s second law to the same force:                  │
│                                                                   │
│    ┌───────────────────────────────────────┐                    │
│    │ Formula Card                           │                    │
│    │                                         │                    │
│    │ \[F = m a\]                            │                    │
│    │                                         │                    │
│    │ [ Explain Formula ]   [ Open Formula Lab ] │                    │
│    └───────────────────────────────────────┘                    │
│                                                                   │
│ 3️⃣ Equate the two expressions for \(F\):                         │
│                                                                   │
│    \[\frac{G M m}{r^{2}} = m a\]                                 │
│                                                                   │
│ 4️⃣ Cancel the common factor \(m\) (the falling object's mass):  │
│                                                                   │
│    \[\frac{G M}{r^{2}} = a\]                                     │
│                                                                   │
│ 5️⃣ Recognise that the resulting acceleration is the **accel‑   │
│    eration due to gravity**, denoted \(g\):                       │
│                                                                   │
│    \[g = \frac{G M}{r^{2}}\]                                     │
│                                                                   │
│ This is the desired expression.                                   │
└───────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ Applications                                                     │
│                                                                   │
│ • **Projectile motion** – determines the vertical component of   │
│   acceleration.                                                  │
│ • **Orbital mechanics** – appears in the vis‑viva equation for   │
│   satellites.                                                    │
│ • **Engineering** – used to design structures, bridges, and      │
│   vehicles that must withstand gravitational loads.              │
│ • **Geophysics** – variations of \(g\) reveal density anomalies  │
│   inside the Earth.                                               │
└───────────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────┐
│ Summary                                                          │
│                                                                   │
│ The acceleration due to gravity at a distance \(r\) from the     │
│ centre of a mass \(M\) is given by                                            │
│                                                                   │
│    \[ g = \frac{G M}{r^{2}} \]                                    │
│                                                                   │
│ It follows directly from equating Newton’s universal law of      │
│ gravitation with Newton’s second law, cancelling the test mass.   │
│ For Earth, substituting the planetary mass and radius yields the  │
│ familiar \(g \approx 9.81\;\text{m/s}^{2}\).                       │
└───────────────────────────────────────────────────────────────────┘
