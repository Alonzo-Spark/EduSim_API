┌───────────────────────────┐
│ Introduction              │
│                           │
│ Thermal expansion refers  │
│ to the tendency of matter │
│ to change its shape, area,│
│ and volume in response to │
│ a change in temperature.  │
└───────────────────────────┘

┌───────────────────────────┐
│ Definition                │
│                           │
│ Thermal expansion is the  │
│ increase in the size of   │
│ an object when it is      │
│ heated. This occurs due   │
│ to the increase in        │
│ kinetic energy of the     │
│ particles, causing them   │
│ to move apart.           │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ 1. **Linear Expansion:**   │
│    - Change in length     │
│    - Given by the formula  │
│      $$L = L_0(1 + \alpha \Delta T)$$ │
│                           │
│ 2. **Area Expansion:**     │
│    - Change in area       │
│    - Given by the formula  │
│      $$A = A_0(1 + 2\alpha \Delta T)$$ │
│                           │
│ 3. **Volume Expansion:**   │
│    - Change in volume     │
│    - Given by the formula  │
│      $$V = V_0(1 + 3\alpha \Delta T)$$ │
└───────────────────────────┘

┌───────────────────────────┐
│ Characteristics           │
│                           │
│ - Different materials     │
│   expand at different     │
│   rates.                 │
│ - The coefficient of      │
│   linear expansion,       │
│   denoted as $\alpha$,    │
│   is a material-specific   │
│   constant.               │
└───────────────────────────┘

│   engineering and         │
│   construction.           │
└───────────────────────────┘

┌───────────────────────────┐
│ Disadvantages             │

└───────────────────────────┘
