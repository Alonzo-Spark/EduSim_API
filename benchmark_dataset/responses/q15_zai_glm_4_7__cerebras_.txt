┌───────────────────────────────────────────────────────────┐
│ Introduction                                              │
├───────────────────────────────────────────────────────────┤
│                                                           │
│ When a gun is fired, the bullet shoots forward at a high  │
│ speed. Simultaneously, the gun itself experiences a       │
│ sudden backward jerk or "kick." This backward movement    │
│ is known as recoil.                                       │
│                                                           │
│ This phenomenon is not caused by the explosion itself,    │
│ but by the interaction between the gun and the bullet.    │
│                                                           │
└───────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────┐
│ Key Concepts                                              │
├───────────────────────────────────────────────────────────┤
│                                                           │
│ • Action Force: The force exerted by the gun on the       │
│   bullet to propel it forward.                            │
│                                                           │
│ • Reaction Force: The equal and opposite force exerted    │
│   by the bullet back onto the gun.                        │
│                                                           │
│ • System: The gun and the bullet are treated as two       │
│   interacting objects within the same system.             │
│                                                           │
└───────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────┐
│ The Mechanism                                             │
├───────────────────────────────────────────────────────────┤
│                                                           │
│ According to Newton's Third Law of Motion, forces always  │
│ occur in pairs. These two forces are equal in magnitude   │
│ but opposite in direction.                                │
│                                                           │
│ 1. The gun exerts a forward force (Action) on the         │
│    bullet, causing it to accelerate rapidly.              │
│                                                           │
│ 2. In response, the bullet exerts an equal backward       │
│    force (Reaction) on the gun.                           │
│                                                           │
│ 3. Since the gun has a much larger mass than the bullet,  │
│    the same force produces a much smaller acceleration    │
│    on the gun, resulting in the recoil speed being lower  │
│    than the bullet's speed.                               │
│                                                           │
└───────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────┐
│ Summary                                                   │
├───────────────────────────────────────────────────────────┤
│                                                           │
│ The recoil of a gun is a direct consequence of Newton's   │
│ Third Law. The forward force on the bullet creates an     │
│ equal and opposite backward force on the gun. While the   │
│ forces are identical, the resulting accelerations differ  │
│ due to the significant difference in mass between the     │
│ gun and the bullet.                                       │
│                                                           │
