### 📘 Thermodynamics Interactive Textbook

┌──────────────────────────────────────────────────────────────────────────────────┐
│ **Introduction**                                                                 │
│                                                                                  │
│ Thermodynamics is the branch of physics that deals with the relationships        │
│ between heat, work, temperature, and energy. The four laws of thermodynamics     │
│ define how these quantities behave under various conditions.                      │
└──────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────────┐
│ **The Zeroth Law: Thermal Equilibrium**                                          │
│                                                                                  │
│ If two systems are each in thermal equilibrium with a third system, then they    │
│ are in thermal equilibrium with each other.                                      │
│                                                                                  │
│ **Key Concept:** This law defines the concept of **Temperature**. It allows us   │
│ to use thermometers to measure the heat state of different bodies.               │
└──────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────────┐
│ **The First Law: Conservation of Energy**                                        │
│                                                                                  │
│ Energy cannot be created or destroyed, only transformed from one form to         │
│ another. The total energy of an isolated system remains constant.                │
└──────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────────┐
│ **Main Formula: First Law of Thermodynamics**                                    │
│                                                                                  │
│ $$\Delta U = Q - W$$                                                             │
│                                                                                  │
│ [ **Explain Formula** ]                                                          │
│ $\Delta U$: Change in internal energy.                                           │
│ $Q$: Heat added to the system.                                                   │
│ $W$: Work done by the system.                                                    │
│                                                                                  │
│ [ **Open Formula Lab** ]                                                         │
└──────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────────┐
│ **The Second Law: Entropy**                                                      │
│                                                                                  │
│ The total entropy of an isolated system can never decrease over time; it can     │
│ only remain constant or increase.                                                │
│                                                                                  │
│ **Key Characteristics:**                                                         │
│ • Heat naturally flows from hot to cold bodies.                                  │
│ • No process is 100% efficient due to energy dissipation.                        │
│ • It defines the "Arrow of Time."                                                │
└──────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────────┐
│ **The Third Law: Absolute Zero**                                                 │
│                                                                                  │
│ As the temperature of a system approaches absolute zero ($0\text{ K}$), the      │
│ entropy of a perfect crystal approaches a constant minimum (usually zero).       │
│                                                                                  │
│ **Important Note:** It is physically impossible to reach absolute zero in a      │
│ finite number of steps.                                                          │
└──────────────────────────────────────────────────────────────────────────────────┘
