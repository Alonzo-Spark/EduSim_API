┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ Heat can move from a hotter region to a │
│ cooler one in three fundamental ways: │
│ conduction, convection, and radiation.│
│ Understanding each mechanism is key   │
│ for physics, engineering, and everyday │
│ phenomena.                              │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Definition – Conduction                │
│                                       │
│ • Direct transfer of kinetic energy   │
│   between neighboring particles.      │
│ • Occurs most efficiently in solids,   │
│   especially metals.                  │
│ • No bulk movement of the material.   │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Definition – Convection                │
│                                       │
│ • Transfer of heat by the bulk motion │
│   of fluid (liquid or gas).            │
│ • Driven by density differences that │
│   arise from temperature gradients.   │
│ • Common in atmospheres, oceans,      │
│   and heating/cooling systems.        │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Definition – Radiation                │
│                                       │
│ • Emission of electromagnetic waves   │
│   (primarily infrared) from any       │
│   surface with a temperature above      │
│   absolute zero.                      │
│ • Does not require a material medium; │
│   works even through vacuum.          │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Key Concepts                           │
│                                       │
│ • **Medium Requirement**               │
│   – Conduction & convection need a     │
│     material medium; radiation does   │
│     not.                               │
│ • **Transport Mechanism**               │
│   – Conduction: microscopic collisions│
│   – Convection: macroscopic fluid flow │
│   – Radiation: photon emission         │
│ • **Speed of Transfer**                │
│   – Radiation can be extremely fast; │
│     conduction is relatively slow;    │
│     convection speed depends on flow │
│   – Example: Sun’s heat reaches Earth  │
│     via radiation.                     │
└───────────────────────────────────────┘

│ │ Property            │ Conduction    │ Convection    │ │
│ ├─────────────────────┼───────────────┼───────────────┤ │
│ │ Medium needed?      │ Yes (solid)   │ Yes (fluid)   │ │

┌───────────────────────────────────────┐
│ Applications                           │
│                                       │
│ • **Conduction**: cooking pans,        │
│   heat sinks, building insulation.    │
│ • **Convection**: weather patterns,    │
│   radiator heating, ocean currents.   │
│ • **Radiation**: solar heating,       │
│   infrared ovens, thermal imaging.    │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Advantages – Conduction                │
│                                       │
│ • Predictable, steady heat flow.      │
│ • No moving parts → low maintenance. │
│ • Effective in solid structures.      │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Disadvantages – Conduction             │
│                                       │
│ • Limited to materials with high      │
│   thermal conductivity.               │
│ • Slow over large distances.          │
│ • Cannot transfer heat across vacuum. │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Important Notes                        │
│                                       │
│ • Real systems often involve a mix of  │
│   all three mechanisms (e.g., a fireplace).│
│ • Surface emissivity (ε) influences    │
│   radiative heat loss.                │
│ • Fluid properties (viscosity, density)│
│   dictate convection efficiency.      │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Summary                                │
│                                       │
│ • **Conduction**: microscopic particle│
│   collisions, needs a solid medium.   │
│ • **Convection**: bulk fluid motion,  │
│   driven by density differences.      │
│ • **Radiation**: electromagnetic wave│
│   emission, works without a medium.   │
│ Understanding each helps design       │
│ thermal systems and interpret natural │
│ phenomena.                             │
└───────────────────────────────────────┘
