┌───────────────────────────────────────────────┐  
│ **Introduction**                               │  
│                                               │  
│ Momentum is a fundamental concept in          │  
│ physics that describes the quantity of motion │  
│ an object possesses. It connects how mass and  │  
│ velocity combine to produce an effect that     │  
│ influences how objects interact, especially   │  
│ during collisions. Understanding momentum    │  
│ leads directly to one of the most powerful     │  
│ principles in mechanics: the **law of          │  
│ conservation of momentum**.                    │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Definition**                                 │  
│                                               │  
│ *Momentum* (often denoted **p**) is a **vector**│  
│ quantity defined as the product of an object’s │  
│ **mass (m)** and its **velocity (v)**:          │  
│                                               │  
│ ────────────────────────────────────────────── │  
│ │ **Main Formula**                           │  
│ │                                           │  
│ │ $$\mathbf{p}=m\mathbf{v}$$                │  
│ │                                           │  
│ │ [ Explain Formula ]   [ Open Formula Lab ]│  
│ ────────────────────────────────────────────── │  
│                                               │  
│ Because it is a vector, momentum has both      │  
│ magnitude and direction, pointing in the same  │  
│ direction as the velocity.                     │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Key Concepts**                               │  
│                                               │  
│ • **Vector Nature** – Momentum adds vectorially│  
│   (i.e., you must consider direction).        │  
│ • **Dependence on Mass** – Heavier objects have │  
│   more momentum at the same speed.            │  
│ • **Dependence on Velocity** – Doubling speed   │  
│   doubles momentum.                           │  
│ • **Closed System** – When no external forces   │  
│   act on a group of objects, the total          │  
│   momentum of that group remains constant.     │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Derivation of the Law of Conservation of      │  
│ Momentum**                                     │  
│                                               │  
│ 1. **Start with Newton’s Second Law**          │  
│    $$\mathbf{F}= \frac{d\mathbf{p}}{dt}$$      │  
│    (Force is the time‑rate of change of       │  
│    momentum.)                                 │  
│                                               │  
│ 2. **Consider two interacting particles** A   │  
│    and B. The internal forces they exert on   │  
│    each other are equal and opposite          │  
│    (Newton’s Third Law):                      │  
│    $$\mathbf{F}_{AB}= -\mathbf{F}_{BA}$$       │  
│                                               │  
│ 3. **Write the rate of change of total        │  
│    momentum for the two‑particle system:**    │  
│    $$\frac{d\mathbf{p}_\text{total}}{dt}=     │  
│      \frac{d\mathbf{p}_A}{dt}+ \frac{d\mathbf{p}_B}{dt}│  
│      =\mathbf{F}_{BA}+\mathbf{F}_{AB}=0$$      │  
│                                               │  
│ 4. **Integrate over time** (from an initial    │  
│    instant *t₁* to a later instant *t₂*):      │  
│    $$\mathbf{p}_\text{total}(t_2)-\mathbf{p}_\text{total}(t_1)=0$$│  
│    ⇒ $$\mathbf{p}_\text{total}(t_2)=\mathbf{p}_\text{total}(t_1)$$│  
│                                               │  
│ 5. **General Form for *N* particles**:        │  
│    ──────────────────────────────────────── │  
│    │ **Main Formula**                       │  
│    │                                         │  
│    │ $$\sum_{i=1}^{N} \mathbf{p}_i = \text{constant}$$│  
│    │                                         │  
│    │ [ Explain Formula ]   [ Open Formula Lab ]│  
│    ──────────────────────────────────────── │  
│                                               │  
│ This statement—*the total momentum of an      │  
│ isolated system remains unchanged*—is the      │  
│ **Law of Conservation of Momentum**.           │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Applications**                               │  
│                                               │  
│ • **Collisions** – Predict post‑collision speeds│  
│   in elastic and inelastic collisions.       │  
│ • **Rocket Propulsion** – Momentum carried away │  
│   by exhaust gases propels the rocket forward.│  
│ • **Particle Physics** – Analyzing scattering │  
│   events in accelerators.                     │  
│ • **Astronomy** – Orbital dynamics of planets   │  
│   and binary star systems.                    │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Important Notes**                            │  
│                                               │  
│ • Momentum is **conserved only** when the net  │  
│   external force on the system is zero.       │  
│ • In non‑inertial (accelerating) reference    │  
│   frames, apparent forces must be included.   │  
│ • For relativistic speeds, the definition      │  
│   modifies to $$\mathbf{p}= \gamma m\mathbf{v}$$│  
│   where $$\gamma = \frac{1}{\sqrt{1-v^2/c^2}}$$.│  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ **Summary**                                    │  
│                                               │  
│ • Momentum (**p = m v**) is a vector quantity.│  
│ • Newton’s second law links force to the       │  
│   change in momentum.                          │  
│ • Internal forces cancel pairwise, leading to  │  
│   a constant total momentum for an isolated    │  
│   system – the **conservation law**.           │  
│ • This principle underpins analysis of         │  
│   collisions, rockets, and many other physical │  
│   phenomena.                                   │  
└───────────────────────────────────────────────┘
