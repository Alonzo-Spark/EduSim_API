┌─────────────────────────────────────┐
│ Introduction                        │
│                                     │
│ Waves are disturbances that transfer │
│ energy through a medium (or vacuum).│
│ Understanding the two primary      │
│ classifications—transverse and      │
│ longitudinal—helps explain many     │
│ physical phenomena, from light to  │
│ sound.                               │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Definition                          │
│                                     │
│ **Transverse Wave**: The particle   │
│ displacement is perpendicular to the│
│ direction of wave propagation.      │
│                                     │
│ **Longitudinal Wave**: The particle│
│ displacement is parallel to the      │
│ direction of wave propagation.      │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Key Concepts                        │
│                                     │
│ • **Particle Motion** – describes how│
│   the medium’s particles move relative│
│   to the wave’s travel direction.     │
│ • **Propagation Direction** – the    │
│   path the wave energy follows.       │
│ • **Restoring Forces** – determine   │
│   whether the disturbance is         │
│   transverse or longitudinal.        │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Characteristics                     │
│                                     │
│ | Property                | Transverse | Longitudinal | │
│ |--------------------------|------------|--------------│ │
│ | Particle displacement    | ⟂ to travel| ∥ to travel │ │
│ | Typical examples         | Light,     | Sound,       │ │
│ |                          | seismic S‑waves │ seismic P‑waves │ │
│ | Medium requirement       | Any (including vacuum)│ Requires a material │ │
│ | Speed relation           | Depends on shear modulus │ Depends on bulk modulus │ │
│ | Polarization possible    | Yes (directional) │ No (single direction) │ │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Applications                        │
│                                     │
│ • **Transverse Waves** – optics (light│
│   waves), electromagnetic radiation,│
│   surface water waves, seismic S‑   │
│   waves.                             │
│ • **Longitudinal Waves** – acoustic │
│   waves (sound), seismic P‑waves,   │
│   ultrasound imaging.               │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Summary                             │
│                                     │
│ - Transverse: particle motion ⟂    │
│   to travel direction; can propagate│
│   in vacuum; exhibits polarization.│
│ - Longitudinal: particle motion ∥   │
│   to travel direction; needs a     │
│   material medium; no polarization.│
│ Understanding both types is crucial │
│ for physics, engineering, and       │
│ everyday technology.                │
└─────────────────────────────────────┘
