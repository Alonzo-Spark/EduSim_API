Let's explore why astronauts feel weightless in space!

┌───────────────────────────┐
│ Introduction              │
│                           │
│ Astronauts in orbit appear│
│ to float, experiencing   │
│ weightlessness. But why?  │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ *   **Gravity:** The force│
│     that pulls objects    │
│     towards each other.   │
│ *   **Freefall:** The     │
│     state of falling     │
│     under gravity's       │
│     influence.            │
│ *   **Orbit:** A          │
│     continuous freefall   │
│     around a celestial    │
│     body.                 │
└───────────────────────────┘

┌───────────────────────────┐
│ The Illusion of Weightlessness │
│                           │
│ Astronauts are in a state│
│ of continuous freefall    │
│ around the Earth.  They   │
│ are constantly falling    │
│ towards Earth, but they   │
│ also have a sideways      │
│ velocity that prevents    │
│ them from colliding with  │
│ the Earth.                │
└───────────────────────────┘

┌───────────────────────────┐
│ The Role of Gravity       │
│                           │
│ Gravity is still acting   │
│ on the astronaut and the  │
│ spacecraft. The          │
│ weightlessness is not     │
│ caused by a lack of       │
│ gravity, but rather a     │
│ constant state of freefall.│
└───────────────────────────┘

┌───────────────────────────┐
│ Formula: Orbital Velocity │
│                           │
│ The orbital velocity      │
│ required to maintain an   │
│ orbit around a celestial  │
│ body like Earth can be    │
│ calculated using the      │
│ following formula:        │
│                           │
│     Rendered Formula      │
│                           │
│ $$v = \sqrt{\frac{GM}{r}}$$
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

┌───────────────────────────┐
│ Formula Explanation       │
│                           │
│ The formula for orbital   │
│ velocity,  v,  is derived│
│ from the balance between │
│ the gravitational force   │
│ and the centripetal       │
│ acceleration.  Where:     │
│                           │
│ *   G is the gravitational│
│     constant.             │
│ *   M is the mass of the  │
│     Earth.                │
│ *   r is the distance     │
│     from the center of    │
│     the Earth.            │
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes           │
│                           │
│ *   Weightlessness is not │
│     the absence of        │
│     gravity.              │
│ *   It's the sensation of│
│     being in freefall.    │
│ *   Astronauts and the    │
│     spacecraft are       │
│     falling at the same   │
│     rate.                 │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                   │
│                           │
│ Astronauts experience     │
│ weightlessness because    │
│ they are in a state of   │
│ continuous freefall while │
│ orbiting Earth.  Gravity  │
│ is still present, but the│
│ balance of forces creates│
│ the sensation of          │
│ weightlessness.           │
└───────────────────────────┘
