┌─────────────────────────────────────┐
│ Pressure (Definition)               │
│                                     │
│ Pressure is the normal force that   │
│ is exerted uniformly over a surface  │
│ per unit area. It describes how much │
│ force is applied to each square      │
│ meter (or any area) of the material.│
│                                     │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ Pressure Formula                    │
│                                     │
│   P = \frac{F}{A}                   │
│                                     │
│ [ Explain Formula ]                 │
│ [ Open Formula Lab ]                │
└─────────────────────────────────────┘


┌─────────────────────────────────────┐
│ SI Unit of Pressure                  │
│                                     │
│ Pascal (Pa) = N·m⁻²                 │
│                                     │
│ 1 Pa = 1 newton acting on a          │
│ one‑square‑metre area.               │
│                                     │
└─────────────────────────────────────┘
