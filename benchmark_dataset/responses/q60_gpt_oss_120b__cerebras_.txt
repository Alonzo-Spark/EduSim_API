┌───────────────────────────────────────┐
│ 🌌  Event Overview                     │
│                                       │
│ **Event**: `gravity_changed`          │
│ **Target State**: Zero‑g (g = 0 m/s²) │
│ **Trigger**: Runtime change in the   │
│ sandbox physics engine.               │
│                                       │
│ **What Happens**:                     │
│ • All objects lose the constant        │
│   downward acceleration.              │
│ • Existing velocities are preserved, │
│   so objects continue with their      │
│   current momentum (inertia).          │
│ • Collision response switches to     │
│   elastic‑only unless otherwise       │
│   specified.                           │
│ • UI overlay appears to inform the    │
│   player of the new gravity state.    │
└───────────────────────────────────────┘


┌───────────────────────────────────────┐
│ 📐  Main Formula                        │
│                                         │
│           F = m·g                       │
│                                         │
│ **Explanation**                        │
│ • *F* – Force acting on an object.      │
│ • *m* – Mass of the object.             │
│ • *g* – Gravitational acceleration.     │
│   In zero‑g, **g = 0**, so **F = 0**.   │
│                                         │

│ ```csharp                               │
