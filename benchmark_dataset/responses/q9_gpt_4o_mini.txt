┌───────────────────────────┐
│ Introduction              │
│                           │
│ Uniform circular motion   │
│ refers to the motion of an│
│ object moving in a circle  │
│ at a constant speed. This  │
│ means that while the speed  │
│ remains constant, the      │
│ direction of the object's   │
│ velocity changes continuously.│
└───────────────────────────┘

┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Centripetal acceleration  │
│ is the acceleration that   │
│ acts on an object moving   │
│ in a circular path,       │
│ directed towards the center│
│ of the circle.            │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ 1. **Velocity**: In uniform│
│    circular motion, while  │
│    the speed is constant,  │
│    the velocity is not due │
│    to the change in        │
│    direction.             │
│ 2. **Acceleration**: Even  │
│    at a constant speed,    │
│    there is a centripetal  │
│    acceleration towards the │
│    center of the circular   │
│    path.                  │
└───────────────────────────┘

┌───────────────────────────┐
│ Characteristics           │
│                           │
│ - The path of motion is a  │
│   perfect circle.          │
│ - The radius of the circle  │
│   remains constant.        │
│ - The object experiences    │
│   constant acceleration,    │
│   directed towards the center.│
└───────────────────────────┘

┌───────────────────────────┐
│ Main Formula              │
│                           │
│ The formula for centripetal│
│ acceleration \( a_c \) is: │
│                           │
│ $$ a_c = \frac{v^2}{r} $$ │
│                           │
│ Where:                    │
│ - \( v \) = linear speed  │
│ - \( r \) = radius of the │
│   circular path           │
│                           │
│ [ Explain Formula ]       │
│ [ Open Formula Lab ]      │
└───────────────────────────┘

┌───────────────────────────┐
│ Applications              │
│                           │
│ - Satellites in orbit     │
│ - Cars turning on a road  │
│ - Cyclists on a track     │
│ - Planets orbiting the sun │
└───────────────────────────┘

┌───────────────────────────┐
│ Advantages                │
│                           │
│ - Predictable motion      │
│ - Useful for calculating   │
│   forces in various fields │
│   such as astrophysics and │
│   engineering             │
└───────────────────────────┘

┌───────────────────────────┐
│ Disadvantages             │
│                           │
│ - Requires constant speed  │
│ - Does not account for     │
│   external forces like     │
│   friction or air resistance│
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes           │
│                           │
│ - Uniform circular motion  │
│   cannot occur in the presence│
│   of unbalanced forces.    │
│ - Centripetal force is not  │
│   a separate force but a    │
│   net force resulting from   │
│   other forces acting on the │
│   object.                  │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                   │
│                           │
│ Uniform circular motion is  │
│ the motion of an object in  │
│ a circular path at a constant│
│ speed, accompanied by centripetal│
│ acceleration directed towards │
│ the center of the circle.    │
└───────────────────────────┘
