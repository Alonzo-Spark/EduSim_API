┌───────────────────────────────┐
│          Introduction           │
│────────────────────────────────│
│ When a metal rod is heated, its   │
│ atoms vibrate more vigorously,   │
│ causing the average distance      │
│ between them to increase.  The   │
│ result is a measurable lengthening│
│ of the rod – this phenomenon is   │
│ known as **thermal expansion**.   │
└───────────────────────────────────┘


┌───────────────────────────────┐
│            Definition           │
│────────────────────────────────│
│ **Thermal expansion** is the     │
│ tendency of matter to change its │
│ shape, area, and volume in response│
│ to a change in temperature.      │
│ For solids, the most common       │
│ expression is the change in length│
│ of a straight rod.                │
└───────────────────────────────────┘


┌───────────────────────────────┐
│          Key Concepts           │
│────────────────────────────────│
│ • **Coefficient of linear       │
│   expansion (α)** – material‑specific │
│   constant (°C⁻¹) that quantifies   │
│   how much a unit length changes   │
│   per degree temperature change.   │
│ • **ΔT** – temperature change (°C)   │
│ • **L₀** – original length of the rod │
│ • **ΔL** – change in length after   │
│   heating.                         │
│ • **Uniform heating** – assumption │
│   that temperature is the same      │
│   throughout the rod.               │
└───────────────────────────────────┘


┌───────────────────────────────┐
│        Characteristics          │
│────────────────────────────────│
│ • Linear for small temperature   │
│   ranges; becomes non‑linear at  │
│   very high ΔT.                  │
│ • Isotropic materials expand     │
│   equally in all directions; for│
│   anisotropic crystals, expansion│
│   varies with crystal orientation.│
│ • Constrained expansion generates│
│   thermal stress.                │
└───────────────────────────────────┘


┌───────────────────────────────┐
│            Formula               │
│────────────────────────────────│
│ ┌─────────────────────────────┐ │
│ │  Main Formula                │ │
│ │                             │ │
│ │  ΔL = α L₀ ΔT               │ │
│ │                             │ │
│ │  [ Explain Formula ]        │ │
│ │  [ Open Formula Lab ]       │ │
│ └─────────────────────────────┘ │
│                                 │
│ *Where:*                         │
│ • ΔL – change in length (m)      │
│ • α – coefficient of linear      │
│   expansion (°C⁻¹)               │
│ • L₀ – original length (m)       │
│ • ΔT – temperature change (°C)   │
└───────────────────────────────────┘


┌───────────────────────────────┐
│        Applications             │
│────────────────────────────────│
│ • **Railway tracks** – expansion joints│
│   prevent buckling.                  │
│ • **Bridges** – expansion bearings   │
│   accommodate length changes.        │
│ • **Bimetallic strips** – used in   │
│   thermostats; differing α causes   │
│   bending.                           │
│ • **Precision instruments** – design│
│   tolerances to minimise thermal drift.│
└───────────────────────────────────┘


┌───────────────────────────────┐
│          Advantages             │
│────────────────────────────────│
│ • Predictable dimensional change,   │
│   enabling engineered clearances.   │
│ • Enables temperature‑sensitive    │
│   devices (e.g., bimetallic sensors).│
│ • Simple linear model for most       │
│   engineering calculations.         │
└───────────────────────────────────┘


┌───────────────────────────────┐
│          Disadvantages          │
│────────────────────────────────│
│ • If not accounted for, thermal      │
│   expansion can cause buckling,      │
│   cracks, or loss of alignment.      │
│ • Requires expansion joints, which   │
│   add cost and maintenance.          │
│ • Material‑specific α may vary with │
│   temperature, introducing uncertainty│
└───────────────────────────────────┘


┌───────────────────────────────┐
│        Important Notes          │
│────────────────────────────────│
│ • **Uniform heating** is essential for │
│   the linear formula to hold.           │
│ • Constrained rods develop **thermal   │
│   stress**: σ = α E ΔT (E = Young’s modulus).│
│ • For large ΔT, use the integrated form:│
│   L = L₀ e^{αΔT}.                        │
│ • Volumetric expansion (ΔV) ≈ 3α V₀ ΔT │
│   for isotropic solids.                 │
└───────────────────────────────────┘


┌───────────────────────────────┐
│          Summary                │
│────────────────────────────────│
│ • Heating a metal rod causes its   │
│   length to increase proportionally│
│   to the temperature rise.         │
│ • The linear relationship is       │
│   ΔL = α L₀ ΔT, where α is a material│
│   constant.                        │
│ • Engineers design expansion joints│
│   and bearings to manage this change│
│   in structures and devices.       │
└───────────────────────────────────┘
