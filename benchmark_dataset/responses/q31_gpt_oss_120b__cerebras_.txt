│ Quick Definition – Heat Capacity                │  
│                                                   │  
│ **Heat capacity (C)** is the amount of heat       │  
│ energy that must be added to a body to raise its │  
│ temperature by **one kelvin (or one °C)**.       │  
│ It depends on the material, its mass, and its   │  
│ shape, because all of these affect how the       │  
│ system stores thermal energy.                     │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Quick Definition – Specific Heat Capacity       │  
│                                                   │  
│ **Specific heat capacity (c)** is the heat       │  
│ required to raise the temperature of **one       │  
│ kilogram** of a substance by **one kelvin**.    │  
│ It is an intrinsic property of the material;    │  
│ unlike C, it does **not** depend on the amount   │  
│ of material present.                              │  
└───────────────────────────────────────────────┘  

┌───────────────────────────────────────────────┐  
│ Main Formula                                      │  
│                                                   │  
│ $$\displaystyle Q = C\,\Delta T$$                 │  
│ $$\displaystyle Q = m\,c\,\Delta T$$              │  
│                                                   │

┌───────────────────────────────────────────────┐  
│ Key Concepts                                      │  
│                                                   │  
│ • **Heat (Q)** – energy transferred due to a      │  
│   temperature difference.                        │  
│ • **ΔT** – change in temperature (final – initial).│  
│ • **m** – mass of the substance.                  │  
│ • **C = m c** – relationship between total heat   │  
│   capacity and specific heat capacity.            │  
│                                                   │  
│ Understanding these links lets you calculate the │  
│ heat needed for any temperature change, whether   │  
│ you work with the whole object (C) or per unit    │  
│ mass (c).                                          │
