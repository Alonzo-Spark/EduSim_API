┌───────────────────────────────────────────────────────────────────────────────┐
│ **Introduction**                                                               │
│                                                                               │
│ In physics, *potential energy* is the energy that an object possesses due to │
│ its position in a force field, such as gravity. When an object is raised to   │
│ a higher altitude, it stores gravitational potential energy that can be      │
│ converted into kinetic energy when it falls.                                  │
└───────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────┐
│ **Definition**                                                                 │
│                                                                               │
│ The gravitational potential energy (PE) of a mass *m* at height *h* above    │
│ the reference level is given by the product of its mass, the gravitational  │
│ acceleration, and the height:                                               │
│                                                                               │
│ \[
│ PE = m g h
│ \]                                                                            │
│                                                                               │
│ where:                                                                        │
│ • *m* – mass (kg)                                                            │
│ • *g* – acceleration due to gravity (≈ 9.81 m s⁻² on Earth)                  │
│ • *h* – height above the reference point (m)                                 │
└───────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────┐
│ **Main Formula**                                                               │
│                                                                               │
│     \[
│     PE = m g h
│     \]                                                                        │
│                                                                               │
│ [ Explain Formula ]  [ Open Formula Lab ]                                     │
└───────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────┐
│ **Calculation**                                                                │
│                                                                               │
│ • Mass, *m* = 5 kg                                                            │
│ • Height, *h* = 10 m                                                          │
│ • Gravitational acceleration, *g* ≈ 9.81 m s⁻²                                 │
│                                                                               │
│ Plugging into the formula:                                                   │
│                                                                               │
│ \[
│ PE = (5 \text{kg})(9.81 \text{m/s}^2)(10 \text{m}) = 490.5 \text{J}
│ \]                                                                            │
│                                                                               │
│ Thus the body possesses **≈ 490 J** of gravitational potential energy.         │
└───────────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────────┐
│ **Summary**                                                                    │
│                                                                               │
│ A 5 kg mass lifted to 10 m gains about 490 J of gravitational potential energy │
│ (using *g* = 9.81 m s⁻²). This energy can be released as kinetic energy if   │
│ the mass is allowed to fall.                                                 │
└───────────────────────────────────────────────────────────────────────────────┘
