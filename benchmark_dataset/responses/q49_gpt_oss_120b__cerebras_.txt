┌───────────────────────────────┐
│ 📘 Problem Statement            │
│                                 │
│ A current of **2 A** flows through │
│ a resistor of **10 Ω**. Find the │
│ voltage across the resistor.    │
└───────────────────────────────┘

┌───────────────────────────────┐
│ 🧭 Key Concepts                 │
│                                 │
│ • **Current (I)** – flow of electric │
│   charge, measured in amperes (A).   │
│ • **Resistance (R)** – opposition to │
│   current, measured in ohms (Ω).      │
│ • **Voltage (V)** – electric potential │
│   difference, measured in volts (V). │
│ • **Ohm’s Law** – fundamental relation │
│   linking the three quantities.       │
└───────────────────────────────┘

┌───────────────────────────────┐
│ 📐 Formula Card – Ohm’s Law    │
│                                 │
│          **V = I · R**           │
│                                 │
│ [ Explain Formula ]             │
│   • V – voltage (V)             │
│   • I – current (A)             │
│   • R – resistance (Ω)          │
│                                 │
│ [ Open Formula Lab ]            │
│   Interactive sandbox to       │
│   experiment with I, R, V.      │
└───────────────────────────────┘

┌───────────────────────────────┐
│ 🧮 Solution Steps                │
│                                 │
│ 1. Identify given values:       │
│    • I = 2 A                    │
│    • R = 10 Ω                  │
│                                 │
│ 2. Apply Ohm’s Law:             │
│    V = I · R                    │
│                                 │
│ 3. Substitute:                  │
│    V = (2 A) · (10 Ω)           │
│                                 │
│ 4. Compute:                     │
│    V = 20 V                    │
└───────────────────────────────┘

┌───────────────────────────────┐
│ ✅ Answer                       │
│                                 │
│ The voltage across the resistor │
│ is **20 volts (V)**.             │
└───────────────────────────────┘

┌───────────────────────────────┐
│ 📚 Summary                      │
│                                 │
│ • Ohm’s Law (V = I R) relates   │
│   voltage, current, and resistance. │
│ • Plugging I = 2 A and R = 10 Ω  │
│   yields V = 20 V.               │
│ • This principle is foundational │
│   for analyzing electric circuits. │
└───────────────────────────────┘
