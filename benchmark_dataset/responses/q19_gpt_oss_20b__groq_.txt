┌───────────────────────────────┐
│ Introduction                   │
│                               │
│ Kinetic energy is a central    │
│ concept in physics that      │
│ quantifies the energy an      │
│ object possesses solely due   │
│ to its motion. It is a scalar │
│ quantity and plays a key role │
│ in the conservation of energy │
│ in isolated systems.          │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Definition                     │
│                               │
│ The kinetic energy (KE) of a   │
│ particle with mass *m* moving │
│ at speed *v* is:               │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Main Formula                   │
│                               │
│          KE = ½ m v²           │
│                               │
│ [ Explain Formula ] [ Open Formula Lab ]│
└───────────────────────────────┘

┌───────────────────────────────┐
│ Key Concepts                   │
│                               │
│ • Scalar quantity (no direction)│
│ • Depends only on speed, not   │
│   direction                     │
│ • Additive for systems         │
│ • Conserved in closed systems  │
│   if no non‑conservative work  │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Characteristics                │
│                               │
│ • Independent of reference    │
│   frame (classical regime)    │
│ • Quadratic in velocity       │
│ • Zero when the object is at │
│   rest (v = 0)                 │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Derivation                     │
│                               │
│ Starting from the work‑energy │
│ theorem: dW = F·dx = m a dx.   │
│ Using a = dv/dt and dx = v dt, │
│ we get dW = m v dv. Integrating │
│ from 0 to v:                   │
│ W = ∫₀ᵛ m v dv = ½ m v².        │
│ Thus the kinetic energy gained │
│ equals the work done on the    │
│ particle.                       │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Applications                   │
│                               │
│ • Mechanics: predicting motion│
│   of projectiles and vehicles │
│ • Engineering: design of     │
│   vehicles, machinery, and   │
│   safety systems              │
│ • Astrophysics: orbital       │
│   dynamics                    │
│ • Sports science: performance │
│   analysis                    │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Advantages                     │
│                               │
│ • Simple, intuitive formula   │
│ • Scalar, easy to compute     │
│ • Directly linked to work     │
│   and energy conservation     │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Disadvantages                  │
│                               │
│ • Non‑relativistic: fails for │
│   speeds close to *c*          │
│ • Ignores internal or thermal │
│   energy unless extended      │
│   to include rotational KE    │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Important Notes                │
│                               │
│ • Formula holds in classical │
│   mechanics (Newtonian)       │
│ • Depends on chosen reference │
│   frame; kinetic energy is    │
│   not invariant under Lorentz │
│   transformations             │
│ • For rotating bodies, use   │
│   KE_rot = ½ I ω²              │
└───────────────────────────────┘

┌───────────────────────────────┐
│ Summary                        │
│                               │
│ Kinetic energy quantifies the │
│ energy of motion: KE = ½ m v².│
│ It is derived from the work‑ │
│ energy principle and is a     │
│ fundamental, scalar property │
│ of moving objects.            │
└───────────────────────────────┘
