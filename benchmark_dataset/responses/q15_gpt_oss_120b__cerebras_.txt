┌───────────────────────────────────────────────────────┐
│ Introduction                                            │
│                                                       │
│ When a firearm discharges, the barrel and the bullet │
│ move in opposite directions. This phenomenon is      │
│ commonly called **recoil**. Understanding it helps    │
│ engineers design safer weapons and shooters to manage│
│ the kick‑back they feel.                               │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Definition                                             │
│                                                       │
│ **Newton’s Third Law** – *For every action force there │
│ is an equal and opposite reaction force.*            │
│                                                       │
│ In the context of a gun, the “action” is the force   │
│ that accelerates the bullet forward; the “reaction”  │
│ is the force that pushes the gun backward.            │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Key Concepts                                           │
│                                                       │
│ • **Action‑Reaction Pair** – The bullet experiences a │
│   forward force; the gun experiences an equal backward│
│   force.                                               │
│                                                       │
│ • **Momentum Conservation** – Because the system (gun │
│   + bullet) is isolated, its total linear momentum stays│
│   constant:                                            │
│   \[ \mathbf{p}_{\text{initial}} = \mathbf{p}_{\text{final}} \] │
│                                                       │
│ • **Mass Difference** – The gun’s mass is much larger │
│   than the bullet’s, so the recoil speed is much      │
│   smaller than the bullet’s speed.                     │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Main Formula                                            │
│                                                       │
│   \[ m_{\text{b}}\,v_{\text{b}} = m_{\text{g}}\,v_{\text{g}} \] │
│                                                       │
│   *Where*                                               │
│   • \(m_{\text{b}}\) – mass of the bullet               │
│   • \(v_{\text{b}}\) – velocity of the bullet (forward)│
│   • \(m_{\text{g}}\) – mass of the gun (including      │
│     carriage)                                           │
│   • \(v_{\text{g}}\) – recoil velocity of the gun      │
│     (backward, opposite sign)                          │
│                                                       │

└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Applications                                            │
│                                                       │
│ • **Firearm Design** – Engineers calculate recoil to   │
│   add dampening mechanisms (e.g., recoil springs).   │
│                                                       │
│ • **Sport Shooting** – Shooters adjust stance to      │
│   counteract the expected backward motion.             │
│                                                       │
│ • **Ballistics Forensics** – Recoil analysis helps     │
│   reconstruct shooting events.                         │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Important Notes                                         │
│                                                       │
│ • The forces are simultaneous; they do not “cause”    │
│   each other in a time‑lagged sense.                  │
│                                                       │
│ • Direction matters: the gun’s recoil is opposite the│
│   bullet’s motion.                                     │
│                                                       │
│ • Air resistance on the bullet is negligible during   │
│   the very short time the force acts.                 │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Summary                                                │
│                                                       │
│ • Newton’s third law guarantees an equal opposite     │
│   force on the gun when the bullet is propelled.      │
│ • Momentum conservation gives the quantitative relation│
│   \(m_{\text{b}}v_{\text{b}} = m_{\text{g}}v_{\text{g}}\).│
│ • Because \(m_{\text{g}} \gg m_{\text{b}}\), the gun’s │
│   recoil speed is much smaller than the bullet’s speed│
│   – the basis for recoil‑mitigation design.           │
└───────────────────────────────────────────────────────┘
