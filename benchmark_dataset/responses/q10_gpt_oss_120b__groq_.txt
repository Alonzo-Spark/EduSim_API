┌───────────────────────────────────────────────┐
│ Introduction                                    │
│                                               │
│ In physics and engineering, quantities are   │
│ classified by how they are described.  Some   │
│ have only magnitude, while others also carry   │
│ direction.  Understanding the difference      │
│ between **scalar** and **vector** quantities   │
│ is fundamental for solving problems in        │
│ mechanics, electromagnetism, thermodynamics,  │
│ and many other fields.                         │
└─────────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│ Definition                                     │
│                                               │
│ **Scalar Quantity**                           │
│ – Described by a single number (magnitude)   │
│ – No direction associated                     │
│ – Units are the same as the physical quantity │
│                                               │
│ **Vector Quantity**                           │
│ – Described by both magnitude and direction   │
│ – Represented by an arrow or a set of         │
│   components (e.g., (x, y, z))                │
│ – Units are the same as the physical quantity │
└─────────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│ Key Concepts                                   │
│                                               │
│ • **Magnitude** – Size of the quantity; for   │
│   vectors it is the length of the arrow.      │
│ • **Direction** – Only vectors have this; it  │
│   points from the tail to the head of the     │
│   arrow.                                      │
│ • **Addition** – Scalars add algebraically;   │
│   vectors add tip‑to‑tail (or component‑wise).│
│ • **Multiplication** – Scalars multiply by     │
│   numbers directly; vectors can be multiplied │
│   by scalars (scaling) or by other vectors     │
│   (dot product, cross product).               │
└─────────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│ Examples                                       │
│                                               │
│ **Scalar Examples**                           │
│   – Temperature (°C, K)                       │
│   – Mass (kg)                                 │
│   – Speed (m s⁻¹) – magnitude of velocity      │
│   – Energy (J)                                │
│                                               │
│ **Vector Examples**                           │
│   – Displacement (m, with direction)          │
│   – Velocity (m s⁻¹, with direction)           │
│   – Acceleration (m s⁻², with direction)       │
│   – Force (N, with direction)                 │
│   – Electric field (N C⁻¹, with direction)    │
└─────────────────────────────────────────────────┘

└─────────────────────────────────────────────────┘


┌───────────────────────────────────────────────┐
│ Summary                                        │
│                                               │
│ • Scalars have only magnitude; vectors have   │
│   both magnitude and direction.               │
│ • Scalars are added/subtracted algebraically;│
│   vectors require direction‑aware methods.    │
│ • Real‑world problems often start with scalar  │
│   quantities and become vectors when direction │
│   matters (e.g., speed → velocity).            │
└─────────────────────────────────────────────────┘
