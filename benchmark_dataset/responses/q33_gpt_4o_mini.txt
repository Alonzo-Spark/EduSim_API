┌───────────────────────────┐
│ Introduction              │
│                           │
│ Heat transfer occurs in   │
│ three main ways:         │
│ conduction, convection,   │
│ and radiation. Each has   │
│ unique mechanisms and     │
│ applications.            │
└───────────────────────────┘

┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ **Conduction** is the     │
│ transfer of heat through   │
│ direct contact between     │
│ materials.                │
│                           │
│ **Convection** is the      │
│ transfer of heat by the    │
│ movement of fluids (liquids │
│ and gases).               │
│                           │
│ **Radiation** is the       │
│ transfer of heat in the    │
│ form of electromagnetic     │
│ waves, which can occur in  │
│ a vacuum.                 │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ - **Conduction**: Involves │
│   direct contact; heat     │
│   flows from hot to cold   │
│   areas. Common in solids. │
│                           │
│ - **Convection**: Involves  │
│   the movement of fluids;   │
│   hot fluid rises, cold     │
│   fluid sinks, creating a   │
│   circulation pattern.      │
│                           │
│ - **Radiation**: Can      │
│   occur through empty space │
│   and does not require a    │
│   medium. Examples include   │
│   heat from the sun.        │
└───────────────────────────┘

┌───────────────────────────┐
│ Characteristics           │
│                           │
│ - **Conduction**:         │
│   - Occurs in solids      │
│   - Depends on material   │
│   - Faster in metals      │
│                           │
│ - **Convection**:         │
│   - Occurs in fluids      │
│   - Depends on fluid flow  │
│   - Involves bulk motion   │
│                           │
│ - **Radiation**:          │
│   - Can occur in vacuum    │
│   - Depends on temperature  │
│   - Emission of thermal     │
│     energy                  │
└───────────────────────────┘

┌───────────────────────────┐
│ Applications              │
│                           │
│ - **Conduction**: Used in  │
│   heat sinks and cooking    │
│   utensils.                 │
│                           │
│ - **Convection**: Found in  │
│   heating systems and       │
│   ocean currents.           │
│                           │
│ - **Radiation**: Used in    │
│   solar panels and thermal  │
│   insulation.               │
└───────────────────────────┘

┌───────────────────────────┐
│ Advantages                │
│                           │
│ - **Conduction**: Simple   │
│   and direct heat transfer. │
│                           │
│ - **Convection**: Efficient │
│   for heating large areas.  │
│                           │
│ - **Radiation**: Can transfer │
│   heat across distances without │
│   any medium.               │
└───────────────────────────┘

┌───────────────────────────┐
│ Disadvantages             │
│                           │
│ - **Conduction**: Limited  │
│   to solids; slower than    │
│   other methods.            │
│                           │
│ - **Convection**: Can be    │
│   inefficient in small or   │
│   stagnant fluids.          │
│                           │
│ - **Radiation**: Requires    │
│   a temperature difference;   │
│   can cause heat loss.      │
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes           │
│                           │
│ - All three methods can    │
│   occur simultaneously.     │
│ - The effectiveness of each  │
│   method depends on the     │
│   materials involved and the │
│   environment.              │
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                   │
│                           │
│ Heat transfer occurs via   │
│ conduction (direct contact), │
│ convection (fluid movement), │
│ and radiation (electromagnetic │
│ waves). Each method has its  │
│ own characteristics, applications, │
│ advantages, and disadvantages.  │
└───────────────────────────┘
