┌───────────────────────────┐
│ Quick Definition          │
│                           │
│ Resonance is the phenomenon │
│ where a system vibrates with │
│ greater amplitude at certain  │
│ frequencies, known as the     │
│ system's natural frequencies. │
└───────────────────────────┘

┌───────────────────────────┐
│ Key Concepts              │
│                           │
│ - **Natural Frequency**:   │
│   The frequency at which a  │
│   system tends to oscillate  │
│   in the absence of any      │
│   driving force.             │
│ - **Driving Frequency**:    │
│   The frequency of an external│
│   force applied to the system.│
│ - **Amplitude**:            │
│   The maximum extent of         │
│   vibration or displacement.     │
└───────────────────────────┘

┌───────────────────────────┐
│ Characteristics          │
│                           │
│ - Increased amplitude at   │
│   specific frequencies.     │
│ - Can lead to destructive  │
│   interference if not controlled.│
│ - Common in various systems,│
│   including mechanical,     │
│   electrical, and acoustic. │
└───────────────────────────┘

┌───────────────────────────┐
│ Examples                 │
│                           │
│ 1. **Swinging**: A child  │
│    on a swing can be pushed│
│    at the right intervals,  │
│    causing the swing to go │
│    higher with each push.   │
│ 2. **Bridges**: The Tacoma │
│    Narrows Bridge famously  │
│    collapsed due to resonance│
│    when wind matched the    │
│    bridge's natural frequency.│
│ 3. **Musical Instruments**:│
│    A guitar string vibrates │
│    at its natural frequency  │
│    when plucked, producing   │
│    a specific musical note. │
└───────────────────────────┘

┌───────────────────────────┐
│ Important Notes          │
│                           │
│ - Resonance can be both    │
│   beneficial (e.g., in musical│
│   instruments) and harmful (e.g.,│
│   in structures).           │
│ - Damping can reduce the effects│
│   of resonance in various systems.│
└───────────────────────────┘

┌───────────────────────────┐
│ Summary                  │
│                           │
│ Resonance is a fundamental │
│ concept in physics that explains│
│ how systems respond to external│
│ forces. Understanding resonance│
│ is crucial in various fields, │
│ from engineering to music.   │
└───────────────────────────┘
