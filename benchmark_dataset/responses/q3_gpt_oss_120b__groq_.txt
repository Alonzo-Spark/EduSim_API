┌───────────────────────────────────────────────────────────────────────┐
│                           Introduction                                 │
│                                                                       │
│ In physics we often describe how an object moves. Two fundamental   │
│ quantities that appear in every motion problem are **distance** and │
│ **displacement**.  Though they are related, they capture very different│
│ aspects of the motion.  Understanding the distinction is essential   │
│ for solving problems in kinematics, dynamics, and many engineering   │
│ applications.                                                          │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Definition                                   │
│                                                                       │
│ **Distance** – the total length of the path traveled by an object.   │
│ It is a **scalar** quantity (only magnitude, no direction) and is   │
│ always non‑negative.                                                  │
│                                                                       │
│ **Displacement** – the straight‑line vector from the object’s initial │
│ position to its final position.  It has both magnitude **and**      │
│ direction, making it a **vector** quantity.                           │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Key Concepts                                 │
│                                                                       │
│ • **Scalar vs. Vector** – Distance is a scalar; displacement is a     │
│   vector.                                                             │
│ • **Path Dependence** – Distance depends on the actual route taken;  │
│   displacement depends only on start‑ and end‑points.                │
│ • **Additivity** – Total distance adds up over each segment of a      │
│   journey, whereas displacement adds vectorially.                     │
│ • **Units** – Both are measured in meters (m) in SI, but displacement│
│   is often written with a direction (e.g., 5 m east).                │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Examples                                     │
│                                                                       │
│ **Example 1 – Walking around a block**                                 │
│ • Path: a square 100 m on each side.                                   │
│ • Total distance traveled = 4 × 100 m = **400 m**.                       │
│ • Start and finish are the same point, so displacement = **0 m**.      │
│                                                                       │
│ **Example 2 – Running straight north 150 m**                           │
│ • Path: a straight line, no turns.                                      │
│ • Distance = **150 m**.                                                │
│ • Displacement = **150 m north** (same magnitude, with direction).   │
│                                                                       │
│ **Example 3 – Hiking up a mountain then descending the same trail**   │
│ • Upward climb: 2 km, downhill return: 2 km.                           │
│ • Distance = **4 km**.                                                 │
│ • Start and finish at the same campsite → displacement = **0 km**.    │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Comparison Table                              │
│                                                                       │
│ ┌─────────────────────┬───────────────────────┬─────────────────────┐ │
│ │ Property            │ Distance               │ Displacement         │ │
│ ├─────────────────────┼───────────────────────┼─────────────────────┤ │
│ │ Type                │ Scalar                 │ Vector               │ │
│ ├─────────────────────┼───────────────────────┼─────────────────────┤ │
│ │ Depends on path?    │ Yes                    │ No (only start‑end)  │ │
│ ├─────────────────────┼───────────────────────┼─────────────────────┤ │
│ │ Direction?          │ No                     │ Yes                  │ │
│ ├─────────────────────┼───────────────────────┼─────────────────────┤ │
│ │ Additive?           │ Simple sum of lengths │ Vector sum (head‑to‑│ │
│ │                     │                       │ tail)                │ │
│ ├─────────────────────┼───────────────────────┼─────────────────────┤ │
│ │ Minimum value       │ 0 (if object stays   │ 0 (if start = end)   │ │
│ │                     │ still)                │                       │ │
│ └─────────────────────┴───────────────────────┴─────────────────────┘ │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Applications                                 │
│                                                                       │
│ • **Navigation & GPS** – Displacement vectors help compute the        │
│   shortest route between two points, while distance tells how long   │
│   the actual traveled path was.                                        │
│ • **Sports & Fitness** – Runners track total distance run, cyclists  │
│   may be interested in net displacement to see how far they are from │
│   the start point.                                                     │
│ • **Engineering** – When designing conveyor belts, the distance the   │
│   belt moves matters for wear, whereas displacement matters for the │
│   placement of the final product.                                     │
│ • **Physics Experiments** – Work calculations use displacement (via   │
│   force·displacement) rather than distance.                           │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│                           Summary                                       │
│                                                                       │
│ – Distance = total path length, scalar, no direction.                │
│ – Displacement = straight‑line vector from start to finish,          │
│   direction matters.                                                  │
│ – Distance depends on the route; displacement depends only on the    │
│   endpoints.                                                          │
│ – Both are measured in meters, but displacement is expressed with a   │
│   direction (e.g., 5 m east).                                         │
│                                                                       │
│ Remember: *If you close the loop, distance can be large while        │
│ displacement is zero.*                                                │
└───────────────────────────────────────────────────────────────────────┘
