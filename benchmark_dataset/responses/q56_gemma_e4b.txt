**Detailed Component Descriptions & Logic**

**1. Section Cards:**

*   **Purpose:**  Encapsulates a section of text.
*   **Structure:**

    ```html
    <div class="section-card">
      <h3 class="section-title">Section Title</h3>
      <div class="section-content">
        <p>Paragraph content goes here...</p>
      </div>
    </div>
    ```

*   **Logic:**
    *   Detect section headers (e.g., `# Introduction`, `## Definition`).
    *   Extract the text content following the header.
    *   Assign a class based on the section title (e.g., `introduction`, `definition`).
    *   Style the card with appropriate background color, padding, and border.  Consider subtle visual cues to differentiate sections.

**2. Formula Cards:**

*   **Purpose:**  Displays a formula with explanation and interactivity.
*   **Structure:**

    ```html
    <div class="formula-card">
      <h4 class="formula-title">Main Formula</h4>
      <div class="formula-content">
        <div class="rendered-formula">
          $$F=ma$$  <!-- This is the LaTeX formula -->
        </div>
        <p class="explanation">
          This formula states that force (F) is equal to mass (m) times acceleration (a).
        </p>
        <button class="explain-button">Explain Formula</button>
        <button class="formula-lab-button">Open Formula Lab</button>
      </div>
    </div>
    ```

*   **Logic:**
    *   Detect LaTeX formulas (`$$...$$`).
    *   Extract the formula string from the `$$...$$` block.
    *   Render the formula using a math rendering library (MathJax, KaTeX, etc.).  **Important:**  This is where KaTeX comes in.  It's the engine that *actually displays* the LaTeX.
    *   Create a button to display a detailed explanation of the formula (potentially linking to a separate explanation section).
    *   Create a button to open a "Formula Lab" – an interactive environment where users can manipulate variables and see the effect on the formula's outcome.
    *   Store the formula, title, surrounding context, and variables in the `FormulaExtraction` data structure.

**3. Table Cards:**

*   **Purpose:**  Displays markdown tables in a responsive format.
*   **Structure:**

    ```html
    <div class="table-card">
      <h3 class="table-title">Table Title</h3>
      <div class="table-content">
        <table>
          <thead>
            <tr>
              <th>Header 1</th>
              <th>Header 2</th>
            </tr>
          </thead>
          <tbody>
            <tr>
              <td>Data 1</td>
              <td>Data 2</td>
            </tr>
            <tr>
              <td>Data 3</td>
              <td>Data 4</td>
            </tr>
          </tbody>
        </table>
      </div>
    </div>
    ```

*   **Logic:**
    *   Detect markdown tables (`| ... | ... |`).
    *   Parse the table into a structured representation (rows, columns, headers).
    *   Render the table using a responsive table library (e.g., DataTables, React Table, or a CSS-based solution). Responsive tables adjust their layout based on screen size.
    *   Create a card containing the rendered table.
