┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ In physics and engineering, quantities   │
│ are classified by how they are described │
│ and how they behave in calculations.   │
│ Two fundamental categories are          │
│ **scalar** and **vector** quantities.   │
│ Understanding the difference is        │
│ essential for solving problems that     │
│ involve magnitude alone or both magnitude│
│ and direction.                         │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Definition                             │
│                                       │
│ **Scalar Quantity**: A physical quantity│
│ described completely by a single number│
│ (its magnitude) and a unit. No direction│
│ information is needed.                  │
│                                       │
│ **Vector Quantity**: A physical quantity│
│ that requires both a magnitude and a    │
│ direction to be fully described. It is │
│ often represented by an arrow.          │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Key Concepts                           │
│                                       │
│ • **Magnitude** – the size or amount of │
│   the quantity (e.g., 5 kg, 20 m).      │
│ • **Direction** – the orientation in   │
│   space (e.g., north, upward, 30° from│
│   the x‑axis).                         │
│ • **Addition** – scalars add algebraically│
│   (5 kg + 3 kg = 8 kg). Vectors add using│
│   tip‑to‑tail or component‑wise methods.│
│ • **Multiplication** – scalars multiply│
│   like ordinary numbers. Vectors can   │
│   be multiplied by scalars (scaling)   │
│   or combined via dot and cross products│
│   (different results).                 │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Scalar Examples                        │
│                                       │
│ • **Mass** – 12 kg (no direction)      │
│ • **Temperature** – 25 °C              │
│ • **Speed (magnitude of velocity)** – │
│   60 km/h (direction ignored)          │
│ • **Energy** – 500 J                   │
│ • **Time** – 15 s                      │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Vector Examples                        │
│                                       │
│ • **Displacement** – 10 m east         │
│ • **Velocity** – 30 m/s north‑west      │
│ • **Force** – 15 N upward               │
│ • **Acceleration** – 9.8 m/s² downward │
│ • **Momentum** – 5 kg·m/s east          │
└───────────────────────────────────────┘



┌───────────────────────────────────────┐
│ Summary                                 │
│                                       │
│ • Scalars have only magnitude; vectors   │
│   have magnitude *and* direction.        │
│ • Scalars are added/subtracted like       │
│   ordinary numbers; vectors require       │
│   component‑wise or tip‑to‑tail methods. │
│ • Many physical quantities (mass, energy)│
│   are scalars, while quantities involving │
│   spatial orientation (force, velocity)  │
│   are vectors.                           │
└───────────────────────────────────────┘
