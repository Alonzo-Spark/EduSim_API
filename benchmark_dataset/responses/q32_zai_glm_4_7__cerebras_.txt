│                        TOPIC OVERVIEW                          │
│                                                               │
│  Thermodynamics is the branch of physics that deals with heat, │
│  work, and temperature, and their relation to energy,         │
│  radiation, and physical properties of matter.                │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                    The Zeroth Law                              │
│                                                               │
│  **Quick Definition**                                          │
│  If two systems are each in thermal equilibrium with a third, │
│  they are in thermal equilibrium with each other.             │
│                                                               │
│  **Key Concepts**                                              │
│  This law implies that temperature is a fundamental and       │
│  measurable property of matter. It allows us to construct     │
│  thermometers.                                                 │
│                                                               │
│  $$ T_A = T_B \quad \text{and} \quad T_B = T_C \implies T_A = T_C $$ │
│                                                               │

┌───────────────────────────────────────────────────────────────┐
│                    The First Law                               │
│                                                               │
│  **Quick Definition**                                          │
│  Energy cannot be created or destroyed, only changed from     │
│  one form to another. This is the principle of conservation   │
│  of energy.                                                    │
│                                                               │
│  **Main Formula**                                              │
│                                                               │
│           $$ \Delta U = Q - W $$                              │
│                                                               │
│  **Variables**                                                 │
│  • $\Delta U$: Change in internal energy of the system        │
│  • $Q$: Heat added to the system                              │
│  • $W$: Work done by the system                               │
│                                                               │

└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                   The Second Law                               │
│                                                               │
│  **Quick Definition**                                          │
│  The entropy of an isolated system always increases over      │
│  time. Heat cannot spontaneously flow from a colder body to   │
│  a hotter body.                                                │
│                                                               │
│  **Main Formula**                                              │
│                                                               │
│        $$ \Delta S_{\text{univ}} \ge 0 $$                      │
│                                                               │
│  **Variables**                                                 │
│  • $\Delta S_{\text{univ}}$: Change in total entropy of the   │
│    universe (system + surroundings).                          │
│                                                               │
│  [ Explain Formula ]       [ Open Formula Lab ]               │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                    The Third Law                               │
│                                                               │
│  **Quick Definition**                                          │
│  The entropy of a perfect crystal at absolute zero is         │
│  exactly zero.                                                 │
│                                                               │
│  **Main Formula**                                              │
│                                                               │
│        $$ \lim_{T \to 0} S = 0 $$                              │
│                                                               │
│  **Important Notes**                                           │
│  This law implies that it is impossible to reach absolute     │
│  zero (0 Kelvin) through a finite number of steps.            │
