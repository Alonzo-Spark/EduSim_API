┌───────────────────────────────────────────────────────────────┐
│ Introduction                                                    │
│                                                                   │
│ In the study of **current electricity**, the relationship between │
│ voltage ( V ), current ( I ), and resistance ( R ) is captured by │
│ one of the most widely‑used empirical rules: **Ohm’s law**.       │
│ This law provides a simple linear model that works well for many   │
│ conductive materials under ordinary conditions.                  │
└───────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────┐
│ Definition                                                      │
│                                                                   │
│ *Ohm’s law* states that, for a given conductor at a constant      │
│ temperature, the electric **current** flowing through it is       │
│ directly proportional to the **potential difference** (voltage)  │
│ applied across it.                                                │
│                                                                   │
│ In symbols:                                                     │
│                                                                   │
│     The current **I** increases linearly as the voltage **V**    │
│     rises, provided the material’s resistance **R** remains      │
│     unchanged.                                                   │
└───────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────┐
│ Main Formula                                                    │
│                                                                   │
│   $$\displaystyle V = I\,R$$                                      │
│                                                                   │
│   [ Explain Formula ]   [ Open Formula Lab ]                     │
│                                                                   │
│   • **V** – potential difference (volts)                         │
│   • **I** – electric current (amperes)                           │
│   • **R** – resistance (ohms)                                    │
└───────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────┐
│ Limitations                                                     │
│                                                                   │
│ 1. **Temperature Dependence** – Resistance **R** varies with     │
│    temperature; the linear relation breaks down when the        │
│    conductor heats up significantly.                             │
│                                                                   │
│ 2. **Non‑Ohmic Materials** – Semiconductors, diodes, electrolytes│
│    and many polymers do not exhibit a constant R; their I‑V     │
│    curves are nonlinear.                                         │
│                                                                   │
│ 3. **High‑Frequency Effects** – At radio‑frequency and above,    │
│    parasitic inductance and capacitance cause phase shifts,      │
│    making the simple V = IR model inaccurate.                    │
│                                                                   │
│ 4. **Breakdown and Saturation** – When the electric field       │
│    exceeds a material’s breakdown voltage, the current spikes   │
│    dramatically, violating the linear assumption.               │
│                                                                   │
│ 5. **Contact and Interface Resistances** – Real circuits have    │
│    additional resistances at connections and interfaces that     │
│    are not accounted for in the ideal V = IR expression.        │
└───────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────┐
│ Summary                                                         │
│                                                                   │
│ • Ohm’s law: **V = I R** – a linear relationship between voltage,│
│   current, and resistance for a *constant‑temperature* conductor.│
│ • It is an excellent first‑order model for metals and many simple │
│   circuits.                                                       │
│ • The law fails when resistance changes (temperature, material   │
│   type, frequency, high fields, or contact effects).             │
│                                                                   │
│ Understanding these limits is essential for designing reliable │
│ electronic and power‑distribution systems.                       │
└───────────────────────────────────────────────────────────────┘
