┌───────────────────────────────────────────────────────────────┐
│ Given Parameters                                               │

│ ┌─────────────────────┬───────────────────┐                  │
│ │ Quantity            │ Value             │                  │
│ ├─────────────────────┼───────────────────┤                  │
│ │ Initial Velocity (u)│ 20 m/s            │                  │
│ │ Angle (θ)           │ 45°               │                  │
│ │ Gravity (g)         │ 9.8 m/s²          │                  │
│ └─────────────────────┴───────────────────┘                  │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ Main Formula                                                   │
│                                                               │
│                                                               │
│      $$ R = \frac{u^2 \sin(2\theta)}{g} $$                    │
│                                                               │
│                                                               │
│ [ Explain Formula ]       [ Open Formula Lab ]                │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ Step-by-Step Calculation                                      │
│                                                               │
│ 1. Identify the components:                                   │
│    - $u = 20$ m/s                                             │
│    - $\theta = 45^\circ$                                      │
│                                                               │
│ 2. Determine $\sin(2\theta)$:                                 │
│    - Since $\theta = 45^\circ$, $2\theta = 90^\circ$.         │
│    - $\sin(90^\circ) = 1$                                     │
│                                                               │
│ 3. Substitute values into the formula:                        │
│    $$ R = \frac{(20)^2 \times 1}{9.8} $$                      │
│                                                               │
│ 4. Simplify:                                                  │
│    $$ R = \frac{400}{9.8} $$                                  │
│    $$ R \approx 40.816 \text{ m} $$                           │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ Final Answer                                                  │
│                                                               │
│ The horizontal range of the ball is approximately **40.82 m**.│
│ (Note: If using $g = 10$ m/s², the range is exactly 40 m).    │
