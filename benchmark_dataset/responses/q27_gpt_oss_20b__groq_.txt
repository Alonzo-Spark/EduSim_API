┌───────────────────────────────────────────────────────────────────────┐
│ Definition                                                                       │
│                                                                                 │
│ Pascal’s law states that in a fluid at rest, the pressure exerted by the fluid │
│ is the same in all directions. The pressure at any point is equal to the       │
│ hydrostatic pressure at that point.                                               │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Main Formula                                                                     │
│                                                                                 │
│     P \;=\; \frac{F}{A}                                                         │
│                                                                                 │
│ [Explain Formula]   [Open Formula Lab]                                           │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Applications                                                                     │
│                                                                                 │
│ • Hydraulic presses                                                             │
│ • Fluid power systems                                                           │
│ • Hydraulic brakes in vehicles                                                  │
│ • Pneumatic tools                                                               │
│ • Measuring fluid pressure in gauges                                           │
└───────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────┐
│ Summary                                                                           │
│                                                                                 │
│ Pascal’s law explains that pressure in a fluid is uniform in all directions and │
│ is proportional to the force applied over a given area. It is fundamental to   │
│ fluid mechanics and underpins many practical technologies such as hydraulics, │
│ brakes, and pressure gauges.                                                     │
└───────────────────────────────────────────────────────────────────────┘
