┌───────────────────────────────────────────────────────┐
│ Introduction                                            │
│                                                       │
│ Uniform circular motion (UCM) is the motion of an     │
│ object traveling at a constant speed along a circular  │
│ path.  Although the speed is constant, the direction   │
│ of the velocity continuously changes, which means the │
│ object is accelerating toward the centre of the       │
│ circle.  This inward (centripetal) acceleration is      │
│ called **centripetal acceleration**.                   │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Definition                                             │
│                                                       │
│ *Uniform Circular Motion*: Motion in a circle with     │
│ constant magnitude of velocity (speed) while the       │
│ direction of the velocity vector rotates uniformly.    │
│                                                       │
│ *Centripetal Acceleration*: The acceleration that      │
│ points toward the centre of the circular path and is   │
│ responsible for changing the direction of the velocity.│
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Key Concepts                                           │
│                                                       │
│ • **Radius (r)** – distance from the centre to the     │
│   moving object.                                      │
│ • **Angular Speed (ω)** – rate of change of the angle   │
│   (rad s⁻¹).                                           │
│ • **Linear Speed (v)** – tangential speed along the     │
│   circle, related to ω by  v = ω r.                    │
│ • **Period (T)** – time for one full revolution,       │
│   T = 2π/ω.                                            │
│ • **Frequency (f)** – revolutions per second, f = 1/T.│
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Characteristics                                        │
│                                                       │
│ • Speed (|v|) is constant.                             │
│ • Velocity vector continuously rotates, changing       │
│   direction at a constant rate.                       │
│ • Acceleration is always directed toward the centre    │
│   (radial) and has magnitude a_c.                     │
│ • Motion is described completely by r, ω (or v) and   │
│   the initial angular position.                       │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Main Formula                                            │
│                                                       │
│ a_c = \frac{v^{2}}{r} = \omega^{2} r                    │
│                                                       │
│ [ Explain Formula ]   [ Open Formula Lab ]            │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Supporting Formulas                                    │
│                                                       │
│ v = \omega r                                           │
│ T = \frac{2\pi r}{v} = \frac{2\pi}{\omega}            │
│ f = \frac{1}{T} = \frac{\omega}{2\pi}                 │
│                                                       │
│ These relations let you move between linear and       │
│ angular quantities easily.                           │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Applications                                           │
│                                                       │
│ • Planetary orbits (approximate circular)             │
│ • Satellite motion around Earth                        │
│ • Turntables, merry‑go‑rounds, rotating machinery      │
│ • Centripetal force in roller‑coaster loops            │
│ • Design of centrifuges and particle accelerators      │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Advantages                                             │
│                                                       │
│ • Predictable, constant speed simplifies analysis.    │
│ • Allows use of simple geometric relations (r, ω).    │
│ • Many engineering systems (gears, rotors) rely on    │
│   steady circular motion for stability.               │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Disadvantages                                          │
│                                                       │
│ • Requires continuous inward (centripetal) force;     │
│   if the force is insufficient, the object flies off   │
│   tangentially.                                        │
│ • Real-world paths often deviate from perfect circles   │
│   due to friction, air resistance, or varying forces. │
│ • At very high speeds relativistic effects become      │
│   non‑negligible.                                      │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Important Notes                                        │
│                                                       │
│ • **Centripetal** means “center‑seeking”; it is a *net* │
│   force, not a new type of force.                     │
│ • The magnitude of centripetal acceleration does not   │
│   depend on the mass of the object (a_c = F_c/m).      │
│ • In a rotating reference frame an apparent “centrifugal│
│   force” is felt outward; it is a pseudo‑force.        │
│ • Uniform circular motion is a special case of         │
│   *uniform angular motion* (constant ω).               │
└───────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────┐
│ Summary                                                │
│                                                       │
│ Uniform circular motion combines a constant speed with│
│ a continuously changing direction, producing a        │
│ radial (centripetal) acceleration a_c = v²/r = ω²r.    │
│ The motion is fully described by the radius r and the │
│ angular speed ω (or linear speed v).  Understanding the│
│ relationship between linear and angular quantities is │
│ essential for analyzing rotating systems in physics   │
│ and engineering.                                      │
└───────────────────────────────────────────────────────┘
