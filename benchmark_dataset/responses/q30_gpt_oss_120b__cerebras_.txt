┌───────────────────────────────────────┐
│ Introduction                           │
│                                       │
│ Bernoulli’s theorem is a cornerstone  │
│ of fluid dynamics. It relates the     │
│ pressure, velocity, and elevation of  │
│ a fluid flowing in a streamline. When │
│ friction and other energy losses are   │
│ negligible, the sum of these energy    │
│ terms remains constant along the flow.│
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Definition                             │
│                                       │
│ **Bernoulli’s theorem** (or Bernoulli’s│
│ equation) states that for an incompress│
│ ible, non‑viscous fluid moving along a │
│ streamline, the total mechanical energy │
│ per unit volume is conserved.          │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Key Concepts                           │
│                                       │
│ • **Streamline** – a path that is      │
│   tangent to the fluid velocity at every│
│   point.                               │
│ • **Incompressible flow** – density ρ  │
│   remains constant.                    │
│ • **Non‑viscous (ideal) flow** – no   │
│   internal friction; energy loss is   │
│   only due to pressure or elevation    │
│   changes.                             │
│ • **Conservation of energy** – the sum │
│   of pressure, kinetic, and potential │
│   energy per unit volume is constant. │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Characteristics                        │
│                                       │
│ • Applies to steady (time‑independent)│
│   flow.                                │
│ • Valid only along a single streamline │
│   unless the flow is irrotational.    │
│ • Assumes no energy added or removed   │
│   by pumps, turbines, or friction.    │
│ • Works for liquids and gases when    │
│   density variations are small.       │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Advantages                              │
│                                          │
│ • Provides a quick, analytical way to  │
│   relate pressure, speed, and height.   │
│ • Requires only local measurements,      │
│   no need for complex instrumentation. │
│ • Forms the basis for many fluid‑flow   │
│   devices (venturi meters, orifice      │
│   plates, Pitot tubes).                 │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Disadvantages                           │
│                                          │
│ • Assumes ideal (non‑viscous) flow; real│
│   fluids experience friction, causing   │
│   energy loss.                           │
│ • Not valid for turbulent or highly     │
│   compressible flows.                   │
│ • Must be applied along a single         │
│   streamline; mixing streams require    │
│   more sophisticated analysis.          │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Important Notes                         │
│                                          │
│ • When a pump adds energy, the constant │
│   becomes **C + work**; when a turbine   │
│   extracts energy, subtract work.       │
│ • For compressible gases, the density   │
│   term varies; an extended Bernoulli     │
│   form includes the specific enthalpy. │
│ • Always check the underlying assumptions│
│   before applying the equation.         │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ Summary                                 │
│                                          │
│ Bernoulli’s theorem links pressure,      │
│ kinetic, and potential energy in an     │
│ ideal fluid. Its simple algebraic form   │
│ makes it a powerful tool for quick       │
│ analysis of fluid systems, provided the │
│ assumptions of incompressibility and    │
│ inviscid flow hold.                       │
└───────────────────────────────────────┘
