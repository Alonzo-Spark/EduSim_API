┌───────────────────────────┐  
│ Quick Definition          │  
│                           │  
│ The problem involves a car  │  
│ accelerating uniformly from  │  
│ rest with a given acceleration. │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Given Information         │  
│                           │  
│ - Initial Velocity (u) = 0 m/s  │  
│ - Acceleration (a) = 2 m/s²   │  
│ - Time (t) = 10 s             │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Main Formula              │  
│                           │  
│     $$v = u + at$$        │  
│                           │  
│ [ Explain Formula ]       │  
│ [ Open Formula Lab ]      │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Calculation               │  
│                           │  
│ Substituting the values:  │  
│                           │  
│ $$v = 0 + (2 \times 10)$$│  
│                           │  
│ $$v = 20 \text{ m/s}$$    │  
└───────────────────────────┘  

┌───────────────────────────┐  
│ Conclusion                │  
│                           │  
│ The velocity of the car   │  
│ after 10 seconds is       │  
│ 20 m/s.                   │  
└───────────────────────────┘
