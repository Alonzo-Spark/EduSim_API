┌───────────────────────────────────────────────┐
│ Introduction                                  │
│                                               │
│ When a gun fires, the bullet is propelled     │
│ forward, and simultaneously the gun moves    │
│ backward. This opposite motion is known as    │
│ recoil. It occurs because the forces inside   │
│ the gun are unbalanced during the firing      │
│ process.                                       │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Definition                                     │
│                                               │
│ Recoil is the backward movement of a gun (or  │
│ any projectile launcher) that occurs when the │
│ bullet is expelled forward. It results from the│
│ conservation of momentum and Newton’s third   │
│ law of motion.                                 │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Key Concepts                                   │
│                                               │
│ • Action–Reaction Pairs                       │
│   (Newton’s Third Law)                        │
│ • Conservation of Linear Momentum             │
│ • Force, Mass, and Acceleration               │
│ • Momentum Change During Firing               │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Main Formula                                   │
│                                               │
│     $$m_{\text{bullet}}\,v_{\text{bullet}} +   │
│        m_{\text{gun}}\,v_{\text{gun}} = 0$$     │

│ Applications                                   │
│                                               │
│ • Design of firearms to minimize recoil       │
│ • Recoil management in sports shooting         │
│ • Understanding projectile motion in          │
│   physics and engineering                     │
└───────────────────────────────────────────────┘

┌───────────────────────────────────────────────┐
│ Summary                                        │
│                                               │
│ The gun’s recoil is a direct consequence of   │
│ Newton’s third law: the bullet’s forward force │
│ on the gun is matched by an equal and opposite │
│ backward force on the bullet. Conservation of  │
│ momentum ensures that the total momentum before│
│ and after firing remains zero, causing the gun │
│ to recoil.                                     │
└───────────────────────────────────────────────┘
