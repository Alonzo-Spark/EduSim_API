┌───────────────────────────────────────┐
│ Definition                            │
│                                       │
│ Surface tension is the tendency of a   │
│ liquid’s surface to contract so as to   │
│ minimize its surface area.  It arises   │
│ from cohesive forces between molecules   │
│ at the liquid‑air interface; molecules   │
│ within the bulk experience balanced       │
│ attractions, while those at the surface   │
│ experience a net inward pull, creating   │
│ a “skin‑like” film that resists external │
│ deformation.                            │
└───────────────────────────────────────┘


┌───────────────────────────────────────┐
│ Factors Affecting Surface Tension      │
│                                       │
│ • **Temperature** – Raising temperature│
│   increases molecular motion, reducing │
│   cohesive forces and thus lowering     │
│   surface tension.                     │
│                                       │
│ • **Impurities / Surfactants** – Substances│
│   that adsorb at the interface (e.g.,   │
│   soaps, detergents, oils) disrupt        │
│   intermolecular attractions, dramatically│
│   decreasing surface tension.          │
│                                       │
│ • **Nature of the Liquid** – Liquids with │
│   stronger intermolecular forces (hydrogen│
│   bonding, dipole‑dipole) exhibit higher │
│   surface tension (e.g., water) than    │
│   non‑polar liquids (e.g., hexane).      │
│                                       │
│ • **Presence of Dissolved Gases** – Gases │
│   can either increase or decrease tension│
│   depending on how they alter the liquid’s│
│   cohesive network.                     │
│                                       │
│ • **Electrical Fields** – In polar liquids│
│   an external electric field can align   │
│   dipoles, modifying intermolecular      │
│   attractions and thus surface tension. │
└───────────────────────────────────────┘
