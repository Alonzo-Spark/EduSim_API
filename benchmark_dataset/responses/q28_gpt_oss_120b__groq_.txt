┌─────────────────────────────┐  
│ Introduction                 │  
│                             │  
│ Archimedes’ principle tells │  
│ us why an object either       │  
│ floats or sinks when it is   │  
│ immersed in a fluid. It is a │  
│ cornerstone of fluid‑         │  
│ mechanics and engineering.   │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│ Definition                   │  
│                             │  
│ *When a body is fully or      │  
│ partially submerged in a     │  
│ fluid, it experiences an      │  
│ upward force equal in magnitude│  
│ to the weight of the fluid    │  
│ displaced by the body.*       │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│ Key Concepts                 │  
│                             │  
│ • **Buoyant force (F​b)** –   │  
│   upward force exerted by the│  
│   fluid.                     │  
│ • **Displaced volume (V​d)** –│  
│   volume of fluid that the   │  
│   object pushes aside.       │  
│ • **Fluid density (ρ​f)** –   │  
│   mass per unit volume of the│  
│   fluid.                     │  
│ • **Gravity (g)** – standard │  
│   acceleration (≈9.81 m s⁻²). │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│ Formula                      │  
│                             │

│ │ Main Formula            │ │  
│ │                         │ │  
│ │  F₍b₎ = ρ₍f₎ V₍d₎ g   │ │

┌─────────────────────────────┐  
│ Example – Floating Wood      │  
│                             │  
│ A block of pine wood (density │  
│ ρ₍wood₎ = 0.55 g cm⁻³) is placed│  
│ in fresh water (ρ₍water₎ =   │  
│ 1.00 g cm⁻³). The block’s      │  
│ dimensions: 10 cm × 10 cm ×│  
│ 5 cm → volume V₍block₎ = 500 │  
│ cm³ = 5 × 10⁻⁴ m³.            │  
│                             │  
│ **Step 1 – Weight of the wood**│  
│   m₍wood₎ = ρ₍wood₎·V₍block₎   │  
│   = 0.55 g cm⁻³ · 500 cm³      │  
│   = 275 g = 0.275 kg          │  
│   W₍wood₎ = m₍wood₎·g ≈ 2.70 N │  
│                             │  
│ **Step 2 – Buoyant force**   │  
│   F₍b₎ = ρ₍water₎·V₍block₎·g   │  
│   = 1.00 g cm⁻³·500 cm³·g      │  
│   = 500 g·g ≈ 4.90 N          │  
│                             │  
│ **Result**: Since F₍b₎ (4.90 N) │  
│ > W₍wood₎ (2.70 N), the block  │  
│ experiences a net upward     │  
│ force and floats, with part   │  
│ of it above the surface.      │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│ Applications                 │  
│                             │  
│ • Designing ships and submarines│  
│ • Determining load capacity of│  
│   floating platforms            │  
│ • Hydrometer calibration        │  
│ • Measuring fluid density via  │  
│   immersion methods            │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│ Important Notes              │  
│                             │  
│ • The principle holds for any │  
│   fluid (liquid or gas).       │  
│ • Only the **displaced** fluid│  
│   contributes to the buoyant  │  
│   force.                       │  
│ • If ρ₍object₎ < ρ₍fluid₎ →      │  
│   object floats; otherwise it  │  
│   sinks.                       │  
│ • Surface tension can modify │  
│   the apparent buoyancy for   │  
│   very small objects.         │  
└─────────────────────────────┘  

┌─────────────────────────────┐  
│ Summary                      │  
│                             │  
│ Archimedes’ principle states │  
│ that the upward buoyant force │  
│ equals the weight of the      │  
│ fluid displaced by the object.│  
│ The simple formula F₍b₎ = ρ₍f₎ V₍d₎ g lets │  
│ engineers predict whether an │  
│ object will float or sink, and │  
│ forms the basis for many      │  
│ practical designs.            │  
└─────────────────────────────┘
